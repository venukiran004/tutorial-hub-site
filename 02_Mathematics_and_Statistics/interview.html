Q1. What is an eigenvalue and eigenvector? Why do they matter in ML?

AnswerML applicationsPCAPageRankSpectral clusteringStability analysis

Answer: For a square matrix $A$, an eigenvector $\mathbf{v}$ satisfies $A\mathbf{v} = \lambda\mathbf{v}$, where $\lambda$ is the eigenvalue. The matrix stretches the eigenvector by $\lambda$ without changing its direction.

ML applications: - PCA: Eigenvectors of the covariance matrix define principal components; eigenvalues indicate variance explained - PageRank: Dominant eigenvector of the link matrix gives page importance - Spectral clustering: Eigenvectors of the graph Laplacian define cluster structure - Stability analysis: Eigenvalues of the Hessian determine convergence of optimization

•

Q2. Explain Singular Value Decomposition (SVD) and its applications.

AnswerApplications

Answer: Any matrix $A_{m \times n}$ can be decomposed as:

$$A = U \Sigma V^T$$

  • $U$ ($m \times m$): Left singular vectors (orthonormal) — column space
  • $\Sigma$ ($m \times n$): Diagonal matrix of singular values $\sigma_1 \geq \sigma_2 \geq \dots \geq 0$
  • $V^T$ ($n \times n$): Right singular vectors (orthonormal) — row space

Applications:

ApplicationHow SVD is used
PCASVD on centered data gives principal components directly
Recommender systemsLow-rank approximation of user-item matrix
Image compressionKeep top-$k$ singular values, discard rest
Pseudoinverse$A^+ = V\Sigma^+ U^T$ for least squares
Latent Semantic AnalysisReduce term-document matrix dimensionality

Q3. What is a positive definite matrix? Why is it important?

AnswerImportance in ML

Answer: A symmetric matrix $A$ is positive definite if $\mathbf{x}^T A \mathbf{x} > 0$ for all nonzero $\mathbf{x}$. Equivalently, all eigenvalues are positive.

Importance in ML: - Covariance matrices must be positive semi-definite (PSD) - Kernel matrices (Gram matrices) must be PSD for valid kernels - The Hessian being positive definite at a point guarantees a local minimum - Cholesky decomposition only works on positive definite matrices

Q4. Explain the difference between rank, null space, and column space.

AnswerRankColumn space (range)Null space (kernel)ML relevance

Answer: - Rank: Number of linearly independent rows (or columns). $\text{rank}(A) = \dim(\text{column space})$ - Column space (range): Set of all possible outputs $A\mathbf{x}$. Dimension = rank - Null space (kernel): Set of all $\mathbf{x}$ such that $A\mathbf{x} = \mathbf{0}$. Dimension = $n - \text{rank}(A)$ (rank-nullity theorem)

ML relevance: If your feature matrix has rank < number of features, you have multicollinearity. The null space tells you which feature combinations are redundant.

Q5. What is the condition number of a matrix and why does it matter?

AnswerML impactFix

Answer: The condition number is $\kappa(A) = \frac{\sigma_{\max}}{\sigma_{\min}}$ (ratio of largest to smallest singular value).

  • $\kappa \approx 1$: Well-conditioned — small input changes → small output changes
  • $\kappa \gg 1$: Ill-conditioned — numerically unstable

ML impact: Ill-conditioned feature matrices cause: - Unstable regression coefficients - Slow convergence in gradient descent - Numerical errors in matrix inversions

Fix: Feature scaling, regularization, or SVD-based pseudoinverse.

Q6. How does matrix multiplication relate to neural networks?

AnswerRotation/reflectionScalingProjection

Answer: A fully connected layer computes $\mathbf{y} = W\mathbf{x} + \mathbf{b}$, which is an affine transformation. The weight matrix $W$ performs: - Rotation/reflection (orthogonal component) - Scaling (singular values) - Projection (if output dim < input dim)

A deep network is a composition of affine transformations with nonlinear activations: $$f(\mathbf{x}) = \sigma(W_L \cdot \sigma(W_{L-1} \cdots \sigma(W_1 \mathbf{x} + b_1) \cdots + b_{L-1}) + b_L)$$

Q8. What is an orthogonal matrix? Where is it used?

AnswerUses

Answer: A matrix $Q$ is orthogonal if $Q^T Q = QQ^T = I$, meaning $Q^{-1} = Q^T$. Columns (and rows) are orthonormal. Orthogonal matrices preserve norms: $|Q\mathbf{x}| = |\mathbf{x}|$.

Uses: - SVD components ($U$ and $V$) - QR decomposition for numerical stability - Orthogonal initialization of neural network weights (reduces vanishing/exploding gradients) - Rotation matrices in computer vision

Q9. Explain the Gram matrix and its role in kernel methods.

AnswerRequirementsApplications

Answer: The Gram matrix $G_{ij} = \mathbf{x}i^T \mathbf{x}_j$ stores all pairwise inner products. In kernel methods, $G{ij} = K(\mathbf{x}_i, \mathbf{x}_j)$ where $K$ is the kernel function.

Requirements: Must be symmetric positive semi-definite (Mercer's condition). This guarantees the kernel corresponds to an inner product in some (possibly infinite-dimensional) feature space.

Applications: SVM, Gaussian processes, kernel PCA, style transfer (Gram matrix of CNN features captures texture).

Q10. What is the trace of a matrix and when is it useful?

AnswerPropertiesML uses

Answer: $\text{tr}(A) = \sum_{i} A_{ii}$ — sum of diagonal elements. Also equals the sum of eigenvalues.

Properties: - $\text{tr}(AB) = \text{tr}(BA)$ (cyclic property) - $\text{tr}(A^T A) = \sum_{ij} A_{ij}^2$ (Frobenius norm squared)

ML uses: Nuclear norm (sum of singular values) for matrix completion, Frobenius norm in regularization, trace in Fisher information matrix.

Q12. What is the matrix determinant and what does it signify?

AnswerML relevance

Answer: The determinant $\det(A)$ measures the signed volume scaling factor of the linear transformation. - $\det(A) = 0$: Matrix is singular (not invertible), columns are linearly dependent - $|\det(A)| > 1$: Transformation expands volume - $\det(A) < 0$: Transformation includes a reflection

ML relevance: Appears in the multivariate Gaussian density: $$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\mu)^T \Sigma^{-1}(\mathbf{x}-\mu)\right)$$

Q13. What is the Hadamard product vs standard matrix multiplication?

AnswerHadamard (element-wise)Standard (dot)In ML

Answer: - Hadamard (element-wise): $(A \odot B){ij} = A{ij} \cdot B_{ij}$ — same-shape matrices - Standard (dot): $(AB){ij} = \sum_k A{ik} B_{kj}$ — inner dimensions must match

In ML: - Hadamard: Gating mechanisms (LSTM gates), attention masking, dropout masks - Standard: Layer transformations, attention ($QK^T$), projection

Q14. What is the Moore-Penrose pseudoinverse?

Answer: For any matrix $A$, the pseudoinverse $A^+$ satisfies $A^+ = V\Sigma^+ U^T$ (from SVD), where $\Sigma^+$ inverts the non-zero singular values.

  • If $A$ is invertible: $A^+ = A^{-1}$
  • Overdetermined ($m > n$): $A^+ = (A^T A)^{-1} A^T$ — least squares solution
  • Underdetermined ($m < n$): $A^+ = A^T (AA^T)^{-1}$ — minimum norm solution

Q15. Explain the relationship between PCA and SVD.

Answer: Given centered data matrix $X$ ($n$ samples × $d$ features): 1. PCA finds eigenvectors of covariance matrix $C = \frac{1}{n-1}X^T X$ 2. SVD of $X = U\Sigma V^T$ gives $X^T X = V\Sigma^2 V^T$ 3. Therefore, $V$ columns = principal components, $\sigma_i^2/(n-1)$ = variance explained

SVD is preferred computationally because: - No need to form $X^T X$ (avoids squaring condition number) - Numerically more stable - Works for non-square matrices directly

Q16. What is the gradient and why is it important for ML?

AnswerIn ML

Answer: The gradient $\nabla f(\mathbf{x})$ is a vector of partial derivatives pointing in the direction of steepest ascent:

$$\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n}\right]$$

In ML: Gradient descent updates parameters in the direction of steepest descent: $$\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)$$

The gradient's magnitude indicates how sensitive the loss is to each parameter.

•

Q17. Explain the chain rule and its role in backpropagation.

AnswerBackpropagation

Answer: For composed functions $f(g(x))$: $\frac{df}{dx} = \frac{df}{dg} \cdot \frac{dg}{dx}$

Backpropagation is the chain rule applied to a computation graph. For a network with layers $z_1, z_2, \dots, z_L$:

$$\frac{\partial \mathcal{L}}{\partial W_l} = \frac{\partial \mathcal{L}}{\partial z_L} \cdot \frac{\partial z_L}{\partial z_{L-1}} \cdots \frac{\partial z_{l+1}}{\partial z_l} \cdot \frac{\partial z_l}{\partial W_l}$$

This is computed efficiently by caching intermediate activations (forward pass) and propagating gradients backward.

Q18. What is a convex function? Why does convexity matter?

AnswerWhy it matterssingle global minimumnon-convex

Answer: A function $f$ is convex if for all $\mathbf{x}, \mathbf{y}$ and $\lambda \in [0,1]$: $$f(\lambda\mathbf{x} + (1-\lambda)\mathbf{y}) \leq \lambda f(\mathbf{x}) + (1-\lambda)f(\mathbf{y})$$

Equivalently, the Hessian $H$ is positive semi-definite everywhere.

Why it matters: - Convex problems have a single global minimum — no local minima traps - Linear regression, logistic regression, SVM (hinge loss) are convex - Neural network losses are non-convex — local minima, saddle points - Convex relaxations are used to approximate hard problems

Q19. What is the Hessian matrix?

AnswerUsesPositive definite $H$Negative definite $H$Indefinite $H$

Answer: The Hessian $H$ is the matrix of second-order partial derivatives:

$$H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$$

Uses: - Positive definite $H$ → local minimum - Negative definite $H$ → local maximum - Indefinite $H$ → saddle point - Newton's method uses $H$ for faster convergence: $\theta_{t+1} = \theta_t - H^{-1}\nabla f$ - Fisher Information Matrix (expected Hessian of log-likelihood) → natural gradient

Q21. What is the learning rate and how do you choose it?

AnswerSelection strategiesLearning rate finderSchedulesAdaptive methodsCyclical LR

Answer: The learning rate $\eta$ controls step size in gradient descent. Too large → divergence. Too small → slow convergence.

Selection strategies: 1. Learning rate finder: Increase LR exponentially, plot loss vs LR, pick steepest descent point 2. Schedules: Step decay, cosine annealing, warm-up + decay 3. Adaptive methods: Adam, AdaGrad, RMSProp adjust per-parameter 4. Cyclical LR: Oscillate between bounds (Smith, 2017)

Rule of thumb: Start with $10^{-3}$ for Adam, $10^{-2}$ for SGD with momentum.

Q22. Explain the vanishing and exploding gradient problems.

AnswervanishexplodeSolutions

Answer: In deep networks with $L$ layers, the gradient at layer $l$ involves a product: $$\frac{\partial \mathcal{L}}{\partial W_l} \propto \prod_{k=l}^{L-1} \frac{\partial z_{k+1}}{\partial z_k}$$

  • If $\left|\frac{\partial z_{k+1}}{\partial z_k}\right| < 1$ for most $k$ → gradients vanish (exponential decay)
  • If $\left|\frac{\partial z_{k+1}}{\partial z_k}\right| > 1$ for most $k$ → gradients explode

Solutions:

ProblemSolutions
VanishingReLU activation, residual connections, LSTM/GRU gates, proper initialization (He, Xavier)
ExplodingGradient clipping, batch normalization, lower learning rate

Q23. What is the Jacobian matrix?

Answer: For a vector-valued function $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$, the Jacobian is:

$$J_{ij} = \frac{\partial f_i}{\partial x_j}$$

The Jacobian is the multivariate generalization of the derivative. In neural networks, each layer's Jacobian relates input perturbations to output perturbations. The chain rule in matrix form: $J_{\text{total}} = J_L \cdot J_{L-1} \cdots J_1$.

Q24. What are Lagrange multipliers and KKT conditions?

AnswerLagrange multipliersKKT conditionsML relevance

Answer: Lagrange multipliers solve constrained optimization: minimize $f(x)$ subject to $g(x) = 0$.

$$\mathcal{L}(x, \lambda) = f(x) + \lambda g(x)$$

Solve $\nabla_x \mathcal{L} = 0$ and $g(x) = 0$.

KKT conditions extend this to inequality constraints ($g(x) \leq 0$): 1. Stationarity: $\nabla f + \sum \lambda_i \nabla g_i = 0$ 2. Primal feasibility: $g_i(x) \leq 0$ 3. Dual feasibility: $\lambda_i \geq 0$ 4. Complementary slackness: $\lambda_i g_i(x) = 0$

ML relevance: SVM optimization is solved using KKT conditions. Support vectors are the points where $\lambda_i > 0$.

•

Q25. What is the difference between local and global minima?

AnswerLocal minimumGlobal minimum

Answer: - Local minimum: $f(x^) \leq f(x)$ for all $x$ in a neighborhood - Global minimum: $f(x^) \leq f(x)$ for all $x$ in the entire domain

For convex functions, every local minimum is global. Neural network loss surfaces are non-convex but: - Most local minima in high dimensions have similar loss values - Saddle points (not local minima) are the main obstacle - Overparameterized networks often have connected low-loss regions

•

Q26. Explain Taylor expansion and its use in optimization.

AnswerUsesNewton's methodNatural gradientTrust region methodsL-BFGS

Answer: Second-order Taylor expansion around $x_0$:

$$f(x) \approx f(x_0) + \nabla f(x_0)^T (x - x_0) + \frac{1}{2}(x - x_0)^T H(x_0)(x - x_0)$$

Uses: - Newton's method: Set gradient of Taylor expansion to 0 → $x_{t+1} = x_t - H^{-1}\nabla f$ - Natural gradient: Uses Fisher information (expected Hessian) instead of $H$ - Trust region methods: Optimize Taylor approximation within a trust region - L-BFGS: Approximates inverse Hessian from past gradients

•

Q27. What is the softmax function and its gradient?

AnswerGradientNumerical stability

Answer:

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

Properties: outputs sum to 1, all positive — valid probability distribution.

Gradient: $$\frac{\partial \text{softmax}(z_i)}{\partial z_j} = \text{softmax}(z_i)(\delta_{ij} - \text{softmax}(z_j))$$

Where $\delta_{ij}$ is the Kronecker delta (1 if $i=j$, 0 otherwise).

Numerical stability: Subtract $\max(z)$ before exponentiation: $\text{softmax}(z - \max(z))$.

•

Q28. What is the cross-entropy loss and why is it used?

AnswerBinary cross-entropy

Answer: For true distribution $p$ and predicted distribution $q$:

$$H(p, q) = -\sum_{i} p_i \log q_i$$

Binary cross-entropy: $\mathcal{L} = -[y\log(\hat{y}) + (1-y)\log(1-\hat{y})]$

Why cross-entropy over MSE for classification: - Cross-entropy gradient doesn't saturate when predictions are confident but wrong - It's the negative log-likelihood for categorical/Bernoulli distributions - Minimizing CE = maximizing likelihood = minimizing KL divergence

•

Q29. Explain the relationship between MLE, MAP, and regularization.

AnswerMLEMAPL2 regularization (Ridge)L1 regularization (Lasso)

Answer: - MLE: $\hat{\theta}{MLE} = \arg\max\theta P(D|\theta)$ — maximize likelihood - MAP: $\hat{\theta}{MAP} = \arg\max\theta P(\theta|D) = \arg\max_\theta P(D|\theta)P(\theta)$ — add prior

Taking negative log: - MLE → minimize $-\log P(D|\theta)$ = loss function alone - MAP with Gaussian prior → minimize $\mathcal{L} + \lambda|\theta|_2^2$ = L2 regularization (Ridge) - MAP with Laplacian prior → minimize $\mathcal{L} + \lambda|\theta|_1$ = L1 regularization (Lasso)

Q30. What are saddle points and why are they problematic?

AnswerSolutions

Answer: A saddle point has zero gradient ($\nabla f = 0$) but is neither a minimum nor maximum — the Hessian has both positive and negative eigenvalues.

Why they're worse than local minima in deep learning: - In $d$ dimensions, a critical point with $k$ negative eigenvalues is a $k$-th order saddle point - The probability of all $d$ eigenvalues being positive (true minimum) decreases exponentially with $d$ - Saddle points create plateaus where gradient is near-zero → slow training

Solutions: Momentum, Adam (adaptive LR escapes plateaus), noise in SGD, negative curvature descent.

Q31. State and explain Bayes' theorem.

AnswerPosteriorLikelihoodPriorEvidence (marginal likelihood)ML applications

Answer: $$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

  • $P(A|B)$: Posterior — updated belief after observing evidence $B$
  • $P(B|A)$: Likelihood — probability of evidence given hypothesis
  • $P(A)$: Prior — initial belief
  • $P(B)$: Evidence (marginal likelihood) — normalizing constant

ML applications: Naive Bayes classifier, Bayesian optimization, posterior inference, spam filtering.

Q33. Explain the Central Limit Theorem (CLT).

AnswerPractical implicationsExceptions

Answer: If $X_1, X_2, \dots, X_n$ are i.i.d. with mean $\mu$ and variance $\sigma^2$, then as $n \to \infty$:

$$\bar{X}_n = \frac{1}{n}\sum X_i \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$$

Practical implications: - Sample means are approximately normal for $n \geq 30$ (rule of thumb) - Justifies confidence intervals and hypothesis tests - Explains why Gaussian noise models work well in many ML settings - Exceptions: Heavy-tailed distributions (Cauchy) — CLT doesn't apply

•

Q34. What is the Law of Large Numbers?

AnswerWeak LLNStrong LLN

Answer: - Weak LLN: $\bar{X}_n \xrightarrow{P} \mu$ (converges in probability) - Strong LLN: $\bar{X}_n \xrightarrow{a.s.} \mu$ (almost sure convergence)

As sample size grows, the sample mean converges to the true mean. This justifies: - Using empirical averages to estimate expectations - Monte Carlo methods - SGD converging to the true gradient in expectation

Q36. What is conditional probability? Explain with an ML example.

AnswerExample — Spam filter

Answer: $P(A|B) = \frac{P(A \cap B)}{P(B)}$

Example — Spam filter: - $P(\text{spam}|\text{"free"}) = \frac{P(\text{"free"}|\text{spam}) \cdot P(\text{spam})}{P(\text{"free"})}$ - If 80% of spam emails contain "free", 5% of all emails are spam, and 10% of all emails contain "free": - $P(\text{spam}|\text{"free"}) = \frac{0.80 \times 0.05}{0.10} = 0.40$

Q37. What is the difference between joint, marginal, and conditional distributions?

AnswerJointMarginalConditionalRelationship

Answer: - Joint: $P(X, Y)$ — probability of $X$ and $Y$ together - Marginal: $P(X) = \sum_y P(X, Y=y)$ — integrate/sum out the other variable - Conditional: $P(Y|X) = \frac{P(X, Y)}{P(X)}$

Relationship: $P(X, Y) = P(Y|X) \cdot P(X) = P(X|Y) \cdot P(Y)$

Q38. What is independence vs conditional independence?

AnswerIndependenceConditional independenceML relevance

Answer: - Independence: $P(A, B) = P(A) \cdot P(B)$ — knowing $A$ tells you nothing about $B$ - Conditional independence: $P(A, B|C) = P(A|C) \cdot P(B|C)$ — given $C$, $A$ and $B$ are independent

ML relevance: Naive Bayes assumes features are conditionally independent given the class. Markov property: $P(X_t | X_{t-1}, X_{t-2}, \dots) = P(X_t | X_{t-1})$.

Q39. Explain the concept of expectation, variance, and covariance.

AnswerExpectationVarianceCovarianceCorrelation

Answer: - Expectation: $E[X] = \sum x \cdot P(x)$ or $\int x \cdot f(x)\,dx$ — the "average" value - Variance: $\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$ — spread - Covariance: $\text{Cov}(X, Y) = E[(X-\mu_X)(Y-\mu_Y)]$ — linear relationship - Correlation: $\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y} \in [-1, 1]$ — normalized covariance

Q40. What is the difference between PDF, PMF, and CDF?

AnswerPMF (discrete)PDF (continuous)CDF

Answer: - PMF (discrete): $P(X = x)$ — probability at each point, sums to 1 - PDF (continuous): $f(x)$ where $P(a \leq X \leq b) = \int_a^b f(x)\,dx$ — density, not probability - CDF: $F(x) = P(X \leq x)$ — cumulative probability, non-decreasing from 0 to 1

Q41. What is the maximum likelihood estimation (MLE)?

AnswerExample — GaussianProperties

Answer: MLE finds parameters that maximize the probability of observed data:

$$\hat{\theta}{MLE} = \arg\max\theta \prod_{i=1}^n P(x_i | \theta) = \arg\max_\theta \sum_{i=1}^n \log P(x_i | \theta)$$

Example — Gaussian: $\hat{\mu}{MLE} = \bar{x}$, $\hat{\sigma}^2{MLE} = \frac{1}{n}\sum(x_i - \bar{x})^2$

Properties: Consistent, asymptotically efficient, asymptotically normal. But can overfit with small data (no regularization).

Q42. What is the KL divergence?

AnswerPropertiesML uses

Answer: KL divergence measures how one distribution $Q$ differs from a reference $P$:

$$D_{KL}(P | Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

Properties: - $D_{KL} \geq 0$ (Gibbs' inequality) - $D_{KL}(P | Q) \neq D_{KL}(Q | P)$ — not symmetric (not a true distance) - Minimizing cross-entropy = minimizing KL divergence (since $H(P, Q) = H(P) + D_{KL}(P|Q)$)

ML uses: VAE loss (ELBO), knowledge distillation, policy optimization (PPO/TRPO).

Q47. Explain the Gaussian (Normal) distribution and why it appears everywhere.

AnswerWhy it's everywhereCLTMaximum entropyTractabilityConjugacy

Answer: $$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

Why it's everywhere: 1. CLT: Sum of many independent random variables → Gaussian 2. Maximum entropy: Given mean and variance, Gaussian has maximum entropy (least assumptions) 3. Tractability: Closed-form marginals, conditionals, products 4. Conjugacy: Gaussian prior + Gaussian likelihood → Gaussian posterior

Q48. What is the multivariate Gaussian?

AnswerML uses

Answer: $$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\mu)^T\Sigma^{-1}(\mathbf{x}-\mu)\right)$$

  • $\mu$: Mean vector ($d$-dimensional)
  • $\Sigma$: Covariance matrix ($d \times d$, symmetric PSD)
  • $\Sigma^{-1}$: Precision matrix

ML uses: GMMs, Gaussian processes, VAE latent space, Mahalanobis distance for anomaly detection.

Q49. What is the Poisson distribution and when do you use it?

AnswerUses

Answer: $$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

Models count of events in a fixed interval when events occur independently at rate $\lambda$.

Uses: Website visits per hour, number of clicks on an ad, defect counts, event-driven predictions. Mean = Variance = $\lambda$.

Q50. What is the Beta distribution?

AnswerUses

Answer: $$f(x; \alpha, \beta) = \frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha, \beta)}, \quad x \in [0,1]$$

A distribution over probabilities. Mean = $\frac{\alpha}{\alpha+\beta}$.

Uses: - Bayesian prior for Bernoulli parameter (e.g., conversion rate) - A/B testing: $\text{Beta}(\alpha + \text{successes}, \beta + \text{failures})$ - Thompson sampling in bandits

Q53. What is a p-value? Common misconceptions?

Answerassuming $H0$ is trueMisconceptions

Answer: The p-value is the probability of observing data as extreme as (or more extreme than) what was observed, assuming $H_0$ is true.

Misconceptions: - ❌ "p-value is the probability $H_0$ is true" — it's not, that would require Bayes' theorem - ❌ "p = 0.05 means 5% chance of being wrong" — wrong interpretation - ❌ "$p > 0.05$ means no effect" — it means insufficient evidence, not absence of effect - ❌ "Smaller p-value = larger effect" — p-value depends on sample size too

Q54. What is statistical power and how do you calculate sample size?

AnswerFactors increasing required $n$

Answer: Power = $P(\text{reject } H_0 | H_0 \text{ is false}) = 1 - \beta$. Typical target: 80%.

Sample size formula for two-sample t-test: $$n = \frac{2(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}$$

Where $\delta$ = minimum detectable effect, $\sigma$ = standard deviation.

Factors increasing required $n$: Smaller effect size, higher power, lower $\alpha$, higher variance.

Q56. What is a confidence interval?

AnswerCommon misconception

Answer: A 95% confidence interval means: if we repeated the experiment many times, 95% of the computed intervals would contain the true parameter.

$$CI = \bar{x} \pm z_{\alpha/2} \cdot \frac{s}{\sqrt{n}}$$

Common misconception: "There's a 95% probability the true value is in this interval" — the true value is fixed, not random. The interval is random.

Q60. What is ANOVA and when do you use it?

  • Two-way ANOVA: Two factors, interaction effects

Q61. Explain correlation vs causation.

AnswerWhy correlation ≠ causationConfoundingReverse causationSelection biasEstablishing causation

Answer: Correlation measures linear association. Causation means one variable directly affects another.

Why correlation ≠ causation: - Confounding: Ice cream sales and drowning deaths both increase in summer (confounder: temperature) - Reverse causation: Hospital visits and death are correlated, but hospitals don't cause death - Selection bias: Only observing a subset of the population

Establishing causation: RCTs (randomized controlled trials), instrumental variables, difference-in-differences, causal graphs (do-calculus).

For $m = 20$: $P(\text{≥1 false positive}) = 1 - 0.95^{20} = 0.64$ (64%!)

Q63. What is Bayesian inference?

AnswerProcess

Answer: Update beliefs about parameters using data:

$$P(\theta|D) = \frac{P(D|\theta) P(\theta)}{P(D)} \propto \text{likelihood} \times \text{prior}$$

Process: 1. Choose prior $P(\theta)$ — encodes domain knowledge 2. Observe data → compute likelihood $P(D|\theta)$ 3. Compute posterior $P(\theta|D)$ 4. Make predictions: $P(x_{\text{new}}|D) = \int P(x_{\text{new}}|\theta) P(\theta|D) d\theta$

Q67. What is Simpson's Paradox?

AnswerClassic exampleML lesson

Answer: A trend that appears in several groups reverses when the groups are combined.

Classic example: UC Berkeley admission data showed overall bias against women, but within each department, women had equal or higher admission rates. The paradox arose because women applied to more competitive departments.

ML lesson: Always check for confounders. Aggregate statistics can be misleading.

Q68. What is survival analysis?

Answer: Analyzes time-to-event data (churn, death, failure), handling censored observations (event hasn't happened yet).

Key concepts: - Survival function: $S(t) = P(T > t)$ - Hazard function: $h(t) = \lim_{\Delta t \to 0} \frac{P(t \leq T < t+\Delta t | T \geq t)}{\Delta t}$ - Kaplan-Meier estimator: Non-parametric survival curve - Cox proportional hazards: Semi-parametric model relating covariates to hazard

Q69. What is the Kolmogorov-Smirnov test?

Answer: Tests whether a sample comes from a specified distribution (one-sample) or whether two samples come from the same distribution (two-sample).

$$D = \max_x |F_n(x) - F_0(x)|$$

Where $F_n$ is the empirical CDF and $F_0$ is the reference CDF. Non-parametric, works for continuous distributions.

Q70. Explain the concept of sufficient statistics.

AnswerExamplesWhy it matters

Answer: A statistic $T(X)$ is sufficient for $\theta$ if $P(X|T(X), \theta) = P(X|T(X))$ — the statistic captures all information about $\theta$ from the data.

Examples: - For Gaussian with known $\sigma$: $\bar{x}$ is sufficient for $\mu$ - For Bernoulli: $\sum x_i$ is sufficient for $p$

Why it matters: You can reduce data to sufficient statistics without losing information. Neural network embeddings can be viewed as learned sufficient statistics.

Q71. How do you determine sample size for an A/B test?

AnswerTypical inputs

Answer: For a two-proportion test (e.g., conversion rates):

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot [p_1(1-p_1) + p_2(1-p_2)]}{(p_1 - p_2)^2}$$

Typical inputs: - $\alpha = 0.05$ ($z = 1.96$), Power = 0.80 ($z_\beta = 0.84$) - Baseline conversion = 5%, MDE (minimum detectable effect) = 0.5% (relative 10%)

from statsmodels.stats.power import NormalIndPower
analysis = NormalIndPower()
n = analysis.solve_power(effect_size=0.1, alpha=0.05, power=0.8, alternative='two-sided')

Q72. What is sequential testing?

AnswerO'Brien-FlemingPocockAlways-valid p-valuesBayesian sequentialAdvantage

Answer: Allows you to check results continuously without inflating the false positive rate. Methods: - O'Brien-Fleming: Conservative early boundaries, liberal later - Pocock: Equal boundaries at each look - Always-valid p-values: Based on martingale theory - Bayesian sequential: Update posterior continuously, stop when credible interval excludes null

Advantage: Can stop early if effect is large, saving time and resources.

Q74. What is the novelty effect?

AnswerSolutions

Answer: Users may engage more (or less) with a new feature simply because it's new. This inflates the initial treatment effect.

Solutions: - Run the test longer (2+ weeks minimum) - Analyze only users who joined after the experiment started - Look for effect decay over time - Use hold-back experiments (keep some users on the old version permanently)

Q75. Explain network effects in A/B testing.

Answer: When users interact (social networks, marketplaces), treating one user affects others → violation of SUTVA (Stable Unit Treatment Value Assumption).

Example: Testing a new messaging feature — treated user's messages affect control users.

Solutions: - Cluster randomization: Randomize at the cluster level (e.g., geographic regions) - Ego-network randomization: Treat entire friend groups - Switchback experiments: Alternate treatment over time periods

Q76. How do you handle ratio metrics (e.g., revenue per user)?

Q77. What is CUPED (Controlled-experiment Using Pre-Experiment Data)?

AnswerBenefit

Answer: Variance reduction technique using pre-experiment data as a covariate:

$$\hat{Y}{\text{adj}} = Y - \theta(X{\text{pre}} - \bar{X}_{\text{pre}})$$

Where $\theta = \frac{\text{Cov}(Y, X_{\text{pre}})}{\text{Var}(X_{\text{pre}})}$.

Benefit: Reduces variance by 50%+ → need smaller sample size → faster experiments. Used at Microsoft, Netflix, Uber.

Q79. What is an interaction effect in A/B testing?

AnswerDetection

Answer: When the effect of one treatment depends on another. E.g., a new UI works well on mobile but not desktop.

Detection: Run multi-factor experiments (2x2 design). Test interaction term in regression: $$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_{12} X_1 X_2 + \epsilon$$

If $\beta_{12}$ is significant, there's an interaction.

Q85. What is the difference between one-tailed and two-tailed tests?

AnswerOne-tailedTwo-tailedRule

Answer: - One-tailed: Tests if effect is in one direction ($H_1: \mu > \mu_0$). More power for that direction. - Two-tailed: Tests if effect exists in either direction ($H_1: \mu \neq \mu_0$). More conservative.

Rule: Use two-tailed unless you have a strong prior reason to test only one direction. In A/B testing, two-tailed is standard.

Q87. Explain L1 vs L2 regularization mathematically.

AnswerL1 (Lasso)sparsityL2 (Ridge)shrinkage but not zeroGeometric view

Answer: - L1 (Lasso): $\mathcal{L}_{\text{reg}} = \mathcal{L} + \lambda \sum_j |\theta_j|$ - Gradient: $\text{sign}(\theta_j)$ — constant push toward zero → exact zeros → sparsity

  • L2 (Ridge): $\mathcal{L}_{\text{reg}} = \mathcal{L} + \lambda \sum_j \theta_j^2$
  • Gradient: $2\theta_j$ — proportional push toward zero → shrinkage but not zero

Geometric view: L1's diamond-shaped constraint set has corners on axes (parameters hit zero). L2's circular constraint set doesn't.

Q88. What is information gain and how is it used in decision trees?

AnswerAlternatives

Answer: $$\text{IG}(S, A) = H(S) - \sum_{v \in \text{values}(A)} \frac{|S_v|}{|S|} H(S_v)$$

Where $H(S) = -\sum p_i \log_2 p_i$ is entropy.

Information gain measures the reduction in entropy after splitting on attribute $A$. Decision trees greedily select the attribute with highest IG at each node.

Alternatives: Gini impurity (CART): $G = 1 - \sum p_i^2$ — computationally simpler, similar results.

Q89. What is the Kullback-Leibler divergence in the context of neural networks?

AnswerVAE lossKnowledge distillationPPO/TRPOMutual information

Answer: In neural networks, KL divergence appears in: 1. VAE loss: $\mathcal{L} = \text{reconstruction} + D_{KL}(q(z|x) | p(z))$ — regularizes latent space toward $\mathcal{N}(0,1)$ 2. Knowledge distillation: Student network minimizes KL from teacher's soft labels 3. PPO/TRPO: Constrains policy updates: $D_{KL}(\pi_{\text{old}} | \pi_{\text{new}}) < \delta$ 4. Mutual information: $I(X;Y) = D_{KL}(P(X,Y) | P(X)P(Y))$

Q90. What is the Mahalanobis distance?

AnswerUses

Answer: $$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \mu)^T \Sigma^{-1} (\mathbf{x} - \mu)}$$

Unlike Euclidean distance, Mahalanobis distance accounts for correlations and different scales in the data.

Uses: - Anomaly/outlier detection (large $D_M$ = unusual point) - Cluster assignment in GMMs - Multivariate hypothesis testing (Hotelling's $T^2$)

Q91. Explain the relationship between entropy, cross-entropy, and KL divergence.

Answer: $$H(P, Q) = H(P) + D_{KL}(P | Q)$$

  • $H(P)$: Entropy of true distribution — fixed, irreducible uncertainty
  • $D_{KL}(P|Q)$: Extra bits needed because we use $Q$ instead of $P$
  • $H(P, Q)$: Total bits needed to encode data from $P$ using code from $Q$

Since $H(P)$ is constant during training, minimizing cross-entropy = minimizing KL divergence.

Q92. What is the Fisher Information Matrix?

AnswerCramér-Rao boundNatural gradientEWC (Elastic Weight Consolidation)

Answer: $$\mathcal{I}(\theta)_{ij} = -E\left[\frac{\partial^2 \log P(X|\theta)}{\partial \theta_i \partial \theta_j}\right]$$

The Fisher Information measures how much information data carries about parameters: - Cramér-Rao bound: $\text{Var}(\hat{\theta}) \geq \mathcal{I}(\theta)^{-1}$ — lower bound on estimator variance - Natural gradient: $\theta_{t+1} = \theta_t - \eta \mathcal{I}^{-1} \nabla \mathcal{L}$ — invariant to parameterization - EWC (Elastic Weight Consolidation): Uses Fisher to identify important weights for continual learning

Q93. What is the EM algorithm?

AnswerE-stepM-stepApplications

Answer: Expectation-Maximization finds MLE when data has latent variables:

  1. E-step: Compute expected value of latent variables given current parameters $$Q(\theta | \theta^{(t)}) = E_{Z|X,\theta^{(t)}}[\log P(X, Z | \theta)]$$

  2. M-step: Maximize $Q$ with respect to $\theta$ $$\theta^{(t+1)} = \arg\max_\theta Q(\theta | \theta^{(t)})$$

Applications: GMM fitting, hidden Markov models, matrix factorization, missing data imputation.

Q94. What is the curse of dimensionality?

AnswerImpact on MLRule of thumb

Answer: As dimensions increase: - Volume of space grows exponentially → data becomes sparse - Distance between nearest and farthest neighbors converges → distance metrics lose meaning - Number of samples needed grows exponentially to maintain density

Impact on ML: - KNN fails in high dimensions - Kernel density estimation breaks down - Need dimensionality reduction (PCA, t-SNE, UMAP)

Rule of thumb: Need $O(10^d)$ samples for $d$ dimensions (for uniform coverage).

Q95. What is mutual information?

Measures how much knowing $Y$ reduces uncertainty about $X$. Unlike correlation, captures nonlinear dependencies.

ML uses: Feature selection (select features with high MI with target), InfoGAN, MINE (Mutual Information Neural Estimation).

Q96. What is the Gini coefficient/impurity?

Where $p_i$ is the proportion of class $i$. - $G = 0$: Pure node (all one class) - $G = 0.5$: Maximum impurity for binary (50-50 split)

Used in CART decision trees. Compared to entropy, Gini is computationally cheaper and behaves similarly in practice.

Q98. Explain the reparameterization trick in VAEs.

AnswerTrick

Answer: In VAEs, we need gradients through sampling from $z \sim \mathcal{N}(\mu, \sigma^2)$. But sampling is non-differentiable.

Trick: Sample $\epsilon \sim \mathcal{N}(0, 1)$, then $z = \mu + \sigma \cdot \epsilon$.

Now the gradient flows through $\mu$ and $\sigma$ (deterministic operations), while the randomness is in $\epsilon$ (independent of parameters).
