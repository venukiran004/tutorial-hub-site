Mathematics for ML/DL — Linear Algebra, Calculus & Optimization

Scope: Linear algebra essentials (vectors, matrices, eigenvalues), matrix decompositions (SVD, PCA), calculus for ML (derivatives, chain rule), multivariable calculus & gradients, optimization theory, convex optimization, probability refresher, information theory, numerical methods, and practical NumPy implementations.

1. Linear Algebra Essentials
•

Vectors

Vector: ordered list of numbers (point in n-dimensional space)
x = [x₁, x₂, ..., xₙ]ᵀ ∈ ℝⁿ

Operations:
- Addition: x + y = [x₁+y₁, x₂+y₂, ...]
- Scalar multiplication: αx = [αx₁, αx₂, ...]
- Dot product: x·y = Σ xᵢyᵢ = ||x|| ||y|| cos(θ)
- Norm: ||x||₂ = √(Σ xᵢ²)   (L2/Euclidean norm)
         ||x||₁ = Σ |xᵢ|     (L1/Manhattan norm)
•

Matrices

Matrix: 2D array of numbers, A ∈ ℝᵐˣⁿ (m rows, n columns)

Key types:
- Identity (I): diagonal = 1, rest = 0 → AI = IA = A
- Diagonal: non-zero only on diagonal
- Symmetric: A = Aᵀ → covariance matrices
- Orthogonal: AᵀA = AAᵀ = I → rotation matrices
- Positive definite: xᵀAx > 0 for all x ≠ 0
•

Matrix Operations

Multiplication: C = AB where C_ij = Σ_k A_ik B_kj
- (m×n)(n×p) = (m×p) — inner dimensions must match
- NOT commutative: AB ≠ BA in general
- Associative: (AB)C = A(BC)

Transpose: (AB)ᵀ = BᵀAᵀ
Inverse: AA⁻¹ = A⁻¹A = I (only for square, non-singular matrices)
Trace: tr(A) = Σ A_ii (sum of diagonal elements)
Determinant: det(A) — scaling factor of linear transformation
Rank: rank(A) = number of linearly independent rows (or columns)
  - rank(A) ≤ min(m, n) for A ∈ ℝᵐˣⁿ
  - Full rank: rank(A) = min(m, n) → invertible (if square)
  - Rank-deficient: linearly dependent rows/columns exist
  - Rank-nullity theorem: rank(A) + nullity(A) = n
  - ML use: Low-rank approximations (LoRA, PCA, matrix factorization)
•

2. Matrix Decompositions
•

Eigendecomposition

Av = λv

A: square matrix
v: eigenvector (direction unchanged by transformation)
λ: eigenvalue (scaling factor)

A = VΛV⁻¹  where V = [v₁|v₂|...|vₙ], Λ = diag(λ₁, λ₂, ..., λₙ)

ML uses:
- PCA: eigenvectors of covariance matrix = principal components
- PageRank: dominant eigenvector of link matrix
- Stability analysis: |λ| < 1 → contracting, |λ| > 1 → expanding
•

Singular Value Decomposition (SVD)

A = UΣVᵀ

U ∈ ℝᵐˣᵐ: left singular vectors (orthogonal)
Σ ∈ ℝᵐˣⁿ: singular values (diagonal, non-negative, sorted)
V ∈ ℝⁿˣⁿ: right singular vectors (orthogonal)

Low-rank approximation:
A_k = Σ_{i=1}^{k} σᵢ uᵢ vᵢᵀ  (keep top k singular values)

ML uses:
- PCA (SVD of centered data matrix)
- Recommendation systems (matrix factorization)
- LSA (Latent Semantic Analysis)
- Model compression (low-rank weight approximation)
- LoRA: W = W₀ + BA where B ∈ ℝᵈˣʳ, A ∈ ℝʳˣᵈ (rank r)
•

Cholesky Decomposition

A = LLᵀ  (for symmetric positive definite matrices)

L: lower triangular matrix

Uses:
- Efficient covariance matrix operations
- Sampling from multivariate normal distribution
- Solving linear systems efficiently
•

QR Decomposition

A = QR

Q: orthogonal matrix
R: upper triangular matrix

Uses:
- Solving least squares problems
- Numerical stability in linear regression
- Gram-Schmidt orthogonalization
3. Calculus for ML
•

Derivatives

f'(x) = lim_{h→0} [f(x+h) - f(x)] / h

Common derivatives:
- d/dx(xⁿ) = nxⁿ⁻¹
- d/dx(eˣ) = eˣ
- d/dx(ln x) = 1/x
- d/dx(sin x) = cos x
- d/dx(σ(x)) = σ(x)(1 - σ(x))    # sigmoid
- d/dx(tanh(x)) = 1 - tanh²(x)
- d/dx(ReLU(x)) = {1 if x > 0, 0 if x ≤ 0}
•

Chain Rule (Foundation of Backpropagation)

If y = f(g(x)), then dy/dx = f'(g(x)) · g'(x)

Neural network example:
z = Wx + b       → dz/dW = x, dz/db = 1
a = σ(z)         → da/dz = σ(z)(1-σ(z))
L = loss(a, y)   → dL/da = loss'(a, y)

Backprop: dL/dW = dL/da · da/dz · dz/dW  (chain rule!)
•

Taylor Series

Taylor expansion of f(x) around point a:

f(x) = f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + f'''(a)(x-a)³/3! + ...
     = Σ_{n=0}^{∞} f⁽ⁿ⁾(a)/n! × (x-a)ⁿ

First-order approximation:  f(x) ≈ f(a) + f'(a)(x-a)
  → This IS gradient descent! (linear approximation of loss)

Second-order approximation: f(x) ≈ f(a) + f'(a)(x-a) + ½f''(a)(x-a)²
  → This IS Newton's method! (quadratic approximation of loss)

Multivariate Taylor expansion:
  f(x) ≈ f(a) + ∇f(a)ᵀ(x-a) + ½(x-a)ᵀH(a)(x-a)
  where H = Hessian matrix

ML connections:
- Gradient descent uses 1st-order Taylor approximation
- Newton's method uses 2nd-order Taylor approximation
- Loss landscape analysis uses quadratic Taylor expansion
- Laplace approximation: approximate posterior with Gaussian
  using 2nd-order Taylor around the MAP estimate
•

4. Multivariable Calculus & Gradients
•

Gradient

∇f(x) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]ᵀ

- Points in direction of steepest ascent
- Magnitude = rate of steepest ascent
- Gradient descent: x ← x - α∇f(x)  (move against gradient)
•

Jacobian Matrix

For f: ℝⁿ → ℝᵐ, the Jacobian J ∈ ℝᵐˣⁿ:

J_ij = ∂fᵢ/∂xⱼ

Used in: backpropagation through vector-valued functions
•

Hessian Matrix

H_ij = ∂²f/∂xᵢ∂xⱼ  (matrix of second derivatives)

Properties:
- Symmetric (if f is smooth)
- Positive definite → local minimum (convex)
- Negative definite → local maximum
- Indefinite → saddle point

ML uses:
- Newton's method: x ← x - H⁻¹∇f
- Understanding loss landscape curvature
- Natural gradient methods
•

Matrix Calculus

∂/∂x (aᵀx) = a
∂/∂x (xᵀAx) = (A + Aᵀ)x = 2Ax (if A symmetric)
∂/∂X (tr(AXB)) = AᵀBᵀ

Normal equation derivation:
L = ||Xw - y||² = (Xw-y)ᵀ(Xw-y) = wᵀXᵀXw - 2wᵀXᵀy + yᵀy
∂L/∂w = 2XᵀXw - 2Xᵀy = 0
→ w* = (XᵀX)⁻¹Xᵀy

•

Convergence Conditions

Convex function: One global minimum, GD converges with proper α
  - α < 2/L (L = Lipschitz constant of gradient)
  - Rate: O(1/t) for GD, O(1/t²) for accelerated

Non-convex (DL): Multiple local minima, saddle points
  - No convergence guarantee to global optimum
  - Saddle points more problematic than local minima in high dimensions
  - SGD noise helps escape saddle points
6. Convex Optimization
•

Convex Sets and Functions

Convex set: Line between any two points stays in set
Convex function: f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y) for λ ∈ [0,1]

ML convex losses: MSE, cross-entropy (in model params, not always in θ)
ML non-convex: Neural network loss functions
•

Lagrangian and Duality

Primal: min f(x) subject to gᵢ(x) ≤ 0, hⱼ(x) = 0

Lagrangian: L(x, λ, ν) = f(x) + Σ λᵢgᵢ(x) + Σ νⱼhⱼ(x)
Dual: max_{λ≥0,ν} min_x L(x, λ, ν)

KKT conditions (necessary for optimality):
1. Stationarity: ∇_x L = 0
2. Primal feasibility: gᵢ(x) ≤ 0, hⱼ(x) = 0
3. Dual feasibility: λᵢ ≥ 0
4. Complementary slackness: λᵢgᵢ(x) = 0

ML example: SVM uses KKT conditions — support vectors have λᵢ > 0
7. Probability Refresher for ML
•

Key Distributions in ML

Bernoulli(p):  Binary classification outcomes
Binomial(n,p): Number of successes in n trials
Categorical:   Multi-class classification
Normal(μ,σ²): Continuous features, noise, weight initialization
Multivariate Normal(μ,Σ): Feature vectors, latent spaces

MLE for Normal:
μ̂ = (1/n) Σ xᵢ     (sample mean)
σ̂² = (1/n) Σ (xᵢ-μ̂)² (sample variance)
•

Bayes' Theorem

P(θ|D) = P(D|θ) P(θ) / P(D)

P(θ):    Prior (belief before seeing data)
P(D|θ):  Likelihood (probability of data given parameters)
P(θ|D):  Posterior (updated belief after seeing data)
P(D):    Evidence (normalizing constant)

ML applications:
- Naïve Bayes classifier
- Bayesian neural networks
- MAP estimation: θ_MAP = argmax P(θ|D) = argmax [log P(D|θ) + log P(θ)]
  → L2 regularization = Gaussian prior on weights
  → L1 regularization = Laplacian prior on weights
•

Expectation and Variance

E[X] = Σ x P(x) or ∫ x f(x) dx
Var(X) = E[(X-μ)²] = E[X²] - (E[X])²

Properties:
E[aX + b] = aE[X] + b
Var(aX + b) = a²Var(X)
Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)

Bias-variance decomposition:
E[(ŷ - y)²] = Bias²(ŷ) + Var(ŷ) + σ²  (irreducible noise)
8. Information Theory
•

Key Concepts

Entropy: H(X) = -Σ P(x) log P(x)
- Measures uncertainty / information content
- Maximum for uniform distribution
- Used in: decision tree splitting criteria

Cross-entropy: H(P, Q) = -Σ P(x) log Q(x)
- Measures difference between two distributions
- Classification loss function
- H(P, Q) = H(P) + D_KL(P||Q)

KL Divergence: D_KL(P||Q) = Σ P(x) log(P(x)/Q(x))
- Measures "distance" between distributions (not symmetric)
- Used in: VAE loss, RLHF KL penalty, knowledge distillation

Mutual Information: I(X;Y) = H(X) - H(X|Y) = D_KL(P(X,Y) || P(X)P(Y))
- Measures shared information
- Used in: feature selection, representation learning
•

9. Numerical Methods
•

Floating Point Precision

FP32: 1 sign + 8 exponent + 23 mantissa = 32 bits
FP16: 1 sign + 5 exponent + 10 mantissa = 16 bits
BF16: 1 sign + 8 exponent + 7 mantissa  = 16 bits (larger range)
FP8:  1 sign + 4 exponent + 3 mantissa  = 8 bits

Issues:
- Overflow/underflow in softmax → use log-sum-exp trick
- Catastrophic cancellation with large/small numbers
- Gradient vanishing with FP16 → mixed precision (loss scaling)
•

Numerical Stability Tricks

# Log-sum-exp trick (prevent overflow in softmax)
def log_sum_exp(x):
    c = x.max()
    return c + np.log(np.sum(np.exp(x - c)))

def stable_softmax(x):
    x_shifted = x - np.max(x)
    exp_x = np.exp(x_shifted)
    return exp_x / np.sum(exp_x)

# Stable log(sigmoid(x))
def log_sigmoid(x):
    return -np.logaddexp(0, -x)  # instead of np.log(sigmoid(x))

# Stable binary cross-entropy
def bce_loss(y, p):
    return -(y * np.log(p + 1e-8) + (1-y) * np.log(1 - p + 1e-8))

Gradient Computation Example

# Numerical gradient (for verification)
def numerical_gradient(f, x, h=1e-5):
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x_plus = x.copy(); x_plus[i] += h
        x_minus = x.copy(); x_minus[i] -= h
        grad[i] = (f(x_plus) - f(x_minus)) / (2 * h)
    return grad

# Verify against analytical gradient
def mse_loss(w, X, y):
    return np.mean((X @ w - y) ** 2)

def mse_gradient(w, X, y):
    return 2 * X.T @ (X @ w - y) / len(y)

# Check: numerical_gradient(lambda w: mse_loss(w, X, y), w) ≈ mse_gradient(w, X, y)
11. Constrained Optimization & KKT Conditions
•

Problem Formulation

General Constrained Optimization:

    minimize    f(x)              ← objective function
    subject to  gᵢ(x) ≤ 0        ← inequality constraints (i = 1,...,m)
                hⱼ(x) = 0        ← equality constraints   (j = 1,...,p)
•

The Lagrangian

Combines the objective with constraints into a single unconstrained function:

L(x, λ, μ) = f(x) + m∑i=1 λi gi(x) + p∑j=1 μj hj(x)
  • λi ≥ 0 — Lagrange multipliers for inequality constraints
  • μj — Lagrange multipliers for equality constraints (unconstrained sign)
•

KKT Conditions (Karush-Kuhn-Tucker)

Necessary conditions for optimality in constrained problems:

  1. Stationarity: ∇ₓL = ∇f(x*) + Σλᵢ∇gᵢ(x*) + Σμⱼ∇hⱼ(x*) = 0
  2. Primal Feasibility: gᵢ(x*) ≤ 0, hⱼ(x*) = 0
  3. Dual Feasibility: λᵢ ≥ 0
  4. Complementary Slackness: λᵢ · gᵢ(x*) = 0 (either λᵢ=0 or gᵢ is active)

Complementary slackness means: if a constraint is inactive (slack), its multiplier must be zero. If the multiplier is positive, the constraint must be tight (active/binding).

•

Geometric Intuition

At the optimum x*, the gradient of f must be a linear combination
of the gradients of the active constraints:

    -∇f(x*) = Σ λᵢ ∇gᵢ(x*)    (for active inequality constraints)

Geometrically: you can't improve f without violating a constraint.
The gradient of f is "blocked" by the constraint boundaries.
•

SVM as Constrained Optimization

SVM Primal Problem:
    minimize    ½‖w‖²
    subject to  yᵢ(w·xᵢ + b) ≥ 1    for all i

Lagrangian:
    L(w,b,α) = ½‖w‖² - Σαᵢ[yᵢ(w·xᵢ + b) - 1]

KKT → Stationarity:
    ∂L/∂w = 0  →  w = Σαᵢyᵢxᵢ        (w is a linear combo of support vectors)
    ∂L/∂b = 0  →  Σαᵢyᵢ = 0

Complementary Slackness:
    αᵢ[yᵢ(w·xᵢ + b) - 1] = 0
    → αᵢ > 0 only for points ON the margin (support vectors)

Dual Problem (substitute back):
    maximize  Σαᵢ - ½ΣΣ αᵢαⱼyᵢyⱼ(xᵢ·xⱼ)
    subject to αᵢ ≥ 0, Σαᵢyᵢ = 0
•

Practical Python: Constrained Optimization with SciPy

import numpy as np
from scipy.optimize import minimize

# Minimize f(x) = x₀² + x₁²  subject to  x₀ + x₁ = 1,  x₀ ≥ 0.2
def objective(x):
    return x[0]**2 + x[1]**2

constraints = [
    {'type': 'eq',   'fun': lambda x: x[0] + x[1] - 1},    # equality
    {'type': 'ineq', 'fun': lambda x: x[0] - 0.2},          # x₀ ≥ 0.2
]

result = minimize(objective, x0=[0.5, 0.5], method='SLSQP', constraints=constraints)
print(f"Optimal x: {result.x}")   # [0.5, 0.5] — equality forces sum=1
print(f"Optimal f: {result.fun}")  # 0.5

# With bounds
from scipy.optimize import LinearConstraint, Bounds
bounds = Bounds(lb=[0, 0], ub=[np.inf, np.inf])  # non-negative
result = minimize(objective, x0=[1, 1], method='trust-constr',
                  constraints={'type': 'eq', 'fun': lambda x: x[0] + x[1] - 1},
                  bounds=bounds)
print(f"Bounded optimal: {result.x}")
12. Concentration Inequalities

Why this matters for ML: Concentration inequalities bound how far a random variable deviates from its expected value. They are the backbone of generalization bounds, PAC learning theory, and sample complexity analysis.

•

Markov's Inequality

For non-negative random variable X and a > 0:

    P(X ≥ a) ≤ E[X] / a

Weakest bound — only requires non-negativity and finite mean.
Example: If avg training loss = 0.1, P(loss ≥ 1) ≤ 0.1.
•

Chebyshev's Inequality

For any random variable X with finite mean μ and variance σ²:

    P(|X - μ| ≥ kσ) ≤ 1/k²

Stronger than Markov — uses variance information.
Example: P(|X - μ| ≥ 3σ) ≤ 1/9 ≈ 11.1%  (compare to Gaussian: 0.3%)
•

Hoeffding's Inequality

For n independent bounded random variables Xᵢ ∈ [aᵢ, bᵢ]:

    P(|X̄ - E[X̄]| ≥ t) ≤ 2·exp(-2n²t² / Σ(bᵢ-aᵢ)²)

For identically bounded [a,b]:
    P(|X̄ - μ| ≥ t) ≤ 2·exp(-2nt² / (b-a)²)

Proof sketch: Apply Markov to exp(s(X̄ - μ)), optimize over s.

ML Application — Generalization Bound:
    With probability ≥ 1-δ:
    |training_error - true_error| ≤ √(ln(2/δ) / (2n))
    → Need n = O(1/ε²) samples for ε-accurate estimate.
•

Chernoff Bounds

For sum S = ΣXᵢ of independent Bernoulli(pᵢ), μ = E[S]:

    P(S ≥ (1+δ)μ) ≤ (eᵟ / (1+δ)^(1+δ))^μ      (upper tail)
    P(S ≤ (1-δ)μ) ≤ exp(-μδ²/2)                  (lower tail)

Tighter than Hoeffding for Bernoulli sums.
Used in randomized algorithms and boosting analysis.
•

McDiarmid's Inequality

If f(x₁,...,xₙ) satisfies bounded differences:
    |f(x₁,...,xᵢ,...,xₙ) - f(x₁,...,xᵢ',...,xₙ)| ≤ cᵢ

Then:
    P(f - E[f] ≥ t) ≤ exp(-2t² / Σcᵢ²)

Generalizes Hoeffding to functions of independent variables.
ML Application: Bounds on empirical risk — changing one sample
changes empirical risk by at most 1/n, so cᵢ = 1/n.
•

Connection to PAC Learning & Sample Complexity

PAC (Probably Approximately Correct) Learning:
    A concept is PAC-learnable if, for any ε, δ > 0:
    with n ≥ n₀(ε, δ) samples, the learner outputs h such that
    P(error(h) ≤ ε) ≥ 1 - δ

Using Hoeffding + Union Bound over hypothesis class H:
    n ≥ (1/2ε²) · ln(2|H|/δ)

For infinite |H|, replace ln|H| with VC dimension d:
    n = O(d/ε² · ln(1/ε) + ln(1/δ)/ε²)

Key insight: More complex models (larger d) need more samples
to generalize — this IS the bias-variance tradeoff formalized.

  2. Explain SVD and its ML applications. A = UΣVᵀ decomposes any matrix into rotation × scaling × rotation. Used in PCA (SVD of data matrix), recommender systems (matrix factorization), LoRA (low-rank adaptation), and latent semantic analysis.

  3. Derive the gradient for linear regression. L = ‖Xw-y‖², ∇L = 2Xᵀ(Xw-y). Setting to zero: w* = (XᵀX)⁻¹Xᵀy (normal equation). GD: w ← w - α·2Xᵀ(Xw-y)/n.

  4. What is the chain rule and how does backprop use it? Chain rule: d(f∘g)/dx = f'(g(x))·g'(x). Backprop applies chain rule layer by layer: dL/dW_i = dL/da_n · da_n/dz_n · ... · dz_i/dW_i. Computed backwards from loss efficiently.

  5. Why does L1 produce sparse solutions but L2 doesn't? L1 gradient is constant (±λ), pushing weights exactly to zero. L2 gradient is proportional to weight (2λw), shrinking but never reaching zero. Geometrically, L1 constraint diamond has corners on axes.

  6. What is KL divergence? D_KL(P‖Q) = Σ P(x) log(P(x)/Q(x)). Measures information lost when Q approximates P. Non-symmetric, non-negative. Used in VAEs, RLHF KL penalty, knowledge distillation.

  7. Explain the bias-variance tradeoff mathematically. E[(ŷ-y)²] = Bias² + Variance + Noise. High bias = underfitting (model too simple). High variance = overfitting (model too complex). Regularization increases bias, decreases variance.

  8. Why use log-sum-exp trick? Direct softmax: exp(1000) overflows. Subtracting max: exp(x - max(x)) is numerically stable and mathematically equivalent because softmax is shift-invariant.

  9. What makes a matrix positive definite? xᵀAx > 0 for all nonzero x. Equivalent: all eigenvalues positive. ML relevance: covariance matrices are PSD, loss Hessian is PD at a minimum.

  10. How does eigendecomposition relate to PCA? PCA finds directions of maximum variance. These are eigenvectors of covariance matrix Σ = XᵀX/(n-1). Eigenvalues = variance explained. Top k eigenvectors = k principal components.
