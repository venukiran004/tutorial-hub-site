NLP & Transformers

The architecture everything else is built on. Classical NLP foundations, the transformer end to end with worked numeric examples, multimodal models, runnable programs, and the interview bank.

If you remember one thing: a transformer block is attention (mix across tokens) + a feed-forward net (think per token), each wrapped in a residual. Everything since 2017 is a cheaper or more stable version of that.
