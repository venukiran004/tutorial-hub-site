Multimodal Fusion Strategies

Early Fusion: Concatenate raw inputs → shared encoder
├── Simple but may miss modality-specific patterns

Late Fusion: Separate encoders → combine at decision level
├── Preserves modality-specific features, easy to train

Cross-Attention Fusion: Attend across modality representations
├── Rich interaction, used in most modern VLMs

Bottleneck Fusion: Compress via learnable queries (Perceiver, Q-Former)
├── Efficient, handles variable-length inputs
2. CLIP and Contrastive Learning
•

CLIP Architecture

Image Encoder (ViT-L/14 or ResNet)  →  Image embedding (d=768)
                                              ↕ cosine similarity
Text Encoder (Transformer)           →  Text embedding (d=768)

Training: Contrastive loss on 400M (image, text) pairs
- Matching pairs → high similarity
- Non-matching pairs → low similarity
•

CLIP Training Objective

# InfoNCE / NT-Xent loss
def clip_loss(image_embeddings, text_embeddings, temperature=0.07):
    # Normalize
    image_embeddings = F.normalize(image_embeddings, dim=-1)
    text_embeddings = F.normalize(text_embeddings, dim=-1)
    
    # Cosine similarity matrix
    logits = image_embeddings @ text_embeddings.T / temperature
    
    # Labels: diagonal elements are positive pairs
    labels = torch.arange(len(logits)).to(logits.device)
    
    # Symmetric loss
    loss_i2t = F.cross_entropy(logits, labels)
    loss_t2i = F.cross_entropy(logits.T, labels)
    
    return (loss_i2t + loss_t2i) / 2

CLIP Zero-Shot Classification

import clip
from PIL import Image

model, preprocess = clip.load("ViT-B/32")

image = preprocess(Image.open("photo.jpg")).unsqueeze(0)
text = clip.tokenize(["a photo of a cat", "a photo of a dog", "a photo of a bird"])

with torch.no_grad():
    image_features = model.encode_image(image)
    text_features = model.encode_text(text)
    
    similarity = (image_features @ text_features.T).softmax(dim=-1)
    print(similarity)  # e.g., [0.92, 0.05, 0.03]

Flamingo (DeepMind, 2022)

Few-shot multimodal learningKey innovationsPerceiver ResamplerGated Cross-AttentionInterleaved image-text trainingArchitecture

Few-shot multimodal learning — can handle new tasks with just a few examples in context.

Key innovations: - Perceiver Resampler: Converts variable-length visual features into fixed number of visual tokens - Gated Cross-Attention: Inserted into frozen LLM layers; visual tokens attend to text - Interleaved image-text training: Trained on sequences mixing images and text from the web

Architecture: Vision Encoder (frozen) → Perceiver Resampler → Gated Cross-Attention Dense layers interleaved with frozen LLM

Impact: Demonstrated that freezing both vision encoder and LLM while training only the connecting modules (cross-attention, perceiver) is effective.

Stable Diffusion Architecture

latent spaceThree componentsVAE (Variational Autoencoder)U-NetText Encoder (CLIP)Diffusion Process

Operates in latent space (not pixel space) for efficiency:

Text Prompt → CLIP Text Encoder → Text Embeddings
                                        ↓
Image → VAE Encoder → Latent (z)  →  U-Net (denoising)  →  VAE Decoder → Generated Image
                                        ↑
                                   Noise Schedule (timesteps)

Three components: 1. VAE (Variational Autoencoder): Compresses images to latent space (64×64 instead of 512×512). Decoder reconstructs from latent. 2. U-Net: Iterative denoising network. Takes noisy latent + text embedding + timestep → predicts noise. Uses cross-attention to condition on text. 3. Text Encoder (CLIP): Converts text prompt to embeddings that guide the U-Net via cross-attention.

Diffusion Process: - Forward (training): Gradually add Gaussian noise to latent: $z_t = \sqrt{\bar{\alpha}t} z_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$ - Reverse (inference): Start from pure noise $z_T$, iteratively denoise using U-Net predictions - Classifier-Free Guidance (CFG): $\hat{\epsilon} = \epsilon{uncond} + w(\epsilon_{cond} - \epsilon_{uncond})$, where $w$ is guidance scale

Variants: SDXL (larger U-Net, two text encoders), SD 3 (DiT architecture with flow matching)

•

ControlNet for Guided Generation

Input: Condition (edge map, depth map, pose) + Text prompt
→ ControlNet processes condition
→ Injected into Stable Diffusion U-Net via zero-convolution
→ Generated image follows both text and spatial condition

ImageBind

Key insight: Images appear in all modality pairs
→ Bind all modalities through image as anchor

image ↔ text    (CLIP pairs)
image ↔ audio   (video + audio pairs)
image ↔ depth   (RGBD pairs)
image ↔ thermal (thermal camera pairs)
image ↔ IMU     (video + motion pairs)

Result: All 6 modalities share one embedding space
→ Audio query can retrieve images (even though never trained together!)

Traditional: Parse PDF → extract text → embed text → retrieval

Multimodal Chat with OpenAI

from openai import OpenAI
import base64

client = OpenAI()

# Encode image
with open("image.png", "rb") as f:
    image_b64 = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "What's in this image? Extract any text you see."},
            {"type": "image_url", "image_url": {
                "url": f"data:image/png;base64,{image_b64}",
                "detail": "high"  # low, high, auto
            }}
        ]
    }],
    max_tokens=1000
)
print(response.choices[0].message.content)

Building a Multimodal Search Engine

from sentence_transformers import SentenceTransformer
import chromadb

# Use CLIP-based model for unified embeddings
model = SentenceTransformer("clip-ViT-B-32")

# Index images
image_embeddings = model.encode([Image.open(f) for f in image_files])
text_embeddings = model.encode(text_descriptions)

# Create vector store
client = chromadb.Client()
collection = client.create_collection("multimodal_search")

# Add images with CLIP embeddings
collection.add(
    embeddings=image_embeddings.tolist(),
    documents=text_descriptions,
    metadatas=[{"type": "image", "path": f} for f in image_files],
    ids=[f"img_{i}" for i in range(len(image_files))]
)

# Search with text query
query_embedding = model.encode(["a sunset over the ocean"])
results = collection.query(query_embeddings=query_embedding.tolist(), n_results=5)

12. Interview Questions
•

Conceptual

How does CLIP work?LLaVA architecture?Multimodal RAG challenges?How do VLMs handle images?CLIP vs LLaVA — when to use?How does Whisper work?

  1. How does CLIP work? Contrastive learning on 400M image-text pairs. Dual encoders produce aligned embeddings. InfoNCE loss pulls matching pairs close, pushes non-matching apart.

  2. LLaVA architecture? CLIP ViT encodes image into patch tokens, linear projector maps them to LLM space, concatenated with text tokens, processed by LLaMA/Vicuna. Two-stage training: alignment then instruction tuning.

  3. Multimodal RAG challenges? Parsing diverse document formats (tables, charts), creating unified embeddings across modalities, source attribution for images, handling large images efficiently.

  4. How do VLMs handle images? Convert images to tokens: ViT splits into patches (typically 14×14 or 16×16), each patch → visual token. These tokens are projected into LLM embedding space via adapter/projector.

  5. CLIP vs LLaVA — when to use? CLIP: retrieval, classification, zero-shot tasks (no generation). LLaVA: visual QA, captioning, reasoning, conversation (generative tasks).

  6. How does Whisper work? Encoder-decoder transformer trained on 680K hours of audio. Mel spectrogram input → encoder → cross-attention → decoder generates text tokens. Handles transcription + translation.

  7. What is ImageBind? Binds 6 modalities (image, text, audio, depth, thermal, IMU) through images as anchor. Enables cross-modal retrieval even between modalities never trained together.

  8. ColPali vs traditional document retrieval? Traditional: OCR → text extraction → text embedding → retrieval (error-prone). ColPali: embed document pages as images directly → late interaction retrieval (robust, layout-aware).

  9. Challenges in video generation? Temporal consistency, motion coherence, high compute (3D attention over space+time), long-duration generation, physics understanding, evaluation metrics.

  10. How to build multimodal search? Use CLIP-based model for unified image-text embeddings. Index images with their CLIP embeddings + text descriptions. Query with text/image → find most similar items across modalities via cosine similarity.
