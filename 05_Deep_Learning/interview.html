Q1. What is a neural network? Formalise it mathematically.

A neural network is a parameterised function $f_\theta: \mathbb{R}^{d_{in}} \to \mathbb{R}^{d_{out}}$ composed of $L$ layers:

$$\mathbf{h}^{(0)} = \mathbf{x}$$ $$\mathbf{z}^{(l)} = \mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}$$ $$\mathbf{h}^{(l)} = \sigma(\mathbf{z}^{(l)})$$

where $\mathbf{W}^{(l)}\in\mathbb{R}^{n_l\times n_{l-1}}$, $\mathbf{b}^{(l)}\in\mathbb{R}^{n_l}$, $\sigma$ is element-wise activation. The output: $\hat{\mathbf{y}} = \mathbf{h}^{(L)}$.

Total parameters: $\sum_{l=1}^L (n_l \cdot n_{l-1} + n_l)$.

•

Q2. Why does depth help? Expressiveness theory.

Depth separation theoremhierarchical feature composition

A shallow (1-hidden-layer) network needs exponentially many neurons to represent certain functions that a deep network with $O(\text{poly}(d))$ neurons can represent.

Depth separation theorem (Eldan & Shamir, 2016): There exist functions computable by depth-3 networks of polynomial size that require exponential size depth-2 networks.

In practice: depth provides hierarchical feature composition: - Layer 1: edges (Gabor-like filters) - Layer 2: shapes (curves, corners) - Layer 3: parts (eyes, wheels) - Layer L: semantic concepts

Q3. Derive backpropagation mathematically. Show full chain rule derivation.

GoalDefine error signal (delta)Output layer ($l=L$)Backward pass (recursion)Weight gradientsUpdate

Goal: Compute $\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}}$ and $\frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(l)}}$ for all layers.

Define error signal (delta): $$\boldsymbol\delta^{(l)} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{(l)}}$$

Output layer ($l=L$): $$\boldsymbol\delta^{(L)} = \frac{\partial \mathcal{L}}{\partial \mathbf{h}^{(L)}} \odot \sigma'(\mathbf{z}^{(L)})$$

For MSE: $\frac{\partial \mathcal{L}}{\partial \mathbf{h}^{(L)}} = \hat{\mathbf{y}} - \mathbf{y}$

Backward pass (recursion): $$\boldsymbol\delta^{(l)} = \left(\mathbf{W}^{(l+1)T}\boldsymbol\delta^{(l+1)}\right) \odot \sigma'(\mathbf{z}^{(l)})$$

Weight gradients: $$\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}} = \boldsymbol\delta^{(l)} \cdot (\mathbf{h}^{(l-1)})^T, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(l)}} = \boldsymbol\delta^{(l)}$$

Update: $$\mathbf{W}^{(l)} \leftarrow \mathbf{W}^{(l)} - \eta \frac{\partial\mathcal{L}}{\partial\mathbf{W}^{(l)}}$$

Computational complexity: $O(W)$ per sample for both forward and backward pass, where $W$ = total parameters. Backprop is exactly 2× forward pass cost.

Q4. Gradient descent and learning rate — convergence analysis.

Gradient descent updateLearning rate impact

Gradient descent update: $$\boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta \nabla_{\boldsymbol\theta}\mathcal{L}(\boldsymbol\theta_t)$$

Convergence for $\beta$-smooth convex functions (Lipschitz gradient): After $T$ steps: $\mathcal{L}(\boldsymbol\theta_T) - \mathcal{L}^ \leq \frac{||\boldsymbol\theta_0-\boldsymbol\theta^||^2}{2\eta T}$ with $\eta = 1/\beta$.

Rate: $O(1/T)$ for convex, $O(\rho^T)$ for strongly convex.

Learning rate impact: - $\eta > 2/\beta$: divergence (overshooting) - $\eta = 1/\beta$: optimal step = Lipschitz constant - $\eta \ll 1/\beta$: slow convergence

Relationship between $\eta$, loss landscape curvature: $\eta_{\max} = 2/\lambda_{\max}(\mathbf{H})$ where $\mathbf{H}$ = Hessian.

Q5. What are activation functions? Derive gradients for each.

SigmoidTanhReLUGELU (Gaussian Error Linear Unit)SiLU/Swish

Sigmoid: $$\sigma(x) = \frac{1}{1+e^{-x}}, \quad \sigma'(x) = \sigma(x)(1-\sigma(x)) \in (0, 0.25]$$ Range $(0,1)$. Gradient saturates for $|x| \gg 0$ → vanishing gradients.

Tanh: $$\tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}, \quad \tanh'(x) = 1-\tanh^2(x) \in (0,1]$$ Zero-centered (unlike sigmoid) → faster training. Still saturates.

ReLU: $$\text{ReLU}(x) = \max(0,x), \quad \text{ReLU}'(x) = \mathbf{1}[x>0]$$ No saturation for $x>0$. Gradient = 1 for positive inputs → no vanishing for active neurons.

GELU (Gaussian Error Linear Unit): $$\text{GELU}(x) = x\cdot\Phi(x) = x\cdot\frac{1}{2}\left[1+\erf\left(\frac{x}{\sqrt{2}}\right)\right]$$ Used in BERT, GPT. Smooth approximation: $\approx 0.5x(1+\tanh[\sqrt{2/\pi}(x+0.044715x^3)])$

SiLU/Swish: $x\cdot\sigma(x)$ — self-gated, non-monotonic.

Q6. Why does ReLU prevent vanishing gradients? Derive formally.

For a $L$-layer network with sigmoid activations: $$\frac{\partial\mathcal{L}}{\partial\mathbf{W}^{(1)}} = \prod_{l=2}^L \frac{\partial\mathbf{h}^{(l)}}{\partial\mathbf{h}^{(l-1)}} \cdot \frac{\partial\mathcal{L}}{\partial\mathbf{h}^{(L)}}$$

Each Jacobian $\frac{\partial h^{(l)}i}{\partial h^{(l-1)}_j} = W^{(l)}{ij}\sigma'(z^{(l)}_i)$

Sigmoid: $\sigma'(z) \leq 0.25$, so $||\frac{\partial\mathbf{h}^{(l)}}{\partial\mathbf{h}^{(l-1)}}||_2 \leq 0.25\cdot||\mathbf{W}^{(l)}||_2$

For $L$=20 layers: gradient scales as $(0.25)^{20} \approx 10^{-12}$! → Numerically zero.

ReLU fix: $\text{ReLU}'(x) = 1$ for $x>0$ → gradient magnitude preserved through active neurons. Only "dying ReLU" problem ($x\leq 0$ forever) remains.

Q7. What is the vanishing gradient problem? Mathematical analysis.

explodeSolutions

The gradient of layer $l$ depends on a product of terms: $$||\boldsymbol\delta^{(1)}|| \leq ||\boldsymbol\delta^{(L)}|| \cdot \prod_{l=2}^L ||W^{(l)}|| \cdot |\sigma'(\cdot)|$$

If spectral norm $||W^{(l)}||_2 < 1$ and $|\sigma'| < 1$ (sigmoid): product $\to 0$ exponentially. If spectral norm $||W^{(l)}||_2 > 1$: gradients explode.

Solutions: - ReLU: $|\sigma'|=1$ for active neurons - BatchNorm: normalises $z^{(l)}$, stabilises spectral norms - ResNets: gradient flows through identity shortcut $\frac{\partial}{\partial x}[F(x)+x] = \frac{\partial F}{\partial x} + 1 \geq 1$ - Gradient clipping: $\mathbf{g} \leftarrow \mathbf{g}\cdot\min(1, c/||\mathbf{g}||)$

Q8. What is the exploding gradient problem? Gradient clipping.

$$||g|| = \left|\left|\frac{\partial\mathcal{L}}{\partial\boldsymbol\theta}\right|\right| \gg 1$$

Caused by spectral norms of weight matrices $> 1$ and long sequence unrolling in RNNs.

Gradient clipping by norm: $$\hat{\mathbf{g}} = \begin{cases} \mathbf{g} & \text{if } ||\mathbf{g}|| \leq c \ c \cdot \mathbf{g}/||\mathbf{g}|| & \text{otherwise} \end{cases}$$

Clips norm to $c$ but preserves direction. Typical $c \in [0.5, 5.0]$.

Q9. What is weight initialization? Derive He and Glorot formulations.

ProblemConditionGlorot/XavierHe initialization

Problem: If weights are too large/small, signals and gradients vanish or explode at layer 0 before training.

Condition: Preserve activation variance across layers. If $h_i^{(l)} = \sum_{j=1}^{n_{l-1}} w_{ij}^{(l)} h_j^{(l-1)}$, then: $$\text{Var}(h_i^{(l)}) = n_{l-1}\text{Var}(w_{ij})\text{Var}(h_j^{(l-1)})$$

For stable propagation: $n_{l-1}\text{Var}(w) = 1 \implies \text{Var}(w) = 1/n_{l-1}$

Glorot/Xavier (sigmoid/tanh): Balance forward AND backward: $$w \sim U\left[-\sqrt{\frac{6}{n_{in}+n_{out}}}, \sqrt{\frac{6}{n_{in}+n_{out}}}\right]$$

He initialization (ReLU): Only positive half of distribution active → variance is halved: $$w\sim\mathcal{N}\left(0, \frac{2}{n_{in}}\right)$$

Factor of 2 compensates for ReLU zeroing out negative half.

Q10. What is batch normalization? Derive forward and backward pass.

learnableWhy does it help?Backward passAt inference

For a mini-batch $\mathcal{B} = {z_1,\ldots,z_m}$, normalise each feature:

$$\mu_\mathcal{B} = \frac{1}{m}\sum_{i=1}^m z_i, \quad \sigma^2_\mathcal{B} = \frac{1}{m}\sum_{i=1}^m(z_i-\mu_\mathcal{B})^2$$

$$\hat{z}i = \frac{z_i-\mu\mathcal{B}}{\sqrt{\sigma^2_\mathcal{B}+\epsilon}}$$

$$y_i = \gamma\hat{z}_i + \beta$$

where $\gamma, \beta$ are learnable parameters (identity at initialisation: $\gamma=1, \beta=0$).

Why does it help? 1. Reduces internal covariate shift — input distribution to each layer is stabilised 2. Acts as regularizer (noise from batch statistics) 3. Allows higher learning rates (landscape is smoother) 4. Reduces sensitivity to initialization

Backward pass: $$\frac{\partial\mathcal{L}}{\partial\gamma} = \sum_i\delta_i\hat{z}_i, \quad \frac{\partial\mathcal{L}}{\partial\beta} = \sum_i\delta_i$$

$$\frac{\partial\mathcal{L}}{\partial z_i} = \frac{\gamma}{m\sigma_\mathcal{B}}\left[m\delta_i - \sum_j\delta_j - \hat{z}_i\sum_j\delta_j\hat{z}_j\right]$$

At inference: Use running mean/variance computed during training (EMA).

Q11. What is dropout? Mathematical interpretation as ensemble.

inverted dropoutEnsemble interpretationRegularization effect

During training, each neuron is independently set to 0 with probability $p$ (keep prob = $1-p$): $$\tilde{h}_i = h_i \cdot \text{Bernoulli}(1-p) / (1-p)$$

The $(1-p)$ denominator = inverted dropout — scales activations so expected output is unchanged at inference.

Ensemble interpretation: With $n$ neurons, there are $2^n$ possible sub-networks. Dropout trains a stochastic ensemble of all these. At inference, using full network with scaled weights approximates geometric mean of ensemble predictions.

Regularization effect: Adds noise $\propto$ activation magnitude → prevents co-adaptation. Equivalent to L2 regularization under certain assumptions.

Q12. Double descent phenomenon in deep learning.

Classical bias-variance: test error $U$-shaped as model complexity increases.

Double descent: For over-parameterised models ($\text{params} \gg n$): 1. Classical regime: error decreases as complexity grows 2. Interpolation threshold: error peaks when model just fits training data 3. Modern/over-parameterised regime: error decreases again as model grows much larger!

Explanation: Over-parameterisation allows SGD to find flat minima with better generalisation. Implicit regularisation of gradient descent selects the minimum-norm solution.

Q13. Derive SGD, RMSProp, and Adam optimizers.

Momentum SGDRMSPropAdam (Adaptive Moment Estimation)Bias correctionAdamW

Momentum SGD: $$\mathbf{v}t = \beta\mathbf{v}{t-1} + (1-\beta)\mathbf{g}t$$ $$\boldsymbol\theta_t = \boldsymbol\theta{t-1} - \eta\mathbf{v}_t$$ Exponential moving average of gradients. $\beta=0.9$ typical. Dampens oscillations, accelerates along consistent gradient directions.

RMSProp: $$\mathbf{v}t = \beta\mathbf{v}{t-1} + (1-\beta)\mathbf{g}t^2 \quad \text{(element-wise)}$$ $$\boldsymbol\theta_t = \boldsymbol\theta{t-1} - \frac{\eta}{\sqrt{\mathbf{v}_t+\epsilon}}\mathbf{g}_t$$ Adapts per-parameter learning rate — large gradients → smaller effective LR.

Adam (Adaptive Moment Estimation): $$\mathbf{m}t = \beta_1\mathbf{m}{t-1} + (1-\beta_1)\mathbf{g}t \quad \text{(1st moment — mean)}$$ $$\mathbf{v}_t = \beta_2\mathbf{v}{t-1} + (1-\beta_2)\mathbf{g}_t^2 \quad \text{(2nd moment — variance)}$$

Bias correction (crucial at early steps when moments are near 0): $$\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1-\beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1-\beta_2^t}$$

$$\boldsymbol\theta_t = \boldsymbol\theta_{t-1} - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t}+\epsilon}\hat{\mathbf{m}}_t$$

Typical: $\beta_1=0.9$, $\beta_2=0.999$, $\epsilon=10^{-8}$, $\eta=10^{-3}$.

AdamW: Decouples weight decay from adaptive LR: $$\boldsymbol\theta_t = \boldsymbol\theta_{t-1} - \eta\left(\frac{\hat{\mathbf{m}}t}{\sqrt{\hat{\mathbf{v}}_t}+\epsilon} + \lambda\boldsymbol\theta{t-1}\right)$$

Q14. Dying ReLU problem — mathematical explanation and fixes.

Dead neuron conditionSolutionsPrevention

Dead neuron condition: If for all inputs $x$, $z = w^Tx + b < 0$, then $\text{ReLU}(z) = 0$ and $\text{ReLU}'(z) = 0$.

The gradient $\boldsymbol\delta = 0$ → weight updates are zero → neuron stays dead permanently.

Solutions:

ActivationFormulaFix
Leaky ReLU$\max(\alpha x, x)$, $\alpha=0.01$Tiny gradient for $x<0$
PReLU$\max(\alpha x, x)$, $\alpha$ learnedAdaptive
ELU$x$ if $x\geq 0$; $\alpha(e^x-1)$ if $x<0$Smooth negative region
SELU$\lambda\cdot$ELUSelf-normalizing networks

Prevention: He initialization, small learning rate, BatchNorm before activation.

Q15. What is a perceptron? Derive the perceptron learning algorithm.

$\hat{y} = \text{sign}(\mathbf{w}^T\mathbf{x}+b)$

Perceptron update rule: For each misclassified point $(\mathbf{x}_i, y_i)$ where $y_i\in{-1,+1}$: $$\mathbf{w} \leftarrow \mathbf{w} + y_i\mathbf{x}_i$$

Convergence theorem (Novikoff, 1962): If data is linearly separable with margin $\gamma = \min_i y_i(\mathbf{w}^\cdot\mathbf{x}_i)/||\mathbf{w}^||$, then perceptron converges in at most $R^2/\gamma^2$ updates where $R = \max||x_i||$.

Q16. Universal Approximation Theorem — statement and implications.

CaveatDepth provides efficiencyPractical implication

Theorem (Cybenko 1989, Hornik 1991): For any continuous function $f: [0,1]^n \to \mathbb{R}$ and $\epsilon > 0$, there exists a shallow network: $$F(\mathbf{x}) = \sum_{k=1}^N \alpha_k\sigma(\mathbf{w}k^T\mathbf{x}+b_k)$$ such that $\sup\mathbf{x}|F(\mathbf{x})-f(\mathbf{x})| < \epsilon$, for any non-polynomial $\sigma$.

Caveat: Theorem guarantees existence but NOT how large $N$ must be (can be exponential in dimension).

Depth provides efficiency: Lunaberg (2018): Functions representable by deep networks with $O(kn)$ neurons may require $O(k^n)$ neurons in shallow networks.

Practical implication: Depth allows efficient representation; width provides universal approximation.

Q18. Weight regularization in neural networks — L1, L2, and weight decay.

L2 regularization (weight decay)L1 regularizationMax-norm regularization

L2 regularization (weight decay): Add $\frac{\lambda}{2}||\boldsymbol\theta||^2$ to loss: $$\nabla J = \nabla \mathcal{L} + \lambda\boldsymbol\theta$$ $$\boldsymbol\theta_{t+1} = (1-\eta\lambda)\boldsymbol\theta_t - \eta\nabla\mathcal{L}$$

The $(1-\eta\lambda)$ multiplicative factor "decays" weights each step.

L1 regularization: Add $\lambda||\boldsymbol\theta||_1$: $$\nabla J = \nabla\mathcal{L} + \lambda\text{sign}(\boldsymbol\theta)$$ Promotes sparse activations/weights.

Max-norm regularization: Constrain $||\mathbf{w}_i|| \leq c$ after each update. Used with dropout (prevents blow-up of unregularized weights).

Q19. Data augmentation — theoretical justification.

Key augmentations and invariances enforced: - Horizontal flip → left-right equivariance - Random crop → translation equivariance
- Color jitter → photometric invariance - Mixup: $\tilde{x} = \lambda x_i + (1-\lambda)x_j$, $\tilde{y} = \lambda y_i + (1-\lambda)y_j$ — linear interpolation of examples and labels; improves calibration - CutMix: replace patches from another image

Q20. Epoch, batch, iteration — learning dynamics analysis.

For dataset size $n$, batch size $B$: - Iterations per epoch = $\lceil n/B \rceil$ - Total gradient updates = epochs $\times$ iterations/epoch

Effect of batch size on generalisation (Keskar et al., 2017): - Small batch → noisy gradients → explores loss landscape → finds flatter minima → better generalisation - Large batch → accurate gradient estimate → finds sharper minima → worse test performance (but same training loss) - Linear scaling rule: when multiplying $B$ by $k$, multiply $\eta$ by $k$ (maintains same weight update magnitude)

Q21. Derive the CNN convolution operation mathematically.

For input feature map $\mathbf{X}\in\mathbb{R}^{H\times W\times C_{in}}$, filter $\mathbf{K}\in\mathbb{R}^{k_h\times k_w\times C_{in}\times C_{out}}$:

$$\mathbf{Y}[i,j,c_{out}] = \sum_{m=0}^{k_h-1}\sum_{n=0}^{k_w-1}\sum_{c_{in}=0}^{C_{in}-1} \mathbf{K}[m,n,c_{in},c_{out}]\cdot\mathbf{X}[i\cdot s+m,\ j\cdot s+n,\ c_{in}]$$

where $s$ = stride.

Output dimensions: $$H_{out} = \left\lfloor\frac{H+2p-k_h}{s}\right\rfloor+1, \quad W_{out} = \left\lfloor\frac{W+2p-k_w}{s}\right\rfloor+1$$

Parameter count for convolutional layer: $$\underbrace{k_h\cdot k_w\cdot C_{in}}{{\text{per filter}}}\cdot C{out} + C_{out} \text{ (biases)}$$

vs. fully connected: $(H\cdot W\cdot C_{in})\cdot(H_{out}\cdot W_{out}\cdot C_{out})$ — exponentially more.

FLOPs (multiply-accumulate operations): $$2\cdot k_h\cdot k_w\cdot C_{in}\cdot H_{out}\cdot W_{out}\cdot C_{out}$$

Q22. What is parameter sharing? Compare to FC layers.

ConsequenceTranslation equivariance

In a FC layer: each output neuron has unique weights for every input neuron. In a Conv layer: the same filter $\mathbf{K}[:,:,:,c]$ is applied at every $(i,j)$ position.

Consequence: - FC: $H_{out}W_{out}C_{out} \times H_{in}W_{in}C_{in}$ parameters - Conv: $k_hk_wC_{in}C_{out}$ parameters — independent of spatial dimensions

Translation equivariance: If input shifts by $(t,s)$, output also shifts by $(t/s_{\text{stride}}, s/s_{\text{stride}})$. Formally: $f(T_\mathbf{t}\mathbf{x}) = T_\mathbf{t} f(\mathbf{x})$.

Pooling creates translation invariance (shift input → no change in output).

Q23. Pooling layers — math and spatial effect.

Max poolingBackward pass of max poolAverage pooling

Max pooling: $$\mathbf{Y}[i,j,c] = \max_{0\leq m<k, 0\leq n<k} \mathbf{X}[i\cdot s+m,\ j\cdot s+n,\ c]$$

No parameters. Spatial dimensions reduced by factor $s$ (stride).

Backward pass of max pool: Gradient flows only to the max position (others get 0): $$\frac{\partial\mathcal{L}}{\partial\mathbf{X}[i,j]} = \frac{\partial\mathcal{L}}{\partial\mathbf{Y}[i',j']} \cdot \mathbf{1}[\text{X}[i,j]=\text{max}]$$

Average pooling: $$\mathbf{Y}[i,j,c] = \frac{1}{k^2}\sum_{m,n}\mathbf{X}[i\cdot s+m, j\cdot s+n, c]$$

Gradient distributes uniformly to all positions.

Q26. Residual connections in ResNet — gradient flow analysis.

Residual blockGradient through residual pathHe et al. interpretation

Residual block: $$\mathbf{y} = F(\mathbf{x}, {W_i}) + \mathbf{x}$$

For a network of $L$ residual blocks: $$\mathbf{x}L = \mathbf{x}_l + \sum{i=l}^{L-1} F(\mathbf{x}_i, {W_i})$$

Gradient through residual path: $$\frac{\partial \mathcal{L}}{\partial \mathbf{x}l} = \frac{\partial \mathcal{L}}{\partial \mathbf{x}_L}\cdot\frac{\partial \mathbf{x}_L}{\partial \mathbf{x}_l} = \frac{\partial\mathcal{L}}{\partial\mathbf{x}_L}\left(1 + \frac{\partial}{\partial\mathbf{x}_l}\sum{i=l}^{L-1}F_i\right)$$

The "+1" term ensures gradient flows directly from $\mathbf{x}_L$ to $\mathbf{x}_l$ without going through any weights — effectively unlimited depth without vanishing.

He et al. interpretation: ResNet learns residuals $F(\mathbf{x}) = H(\mathbf{x}) - \mathbf{x}$. If optimal function is close to identity ($H^*\approx\mathbf{x}$), it's easier to drive $F\to0$ than to learn identity from scratch.

Q30. Receptive field calculation in deep CNNs.

For stacked convolutional layers with kernel $k_l$ and stride $s_l$ at layer $l$: $$RF_l = RF_{l-1} + (k_l-1)\prod_{i=1}^{l-1}s_i$$

For uniform $k=3$, $s=1$: $RF_L = 1 + 2L$ (linear growth). For $s=2$ every other layer: $RF$ grows exponentially.

Dilated convolution: Kernel with holes — $k=3$, dilation $d$: $$\text{effective }k = k + (k-1)(d-1) = 2d+1$$

WaveNet uses exponentially-increasing dilation: $d=1,2,4,8,\ldots,512$ → RF = $O(1024)$ with only $O(\log\text{RF})$ layers.

Q37. Derive LSTM gates mathematically. Show how cell state prevents vanishing gradients.

For input $\mathbf{x}t\in\mathbb{R}^d$, hidden state $\mathbf{h}{t-1}\in\mathbb{R}^h$, cell state $\mathbf{c}_{t-1}\in\mathbb{R}^h$:

Gate equations: $$\mathbf{f}t = \sigma(\mathbf{W}_f[\mathbf{h}{t-1};\mathbf{x}t] + \mathbf{b}_f) \quad \text{[forget gate] — how much to forget}$$ $$\mathbf{i}_t = \sigma(\mathbf{W}_i[\mathbf{h}{t-1};\mathbf{x}t] + \mathbf{b}_i) \quad \text{[input gate] — what to write}$$ $$\tilde{\mathbf{c}}_t = \tanh(\mathbf{W}_c[\mathbf{h}{t-1};\mathbf{x}t] + \mathbf{b}_c) \quad \text{[cell candidate]}$$ $$\mathbf{o}_t = \sigma(\mathbf{W}_o[\mathbf{h}{t-1};\mathbf{x}_t] + \mathbf{b}_o) \quad \text{[output gate] — what to read}$$

The gradient flows through cell state simply as multiplication by $\mathbf{f}_t\in[0,1]$. When forget gate $\approx 1$ (remember mode), gradient flows without attenuation. The cell state acts as a gradient highway.

Q39. Derive Backpropagation Through Time (BPTT) with time complexity.

Unrolled RNN for $T$ steps has $T\times$ copies of the weight matrices but all share $\mathbf{W}_{hh}$.

Q44. Word2Vec — derive Skip-gram objective and negative sampling.

Skip-gram objectiveNegative sampling approximation

Skip-gram objective: Given word $w_t$, maximise probability of context words: $$\mathcal{L} = \sum_{t=1}^T\sum_{-c\leq j\leq c, j\neq 0} \log P(w_{t+j}|w_t)$$

$$P(w_O|w_I) = \frac{\exp(\mathbf{v}{w_O}^T\mathbf{v}{w_I})}{\sum_{w=1}^W\exp(\mathbf{v}w^T\mathbf{v}{w_I})}$$

Computing full softmax is $O(W)$ (vocab size) — too expensive.

Negative sampling approximation: $$\log\sigma(\mathbf{v}{w_O}^T\mathbf{v}{w_I}) + \sum_{k=1}^K E_{w_k\sim P_n}[\log\sigma(-\mathbf{v}{w_k}^T\mathbf{v}{w_I})]$$

Sample $K=5$ negative words from unigram distribution $P_n(w)\propto f(w)^{3/4}$. Reduces complexity to $O(K)$ instead of $O(W)$.

Q52. Derive scaled dot-product self-attention completely.

InputsProjectionsAttention functionElement-wiseComplexityWhy $\sqrt{dk}$ scaling?

Inputs: Token representations $\mathbf{X}\in\mathbb{R}^{T\times d_{model}}$

Projections: $$\mathbf{Q} = \mathbf{X}\mathbf{W}^Q, \quad \mathbf{K} = \mathbf{X}\mathbf{W}^K, \quad \mathbf{V} = \mathbf{X}\mathbf{W}^V$$ where $\mathbf{W}^Q,\mathbf{W}^K\in\mathbb{R}^{d_{model}\times d_k}$, $\mathbf{W}^V\in\mathbb{R}^{d_{model}\times d_v}$.

Attention function: $$\text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}}\right)\mathbf{V}$$

Element-wise: $a_{ij} = \text{softmax}\left(\frac{\mathbf{q}i^T\mathbf{k}_j}{\sqrt{d_k}}\right)$, output $\mathbf{o}_i = \sum_j a{ij}\mathbf{v}_j$

Complexity: $O(T^2d)$ memory and time — quadratic in sequence length.

Why $\sqrt{d_k}$ scaling? If $\mathbf{q}_i,\mathbf{k}_j\sim\mathcal{N}(0,1)$, then $\mathbf{q}_i^T\mathbf{k}_j\sim\mathcal{N}(0,d_k)$. Without scaling: $d_k=64$ → std = 8 → softmax input has large magnitude → gradients vanish. With $1/\sqrt{d_k}$ scaling: $\text{Var}=1$ → softmax is well-conditioned.

Q53. Multi-head attention — derive and explain what multiple heads learn.

$$\text{MultiHead}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{Concat}(\text{head}_1,\ldots,\text{head}_h)\mathbf{W}^O$$

$$\text{head}_i = \text{Attention}(\mathbf{Q}\mathbf{W}_i^Q, \mathbf{K}\mathbf{W}_i^K, \mathbf{V}\mathbf{W}_i^V)$$

$\mathbf{W}i^Q,\mathbf{W}_i^K\in\mathbb{R}^{d{model}\times d_k}$, $d_k = d_{model}/h$, $\mathbf{W}^O\in\mathbb{R}^{hd_v\times d_{model}}$.

Q54. Positional encoding — derive the sinusoidal scheme.

Sinusoidal (learned components)Properties

Transformer has no notion of token order — a permutation of tokens gives the same attention scores. Positional encodings inject position information.

Sinusoidal (learned components): $$PE_{(pos,2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ $$PE_{(pos,2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

Properties: 1. Offset by $T$ is a fixed linear transformation: $PE_{pos+T}$ can be expressed as $\mathbf{M}T \cdot PE{pos}$ for a rotation matrix $\mathbf{M}T$ 2. Allows model to attend to relative positions: $\mathbf{q}{pos}^T\mathbf{k}_{pos+j}$ depends on $j$ 3. Generalises to longer sequences than seen in training

RoPE (Rotary Position Embedding, LLaMA): Applies rotation to Q/K as a function of position: $$\mathbf{q}_m^T\mathbf{k}_n = \mathbf{q}_m^T(\mathbf{R}_m^T\mathbf{R}_n)\mathbf{k}_n$$ Encodes relative position $m-n$ directly into attention scores.

Q59. Fine-tuning transformers — PEFT methods derivation.

Full fine-tuningLoRA (Low-Rank Adaptation)AdapterPrompt tuning

Full fine-tuning: Update all $W$ parameters. Expensive. Catastrophic forgetting risk.

LoRA (Low-Rank Adaptation): $$\mathbf{W}' = \mathbf{W}_0 + \Delta\mathbf{W} = \mathbf{W}_0 + \mathbf{B}\mathbf{A}$$

$\mathbf{A}\in\mathbb{R}^{r\times d_{in}}$, $\mathbf{B}\in\mathbb{R}^{d_{out}\times r}$, $r\ll\min(d_{in},d_{out})$

Trainable params: $r(d_{in}+d_{out})$ vs $d_{in}d_{out}$. Rank $r=8$ → $\sim800\times$ reduction.

Initialisation: $\mathbf{B}=0$ → $\Delta\mathbf{W}=0$ at start. $\mathbf{A}\sim\mathcal{N}(0,\sigma^2)$.

Adapter: Insert small $(\text{down-proj} \to \text{ReLU} \to \text{up-proj})$ modules between layers.

Prompt tuning: Prepend $k$ soft "virtual tokens" to input; only train their embeddings.

Q60. Flash Attention — IO-aware algorithm for O(n) memory.

Standard attention memoryFlash Attention (Dao et al. 2022)online softmaxOnline softmax recurrence

Standard attention memory: $O(T^2)$ — must materialise full $T\times T$ attention matrix.

Flash Attention (Dao et al. 2022): Key insight: Compute attention tile-by-tile using online softmax — never materialise the full $T\times T$ matrix.

$$\text{For each block } (i,j): \text{compute partial } e^{x_{ij}-m}, \text{ update running max } m, \text{ running sum } \ell$$

Memory: $O(T\cdot d)$ (no $T\times T$ matrix). Speed: 2–4× faster due to reduced HBM reads/writes.

Online softmax recurrence: $$m_j = \max(m_{j-1}, \max_k A_{ik}) \quad \ell_j = e^{m_{j-1}-m_j}\ell_{j-1} + \sum_k e^{A_{ik}-m_j}$$

Q63. Tensor parallelism vs pipeline parallelism for LLM training.

Data parallelismTensor parallelism (Megatron-LM)Pipeline parallelismBubble timeZeRO (DeepSpeed)

Data parallelism: Each GPU holds a copy of the model; data is sharded. Gradient synchronization via all-reduce: $O(W)$ communication.

Tensor parallelism (Megatron-LM): Shard individual weight matrices: $$\mathbf{W}_{MLP} = [\mathbf{W}_1 | \mathbf{W}_2]$$ Each GPU computes part of the matrix multiply. Communication: all-reduce per layer.

Pipeline parallelism: Assign consecutive transformer layers to different GPUs. Mini-batch split into $m$ micro-batches; pipeline parallelism fills idle stages. Bubble time (wasted): $\frac{p-1}{m+p-1}$ where $p$ = pipeline stages.

ZeRO (DeepSpeed): Partition states (optimizer, gradients, params) across GPUs. - Stage 1: Optimizer state partitioned → $4\times$ memory reduction - Stage 2: + Gradient partition → $8\times$ - Stage 3: + Parameter partition → $N_{gpu}\times$

Q67. What is Parameter-Efficient Fine-Tuning (PEFT)?

Fine-tuning only a small number of additional parameters instead of the full model. Methods: LoRA, Prefix Tuning, Prompt Tuning, Adapter layers. Reduces GPU memory and training time dramatically.

Q68. What is LoRA (Low-Rank Adaptation)?

LoRA freezes pre-trained weights and adds low-rank decomposition matrices (A·B) to attention layers. Only A and B are trained. Rank r << d means far fewer parameters. At inference, ΔW = A·B merges back into original weights.

Q69. What is Reinforcement Learning from Human Feedback (RLHF)?

A fine-tuning pipeline: (1) Supervised Fine-Tuning on demonstrations; (2) Train a Reward Model on human preference rankings; (3) Optimize with PPO to maximize reward while penalizing KL divergence from the SFT model.

Q72. What is a GAN? Derive the minimax objective and optimal discriminator.

Minimax gameOptimal discriminatorGlobal minimumVanishing gradient problem

Minimax game: $$\min_G\max_D V(D,G) = \mathbb{E}{x\sim p{data}}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1-D(G(z)))]$$

Optimal discriminator (with $G$ fixed): $$D^*(x) = \frac{p_{data}(x)}{p_{data}(x)+p_g(x)}$$

Substituting $D^$ back, the game becomes: $$\min_G V(D^,G) = \underbrace{-\log 4}{\text{constant}} + 2\cdot KL\left(p{data}\middle|\frac{p_{data}+p_g}{2}\right) + 2\cdot KL\left(p_g\middle|\frac{p_{data}+p_g}{2}\right)$$ $$= -\log 4 + 4\cdot JSD(p_{data}|p_g)$$

Global minimum at $G^*$: $p_g = p_{data}$ → $JSD = 0$.

Vanishing gradient problem: When $D$ is perfect: $$D(G(z)) \approx 0 \implies \nabla_G\log(1-D(G(z))) \approx 0$$ → Generator receives zero gradient.

Non-saturating loss fix (heuristic): $$\max_G \mathbb{E}_z[\log D(G(z))]$$ Same fixed point, but provides stronger gradient early in training.

Q73. WGAN — derive the Wasserstein distance and gradient penalty.

Problem with JSDWGAN objectiveGradient Penalty (WGAN-GP)

Problem with JSD: Disjoint support of $p_{data}$ and $p_g$ → $JSD = \log 2$ (constant, zero gradient).

Earth Mover's (Wasserstein-1) distance: $$W(p,q) = \inf_{\gamma\in\Pi(p,q)} \mathbb{E}_{(x,y)\sim\gamma}[||x-y||]$$

Kantorovich-Rubinstein duality (1-Lipschitz functions $f$ with $||f||_L \leq 1$): $$W(p,q) = \sup_{||f||_L\leq 1} \mathbb{E}_x[f(x)] - \mathbb{E}_y[f(y)]$$

WGAN objective: $$\min_G\max_{||D||L\leq 1} \mathbb{E}{x\sim p_{data}}[D(x)] - \mathbb{E}_{z\sim p_z}[D(G(z))]$$

Gradient Penalty (WGAN-GP): Enforce Lipschitz constraint via: $$\lambda \mathbb{E}{\hat{x}}[(||\nabla{\hat{x}}D(\hat{x})||_2 - 1)^2]$$ where $\hat{x}$ is sampled uniformly along lines between real and fake samples.

Q74. Derive the VAE ELBO objective from first principles.

GoalVariational inferenceELBO decompositionEncoderReparameterisation trickClosed-form KL

Goal: Learn a generative model $p_\theta(x) = \int p_\theta(x|z)p(z)dz$ — intractable integral.

Variational inference: Introduce approximate posterior $q_\phi(z|x)$: $$\log p_\theta(x) = \mathbb{E}{q\phi(z|x)}\left[\log\frac{p_\theta(x,z)}{q_\phi(z|x)}\right] + KL(q_\phi(z|x)||p_\theta(z|x))$$ $$\geq \underbrace{\mathbb{E}{q\phi(z|x)}[\log p_\theta(x|z)] - KL(q_\phi(z|x)||p(z))}_{\text{ELBO} = \mathcal{L}(\theta,\phi;x)}$$

ELBO decomposition: - $\mathbb{E}{q\phi(z|x)}[\log p_\theta(x|z)]$: reconstruction term (log-likelihood) - $-KL(q_\phi(z|x)||p(z))$: regularisation (keep posterior close to prior $p(z)=\mathcal{N}(0,I)$)

Encoder: $q_\phi(z|x) = \mathcal{N}(z|\mu_\phi(x), \text{diag}(\sigma^2_\phi(x)))$

Reparameterisation trick: $$z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon, \quad \epsilon\sim\mathcal{N}(0,I)$$

Closed-form KL (Gaussian prior): $$KL = -\frac{1}{2}\sum_j(1+\log\sigma_j^2 - \mu_j^2 - \sigma_j^2)$$

Training loss: $$\mathcal{L} = -\mathbb{E}{\epsilon}[\log p\theta(x|\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon)] + \frac{1}{2}\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2)$$

Q75. Derive diffusion models — forward process, reverse process, and training objective.

Forward process (DDPM)Closed-form marginalReverse processELBO training objectivePosterior mean (known)DDIM (deterministic)

Forward process (DDPM): Add Gaussian noise over $T$ steps: $$q(x_t|x_{t-1}) = \mathcal{N}(x_t;\sqrt{1-\beta_t}x_{t-1}, \beta_t\mathbf{I})$$

Closed-form marginal (let $\alpha_t = 1-\beta_t$, $\bar{\alpha}t = \prod{s=1}^t\alpha_s$): $$q(x_t|x_0) = \mathcal{N}(x_t;\sqrt{\bar{\alpha}_t}x_0, (1-\bar{\alpha}_t)\mathbf{I})$$ $$\implies x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon, \quad \epsilon\sim\mathcal{N}(0,\mathbf{I})$$

Reverse process: Learn $p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1};\mu_\theta(x_t,t), \Sigma_\theta)$

ELBO training objective: $$\mathcal{L} = \mathbb{E}{x_0,\epsilon,t}\left[||\epsilon - \epsilon\theta(x_t,t)||^2\right]$$

The neural network $\epsilon_\theta$ predicts the noise $\epsilon$ added at step $t$ — equivalent to score matching.

Posterior mean (known): $$\tilde{\mu}t(x_t,x_0) = \frac{\sqrt{\bar{\alpha}{t-1}}\beta_t}{1-\bar{\alpha}t}x_0 + \frac{\sqrt{\alpha_t}(1-\bar{\alpha}{t-1})}{1-\bar{\alpha}_t}x_t$$

DDIM (deterministic): Replace stochastic reverse with non-Markovian update: $$x_{t-1} = \sqrt{\bar{\alpha}{t-1}}\hat{x}_0 + \sqrt{1-\bar{\alpha}{t-1}}\epsilon_\theta(x_t,t)$$ Allows $\sim$50 steps instead of 1000.

Q76. Derive contrastive learning objectives — NT-Xent (SimCLR) and CLIP.

SimCLR NT-Xent lossCLIP contrastive lossInfoNCE lower bound

SimCLR NT-Xent loss: For a batch of $N$ samples, create $2N$ views via augmentation. For a positive pair $(i, j)$: $$\ell(i,j) = -\log\frac{\exp(\text{sim}(z_i,z_j)/\tau)}{\sum_{k=1}^{2N}\mathbf{1}[k\neq i]\exp(\text{sim}(z_i,z_k)/\tau)}$$ $$\mathcal{L}{SimCLR} = \frac{1}{2N}\sum{k=1}^N[\ell(2k-1,2k)+\ell(2k,2k-1)]$$ where $\text{sim}(u,v) = u^Tv/(||u||\cdot||v||)$ and $\tau$ = temperature.

CLIP contrastive loss (joint image-text): For batch of $(image_i, text_i)$ pairs: $$\mathcal{L}{CLIP} = -\frac{1}{2N}\sum_i\left[\log\frac{e^{\phi_i^T\psi_i/\tau}}{\sum_j e^{\phi_i^T\psi_j/\tau}} + \log\frac{e^{\phi_i^T\psi_i/\tau}}{\sum_j e^{\phi_j^T\psi_i/\tau}}\right]$$ where $\phi_i = f{vision}(image_i)$, $\psi_i = g_{text}(text_i)$ are normalized embeddings.

InfoNCE lower bound: $\mathcal{L}_{NT-Xent}$ is an upper bound on $-MI(z_i;z_j)$ — maximising it maximises a lower bound on mutual information between views.

  • Top-p (nucleus): Sample from the smallest set of tokens whose cumulative probability exceeds p.

Q96. How does weight tying in language models work?

Sharing the weights between the input embedding matrix and the final output projection matrix. Reduces parameters and often improves performance, especially in smaller models.

•

Q97. What is model merging (SLERP, DARE, TIES)?

Combining weights of multiple fine-tuned models derived from the same base without additional training. SLERP: spherical linear interpolation in weight space. TIES: resolves sign conflicts during merge. Popular in open-source LLM community.

•

Q98. What is FSDP (Fully Sharded Data Parallel)?

PyTorch's distributed training strategy that shards model parameters, gradients, and optimizer states across GPUs instead of replicating them. Enables training models that don't fit on a single GPU memory.

•

Q99. What is the difference between a frozen and unfrozen backbone in fine-tuning?

FrozenUnfrozen (full fine-tuning)
  • Frozen: Pre-trained weights don't change; only task head is trained. Fast; prevents catastrophic forgetting. Best with limited data.
  • Unfrozen (full fine-tuning): All weights are updated. Better performance but slower and risks forgetting.
•

Q100. What is the attention bottleneck at inference and how is it being solved?

Standard attention is O(n²) time and memory in sequence length. Solutions:
- KV cache compression (quantized KV, GQA, MQA)
- Grouped Query Attention (GQA): Fewer K/V heads than Q heads
- Multi-Query Attention (MQA): Single K/V head shared across all Q heads
- Sliding window / sparse attention for very long sequences

Advanced Architectures (Q101–Q120)
•

Q101. What is a Residual Network (ResNet) and why does it work?

Skip connections allow gradient flow directly through identity mappings:
$$\mathbf{y} = \mathcal{F}(\mathbf{x}, {W_i}) + \mathbf{x}$$
Networks can learn residuals $\mathcal{F}(\mathbf{x})$ rather than full mappings. Solves vanishing gradients in 100+ layer networks. ResNet-50/101/152 remain production baselines.

•

Q102. What is a DenseNet architecture?

Each layer receives feature maps from ALL previous layers (dense connectivity). Encourages feature reuse, reduces parameter count, improves gradient flow vs ResNets. Connection: $\mathbf{x_l} = H_l([\mathbf{x_0}, \mathbf{x_1}, ..., \mathbf{x_{l-1}}])$.

•

Q103. What is MobileNet and why is it used for edge deployment?

Replaces standard convolutions with depthwise separable convolutions:
- Depthwise conv: 1 filter per input channel (spatial features).
- Pointwise conv: 1×1 conv to combine channels (cross-channel features).
Reduces params/FLOPs by ~8-9× vs standard conv with minimal accuracy loss. Ideal for mobile/embedded inference.

•

Q104. What is EfficientNet and its compound scaling strategy?

Uniformly scales network width (channels), depth (layers), and resolution together using a compound coefficient $\phi$:
$$d = \alpha^\phi, \quad w = \beta^\phi, \quad r = \gamma^\phi \quad s.t. \quad \alpha \cdot \beta^2 \cdot \gamma^2 \approx 2$$
Achieves state-of-the-art accuracy with far fewer parameters than ResNets.

•

Q105. What is Vision Transformer (ViT)?

Treats image as a sequence of patches:
1. Split image into 16×16 patches.
2. Linearly embed each patch.
3. Add positional embeddings.
4. Feed through standard Transformer encoder.
5. [CLS] token is classified.
Outperforms CNNs on large-scale data but needs more data than CNNs for small datasets.

•

Q106. What is Swin Transformer and how does it differ from ViT?

Introduces hierarchical (multi-scale) representations and shifted window attention (instead of global attention). Attention computed within local windows — O(N) vs ViT's O(N²). Suitable as vision backbone for detection and segmentation tasks.

•

Q107. What is YOLO (You Only Look Once)?

Single-shot object detection: divides image into grid, each cell predicts bounding boxes + class probabilities in one forward pass. Much faster than two-stage detectors (R-CNN family). YOLOv8 achieves ~55ms inference on CPU for full-HD images.

•

Q108. What is UNet and what is it used for?

An encoder-decoder CNN with skip connections between corresponding encoder and decoder layers. Produces pixel-wise segmentation maps. Originally designed for biomedical image segmentation; now a backbone for diffusion models' denoising U-Nets.

•

Q109. What is a Generative Adversarial Network (GAN)?

Generator GDiscriminator D

Two networks trained adversarially:
- Generator G: Maps noise $z$ to fake samples.
- Discriminator D: Distinguishes real from fake.
Objective: $\min_G \max_D \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1-D(G(z)))]$
Training instability (mode collapse, vanishing gradients) is the main challenge.

•

Q110. What is mode collapse in GANs and how do you mitigate it?

Wasserstein GAN (WGAN)Minibatch discriminationProgressive growing (ProGAN)

Generator produces only a few high-quality samples while ignoring most of the data distribution. Mitigation:
- Wasserstein GAN (WGAN): Uses earth mover's distance — more stable training.
- Minibatch discrimination: Expose D to statistics across batch.
- Progressive growing (ProGAN): Gradually increase resolution during training.

•

Q111. What is a Variational Autoencoder (VAE)?

Encodes inputs to a latent distribution $q(z|x) = \mathcal{N}(\mu, \sigma^2)$ rather than a point. Trained to maximize ELBO:
$$\mathcal{L} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - KL(q(z|x) | p(z))$$
Reconstruction loss + KL regularization toward standard normal prior. Enables smooth interpolation and generation.

•

Q112. What is the reparameterization trick in VAEs?

Backpropagation cannot flow through sampling $z \sim \mathcal{N}(\mu, \sigma^2)$. Instead:
$$z = \mu + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$
Gradients flow through $\mu$ and $\sigma$, not through the stochastic node.

•

Q113. What is a diffusion model?

Forward (noising)Reverse (denoising)

Two processes:
- Forward (noising): Gradually adds Gaussian noise to data over T timesteps.
- Reverse (denoising): Train a U-Net to predict and remove noise at each step.
At inference: start from Gaussian noise, predict and remove noise iteratively. State-of-the-art for image/audio/video generation (DALL·E 3, Stable Diffusion, Sora).

•

Q114. What is DDPM vs DDIM?

  • DDPM (Denoising Diffusion Probabilistic Models): Stochastic reverse process, requires ~1000 steps.
  • DDIM (Denoising Diffusion Implicit Models): Deterministic reverse process, ~50 steps with nearly identical quality. Enables image interpolation and editing.
•

Q115. What is a flow-based generative model?

Learn an invertible transformation $f: x \leftrightarrow z$ (bijection between data and latent space). Exact log-likelihood computation via change of variables formula. Examples: Glow, RealNVP, Normalizing Flows. Slower than diffusion/GANs in practice.

•

Q116. What is a Capsule Network?

Hinton's alternative to CNNs: capsules are groups of neurons encoding entity properties (position, orientation, size) as vectors. Dynamic routing replaces max-pooling. Better at equivariance but expensive. Not yet widely adopted in industry.

•

Q117. What is Graph Neural Network (GNN)?

Extends neural networks to graph-structured data. Message passing: each node aggregates information from neighbors:
$$h_v^{(l+1)} = \sigma!\left(W \cdot \text{AGG}!\left({h_u^{(l)} : u \in \mathcal{N}(v)}\right)\right)$$
Applications: molecular property prediction, recommendation systems, social networks, knowledge graphs.

•

Q118. What are GCN, GAT, and GraphSAGE?

GCN (Graph Convolutional Network)GAT (Graph Attention Network)GraphSAGE
  • GCN (Graph Convolutional Network): Averages neighbor features with fixed symmetric normalization.
  • GAT (Graph Attention Network): Learns importance weights for each neighbor via attention.
  • GraphSAGE: Samples a fixed number of neighbors, then aggregates — scales to millions of nodes.
•

Q119. What is a Neural ODE?

Parameterizes the derivative of hidden state with a neural network:
$$\frac{dh(t)}{dt} = f_\theta(h(t), t)$$
Hidden state is the ODE solution at time T. Memory-efficient (O(1) memory for backprop). Applications: continuous normalizing flows, time-series modeling.

•

Q120. What is a State Space Model (SSM) and Mamba?

SSMs model sequences with recurrent state: $h'(t) = Ah(t) + Bx(t)$, $y(t) = Ch(t) + Dx(t)$. Mamba introduces input-selective SSM (S6 layer) — linear complexity O(N) vs Transformer's O(N²). Competitive with Transformers on long sequences.

Training Techniques & Regularization (Q121–Q140)
•

Q121. What is weight initialization and why does it matter?

Xavier/GlorotHe/KaimingOrthogonal init

Poor initialization → vanishing/exploding gradients before training starts.
- Xavier/Glorot: Keeps variance stable for tanh/sigmoid. $\text{Var}(w) = \frac{2}{n_{in}+n_{out}}$
- He/Kaiming: For ReLU. $\text{Var}(w) = \frac{2}{n_{in}}$
- Orthogonal init: For RNNs.

•

Q122. What is Layer Normalization vs Batch Normalization?

BatchNormLayerNorm

•

Q123. What is Group Normalization and when is it used?

Divides channels into groups and normalizes within each group independently. Works well with small batch sizes (e.g., object detection where batch size = 1-2):
$$\hat{x}_i = \frac{x_i - \mu_G}{\sqrt{\sigma_G^2 + \epsilon}}$$

•

Q124. What is spectral normalization in GANs?

Constrains the Lipschitz constant of the discriminator by normalizing each weight matrix by its spectral norm (largest singular value). Stabilizes GAN training without needing gradient penalty.

•

Q125. What is the difference between dropout and DropBlock?

DropoutDropBlock
  • Dropout: Randomly zeroes individual activations. Ineffective for CNNs (nearby units carry same info).
  • DropBlock: Drops contiguous spatial regions (blocks) of feature maps. More effective regularization for CNNs.
•

Q126. What is label smoothing and what does it do?

Replace hard one-hot labels with soft targets: $y' = (1-\epsilon) \cdot y + \epsilon/K$.
Prevents the model from becoming overconfident. Improves calibration. Commonly $\epsilon=0.1$. Hurts performance if used before knowledge distillation (teacher producing soft labels already).

•

Q127. What is mixup training?

lam = np.random.beta(alpha, alpha)
x_mix = lam * x1 + (1 - lam) * x2
y_mix = lam * y1 + (1 - lam) * y2
# Train on mixed samples and labels

Reduces overconfidence and improves robustness to adversarial examples.

•

Q128. What is CutMix augmentation?

Cut a rectangular region from one image and paste it into another. Mix labels proportionally to pixel area from each image. More effective than Mixup for vision tasks — preserves spatial information.

•

Q129. What is stochastic depth?

During training, randomly skip entire layers with probability $p_l$. At inference, scale layer output by $(1-p_l)$. Trains very deep networks (1000+ layers) effectively. Different from dropout: entire layers are dropped.

•

Q130. What is the difference between fine-tuning and feature extraction in transfer learning?

Feature extractionFine-tuningDiscriminative fine-tuning
  • Feature extraction: Freeze pretrained weights, train only the new head.
  • Fine-tuning: Unfreeze all (or some) pretrained layers and train with a small learning rate.
  • Discriminative fine-tuning: Different learning rates per layer (lower for earlier layers).
•

Q131. What is catastrophic forgetting in neural networks?

When fine-tuned on new data, the model's performance on original training data degrades significantly. Solutions: EWC (Elastic Weight Consolidation), progressive networks, learning without forgetting, LoRA for LLM fine-tuning.

•

Q132. What is knowledge distillation in deep learning?

Train a small student network to mimic large teacher's output:
$$\mathcal{L} = \alpha \cdot \mathcal{L}{hard} + (1-\alpha) \cdot T^2 \cdot KL(q{student}^T | q_{teacher}^T)$$
$T$ = temperature (softer probability distributions). Student often achieves near-teacher performance at much lower cost.

•

Q133. What is adversarial training?

Include adversarially perturbed examples during training to improve robustness:
$$\min_\theta \mathbb{E}{(x,y)} \left[ \max{|\delta| \leq \epsilon} \mathcal{L}(f_\theta(x+\delta), y) \right]$$
PGD adversarial training is the gold standard but 3-10× slower than standard training.

•

Q134. What is implicit regularization in deep learning?

Properties of the optimizer (especially SGD) that implicitly regularize the model even without explicit regularization terms:
- SGD finds minimum-norm solutions in over-parameterized settings.
- Large learning rates prefer flatter minima.
These effects are still not completely understood theoretically.

•

Q135. What is neural tangent kernel (NTK)?

In the infinite-width limit, neural networks trained with gradient descent behave like kernel regression with the NTK. Provides theoretical grounding for: convergence analysis, generalization bounds, and understanding why over-parameterized networks generalize well.

•

Q136. What is curriculum learning?

Train the model on examples ordered from easy to hard (mimicking how humans learn). Benefits: faster convergence, better final accuracy for hard tasks. Self-paced learning automates difficulty scoring from model confidence.

•

Q137. What is test-time augmentation (TTA)?

# Average predictions over multiple augmented versions at inference
preds = []
for _ in range(10):
    augmented = augment(test_image)
    preds.append(model(augmented))
final_pred = torch.stack(preds).mean(0)

Reduces prediction variance, especially useful in competitions.

•

Q138. What is warm-up learning rate scheduling?

Start with a very small LR, linearly increase to target LR over first N steps. Prevents early training instability (large model divergence with random weights + large LR). Standard for Transformer training.

•

Q139. What is gradient accumulation and why use it?

Accumulate gradients over multiple mini-batches before updating weights — effectively simulates a larger batch size:

optimizer.zero_grad()
for i, (x, y) in enumerate(loader):
    loss = model(x, y) / accumulation_steps
    loss.backward()
    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()

Enables large-batch training on limited GPU memory.

•

Q140. What is automatic mixed precision (AMP) training?

Use float16 (or bfloat16) for forward pass and gradient computation, float32 for optimizer state:

scaler = torch.cuda.amp.GradScaler()
with torch.autocast(device_type="cuda"):
    output = model(input)
    loss = criterion(output, target)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

~2× speedup on modern GPUs with minimal accuracy loss.

NLP & Sequence Models (Q141–Q165)
•

Q141. What is word2vec and how does it work?

Learn word embeddings by predicting context from target (Skip-gram) or target from context (CBOW):
- Skip-gram: Maximize $P(\text{context}|\text{word})$.
- Negative sampling: Efficient approximation — distinguish real context from random noise.
Resulting embeddings capture semantic analogies: king - man + woman ≈ queen.

•

Q142. What is GloVe and how does it differ from word2vec?

GloVe uses global word co-occurrence statistics from the entire corpus:
$$\mathcal{L} = \sum_{i,j} f(X_{ij})(w_i^T \tilde{w}j + b_i + \tilde{b}_j - \log X{ij})^2$$
word2vec: local context windows. GloVe: global matrix factorization. GloVe often performs better on analogy tasks.

•

Q143. What is FastText and its advantage over word2vec?

Represents words as bags of character n-grams. Each word embedding = sum of its n-gram embeddings. Handles OOV (out-of-vocabulary) words naturally — can generate embeddings for unseen words.

•

Q144. What is the vanishing gradient problem in RNNs?

Gradients are multiplied by the recurrent weight matrix $W$ at every time step. If $|W| < 1$ → gradients vanish (long-range dependencies not learned). If $|W| > 1$ → explode. LSTM and GRU mitigate this with gating mechanisms.

•

Q145. What is the LSTM gate mechanism in detail?

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{(forget gate)}$$
$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{(input gate)}$$
$$\tilde{C}t = \tanh(W_C \cdot [h{t-1}, x_t] + b_C) \quad \text{(candidate values)}$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}t \quad \text{(cell update)}$$
$$o_t = \sigma(W_o \cdot [h{t-1}, x_t] + b_o), \quad h_t = o_t \odot \tanh(C_t)$$

•

Q146. What is a Bidirectional RNN?

Two RNNs — one processes the sequence forward, one backward. Output = concatenation of both hidden states:

self.rnn = nn.LSTM(input_size, hidden_size, bidirectional=True)
# Output size = 2 * hidden_size

Each position has context from the full sequence. Used in NER, sentiment analysis (but not language generation where future is unknown).

•

Q147. What is the Transformer encoder vs decoder?

EncoderDecoderEncoder-Decoder
  • Encoder: Self-attention + FFN; produces contextual representations of input. BERT uses encoder-only.
  • Decoder: Masked self-attention + cross-attention to encoder + FFN; generates output tokens. GPT uses decoder-only.
  • Encoder-Decoder: Machine translation (T5, BART). Separated for analysis but increasingly decoder-only is dominant.
•

Q148. What is positional encoding in Transformers and alternatives?

Sinusoidal (original)Learned absolute PERoPE (Rotary PE)ALiBi
  • Sinusoidal (original): Fixed mathematical functions of position. Generalizes to unseen lengths.
  • Learned absolute PE: Trainable embedding per position. Common in BERT.
  • RoPE (Rotary PE): Encodes relative position by rotating query/key vectors. Used in LLaMA, GPT-NeoX.
  • ALiBi: Adds position-scaled bias to attention logits. Extrapolates better to longer sequences.
•

Q149. What is masked language modeling (MLM) and causal language modeling (CLM)?

MLM (BERT-style)CLM (GPT-style)
  • MLM (BERT-style): 15% of tokens masked; model predicts them. Learns bidirectional representations. Cannot directly generate text.
  • CLM (GPT-style): Predict next token given previous tokens. Unidirectional. Natural for generation.
•

Q150. What is BERT and what are its pretraining tasks?

MLMNSP (Next Sentence Prediction)

Bidirectional Encoder Representations from Transformers:
1. MLM: Mask 15% of tokens, predict them.
2. NSP (Next Sentence Prediction): Predict if sentence B follows sentence A.
RoBERTa removed NSP, trained on 10× more data with full-sentence masking → better performance.

•

Q151. What is the GPT architecture and training objective?

Decoder-only Transformer trained with causal language modeling: predict the next token at every position. Pretrained on massive web text. At inference: autoregressive token sampling. Fine-tuned with RLHF for instruction following (InstructGPT → ChatGPT).

•

Q152. What is T5 (Text-to-Text Transfer Transformer)?

Frames every NLP task as a text-to-text problem: input = task prefix + text, output = text. "Translate English to German: The house is wonderful" → "Das Haus ist wunderbar." Encoder-decoder architecture, enabling generation for any task.

•

Q153. What is sentence transformer / sentence embeddings?

Fine-tune a Transformer (BERT-based) to produce fixed-size sentence embeddings for semantic similarity:
- Siamese/Triplet networks with cosine similarity loss.
- Models: all-MiniLM-L6-v2, all-mpnet-base-v2, E5, BGE.
Used for semantic search, RAG, clustering, deduplication.

•

Q154. What is cross-encoder vs bi-encoder for text matching?

Bi-encoderCross-encoder
  • Bi-encoder: Encode query and document independently → dot product. Fast but less accurate.
  • Cross-encoder: Concatenate query + document, encode jointly → classifier. Accurate but O(n·m) for n queries × m docs.
    Production: bi-encoder for retrieval, cross-encoder for reranking.
•

Q155. What is Byte-Pair Encoding (BPE) tokenization?

Start with character vocabulary, iteratively merge the most frequent pair of adjacent tokens until desired vocabulary size is reached. GPT uses BPE. Balances vocabulary size vs OOV rate. Handles morphologically rich languages better than word-level tokenization.

•

Q156. What is BLEU score?

Measures overlap between generated and reference text (n-gram precision):
$$BLEU = BP \cdot \exp\left(\sum_{n=1}^{N} w_n \log p_n\right)$$
BP = brevity penalty, $p_n$ = n-gram precision. BLEU 1-4 are standard. Limitations: doesn't capture semantic similarity, heavily penalizes synonyms.

•

Q157. What is ROUGE score?

ROUGE-NROUGE-L

Recall-oriented metric for summarization:
- ROUGE-N: N-gram recall between hypothesis and reference.
- ROUGE-L: Longest common subsequence ratio.
BLEU = precision-focused; ROUGE = recall-focused. BERTScore measures semantic (cosine) similarity using pretrained embeddings.

•

Q158. What is perplexity in language models?

Measures how well a probability model predicts a sample:
$$PP = 2^{-\frac{1}{N}\sum_{i=1}^N \log_2 P(w_i|w_{<i})}$$
Lower perplexity = better model. GPT-4 has much lower perplexity on open-domain text than GPT-2. Not comparable across different tokenizers.

•

Q159. What is nucleus sampling (top-p)?

Sample from the smallest set of tokens whose cumulative probability exceeds $p$:
- $p=1.0$: All vocabulary (random).
- $p=0.9$: Top 90% probability mass — dynamic vocabulary size.
More natural than top-k because it adapts to the distribution's entropy.

•

Q160. What is beam search and its limitations?

Maintain K candidate sequences (beams), extend each by all vocabulary tokens, keep top K by accumulated log-probability. More accurate than greedy decoding.
Limitations: tends toward generic/repetitive text; over-exploits high-frequency patterns. Modern LLMs prefer sampling over beam search for open-ended generation.

Production Deep Learning (Q161–Q200)
•

Q161. What is model pruning?

Magnitude pruningStructured pruning

Remove redundant weights (weight pruning) or entire filters/heads (structured pruning):
- Magnitude pruning: Remove weights with smallest |w|.
- Structured pruning: Remove entire neurons/heads → actual speedup without specialized hardware.
- After pruning, typically fine-tune to recover accuracy.

•

Q162. What is INT8 quantization-aware training (QAT)?

Simulate quantization effects during training by inserting fake quantization ops. The model learns to be robust to quantization before it's applied:

model = torch.quantization.prepare_qat(model)
# Train with fake quantized weights
model = torch.quantization.convert(model)  # Convert to actual INT8

Better accuracy than post-training quantization (PTQ).

•

Q163. What is ONNX and why is it used?

Open Neural Network Exchange: an open format for representing ML models. Export from PyTorch/TensorFlow, run with ONNX Runtime for optimized inference across platforms:

torch.onnx.export(model, dummy_input, "model.onnx", opset_version=17)
import onnxruntime as ort
sess = ort.InferenceSession("model.onnx")
•

Q164. What is TensorRT and when is it used?

NVIDIA's high-performance inference optimizer. Converts PyTorch/ONNX models to TRT engines:
- Graph optimization (layer fusion, kernel autotuning).
- Precision calibration (INT8/FP16).
- 2–10× latency reduction on NVIDIA GPUs vs vanilla PyTorch.

•

Q165. What is FlashAttention?

A hardware-aware exact attention algorithm that avoids materializing the full N×N attention matrix:
- Tiles computation to fit in GPU SRAM (fast memory).
- IO complexity: O(N²/B) vs O(N²) for standard attention.
- Enables 2-4× speedup and much lower memory usage for long sequences.

•

Q166. What is Grouped Query Attention (GQA)?

Intermediate between MHA (Multi-Head Attention) and MQA (Multi-Query Attention):
- Divide query heads into G groups.
- Each group shares one K/V head.
- GQA balances quality (vs MQA) and memory efficiency (vs MHA).
Used in LLaMA 3, Gemma.

•

Q167. What is KV Cache and how does it work?

During autoregressive generation, Keys and Values from all previous tokens are cached:
- Avoids recomputing attention for previously generated tokens.
- Memory grows linearly with sequence length.
- For 7B LLM: KV cache for 4K tokens can be several GB per request.

•

Q168. What is continuous batching in LLM serving?

Traditional static batching waits for all sequences in a batch to finish (padded to max length). Continuous batching (iteration-level scheduling) dynamically adds/removes sequences at each decoding step:
- In-flight batching: New requests join when existing ones finish.
- Maximizes GPU utilization (10-20× throughput vs static batching).
Implemented in vLLM, TensorRT-LLM.

•

Q169. What is PagedAttention in vLLM?

Inspired by OS virtual memory paging. KV cache is divided into fixed-size blocks (pages) that need not be contiguous. Eliminates memory fragmentation and enables memory sharing across beam search sequences. Core innovation in vLLM.

•

Q170. What is speculative decoding?

Use a small fast draft model to generate K tokens speculatively. A large verifier model checks all K tokens in one forward pass. Accept correct tokens, reject others:
- Draft model is ~10× faster.
- Net result: 2-3× speedup with identical output distribution.

•

Q171. What is tensor parallelism in multi-GPU training?

Split individual weight matrices across multiple GPUs:
- Column parallel: Split columns of $W_1$ across GPUs.
- Row parallel: Split rows of $W_2$ across GPUs.
Used in Megatron-LM for 100B+ model training. Requires fast NVLink bandwidth.

•

Q172. What is pipeline parallelism?

Split the model's layers across multiple GPUs. Each GPU processes one stage of the pipeline. Micro-batching reduces pipeline bubbles. Used alongside data parallelism in large-scale training (GPipe, PipeDream).

•

Q173. What is ZeRO (Zero Redundancy Optimizer)?

DeepSpeed's memory optimization — partitions optimizer states, gradients, and parameters across GPUs (ZeRO-1, 2, 3):
- ZeRO-1: Partition optimizer states.
- ZeRO-2: + Gradient partitioning.
- ZeRO-3: + Parameter partitioning.
ZeRO-3 enables training 1T+ parameter models on commodity GPUs.

•

Q174. What is Flash Decoding?

Optimizes the decoding phase of attention (when KV cache is long). Parallelizes across sequence length dimension (not batch) for attention computation. 8× speedup for long context decoding.

•

Q175. What is AWQ (Activation-aware Weight Quantization)?

Quantize weights to INT4 while preserving the precision of salient weights (identified by activation magnitude). Better accuracy than naive INT4 quantization:
- ~2× memory reduction vs INT8.
- <1% accuracy loss on most tasks.
- LLM AWQ: widely used for deploying 7B-70B models on consumer hardware.

•

Q176. What is LoRA and how does it enable parameter-efficient fine-tuning?

Low-Rank Adaptation: freeze pretrained weights, add trainable low-rank matrices to attention:
$$W = W_0 + BA, \quad B \in \mathbb{R}^{d \times r}, A \in \mathbb{R}^{r \times k}$$
- Typical $r=4-64$ ≪ $d$ (full rank).
- Only ~1-2% of parameters are trained.
- Can be merged into $W_0$ at inference (no overhead).

•

Q177. What is QLoRA?

4-bit quantized base model (NF4 quantization) + LoRA adapters in float16. Enables fine-tuning 65B parameter models on a single A100 GPU. Key innovations: NF4 (Normal Float 4), double quantization, paged optimizers.

•

Q178. What is DPO (Direct Preference Optimization)?

An alternative to RLHF that directly fine-tunes the LLM using human preference data (chosen vs rejected responses) without training a separate reward model:
$$\mathcal{L}{DPO} = -\mathbb{E}\left[\log\sigma\left(\beta\log\frac{\pi\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$
Simpler and more stable than PPO-based RLHF.

•

Q179. What is RLHF (Reinforcement Learning from Human Feedback)?

SFTReward modelPPO
  1. SFT: Fine-tune LLM on high-quality demonstrations.
  2. Reward model: Train on human comparisons of outputs.
  3. PPO: Fine-tune LLM with RL to maximize reward model score while staying close to SFT model (KL penalty).
    Used in ChatGPT, Claude, Gemini. Expensive but powerful alignment technique.
•

Q180. What is Constitutional AI (CAI)?

Anthropic's technique: model critiques its own outputs using a set of principles ("constitution"), revises them, and trains on revised outputs with AI-generated feedback. Reduces need for human labelers for harmlessness training.

•

Q181. What is the context length limitation of Transformers and solutions?

Attention is O(N²) in sequence length (quadratic). Solutions:
- Sparse attention (Longformer, BigBird): O(N).
- Long context fine-tuning with positional interpolation (LLaMA 2 → 4K to 32K).
- RoPE positional extension (NTK-aware scaling).
- Mamba / state space models: O(N).

Q182. What is instruction tuning?

Supervised fine-tuning on diverse instruction-following examples:

output: "Bonjour le monde"

Dramatically improves zero-shot generalization to new instructions. FLAN, Alpaca, LLaMA-Instruct are examples.

Q183. What is chain-of-thought prompting and how does it affect model training?

Prompting the model to produce intermediate reasoning steps before the final answer. Significantly improves performance on math/logic tasks. During training: include step-by-step reasoning in fine-tuning data (OpenAI's scratchpad, Gemini Flash thinking).

Q184. What is emergent behavior in LLMs?

Capabilities that appear suddenly at certain model scales without explicit training for those capabilities (few-shot learning, chain-of-thought, code generation). Predicted by scaling laws but the emergence threshold is difficult to predict for specific abilities.

Q185. What are scaling laws for neural language models?

Chinchilla (Hoffmann et al.) establishes compute-optimal training:
- Model parameters $N$ and training tokens $D$ should scale proportionally.
- For 1 FLOP budget $C$: $N_{opt} \propto C^{0.5}$, $D_{opt} \propto C^{0.5}$.
- Rule of thumb: Train on ~20 tokens per parameter.

Enables capability blending without additional GPU training.

Q192. What is CLIP and how does it work?

Trains an image encoder and text encoder jointly with a contrastive objective:
$$\mathcal{L} = -\frac{1}{N}\sum_i \log \frac{\exp(\text{sim}(i_i, t_i)/\tau)}{\sum_j \exp(\text{sim}(i_i, t_j)/\tau)}$$
Learns aligned image-text representations from 400M internet image-caption pairs. Zero-shot classification: compare image embedding to class description embeddings.

Q193. What is object detection evaluation metric — mAP?

Mean Average Precision across all object classes:
1. For each class, compute precision-recall curve.
2. Average Precision (AP) = area under the PR curve.
3. mAP = mean AP across all classes.
COCO uses mAP@[.5:.95] (average over 10 IoU thresholds). PASCAL VOC uses mAP@0.5.

•

Q194. What is panoptic segmentation?

Combines semantic segmentation (classify every pixel) and instance segmentation (delineate individual object instances) into a single unified output. Each pixel gets a semantic class + optional instance ID (if it belongs to a "thing" class).

Q195. What is Neural Radiance Fields (NeRF)?

Represent a 3D scene as a continuous volumetric radiance field $F: (x,y,z,\theta,\phi) \rightarrow (RGB, \sigma)$ modeled by an MLP. Rendered via differentiable volume rendering. Enables novel view synthesis from limited 2D images.

Q196. What is image generation evaluation metric (FID)?

Fréchet Inception Distance: measures statistical distance between real and generated image distributions in Inception feature space:
$$FID = |\mu_r - \mu_g|^2 + Tr(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2})$$
Lower = better. Sensitive to both image quality and diversity (contrast to IS which only measures quality).

Q197. What is text-to-image generation pipeline?

  1. Text → CLIP/T5 text embedding.
  2. Latent diffusion: u-Net denoising in compressed latent space.
  3. VAE decoder: Decode latent to pixel space.
    SDXL, Stable Diffusion 3 use transformer-based DiT (Diffusion Transformer) instead of U-Net.

Q198. What is RLVR (Reinforcement Learning with Verifiable Rewards)?

Train reasoning models (math, code) using RL with a verifier that checks exact correctness (not an LLM judge). Groups of rollouts; correct answers get positive reward. Used in DeepSeek-R1, OpenAI o1. Produces chain-of-thought reasoning without step-level annotations.

  • Standard chat: Outputs directly, fast.

Replace dense FFN layers with a router + multiple expert FFNs. At each token, the router selects top-K experts (typically 2 out of 8-64). Only selected experts activate → dense model capacity at sparse compute:
- Mixtral 8×7B activates ~13B params per token out of 47B total.
- GPT-4 (rumored): MoE architecture enables scale beyond dense models.

def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

from collections import deque

def bfs(graph, start):
    visited = set([start])
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return order

def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    return visited

def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

# ═══════════════ TOPOLOGICAL SORT ═══════════════
def topological_sort(graph, num_nodes):
    """Kahn's algorithm — BFS-based."""
    in_degree = [0] * num_nodes
    for u in graph:
        for v in graph[u]:
            in_degree[v] += 1

    queue = deque([i for i in range(num_nodes) if in_degree[i] == 0])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph.get(node, []):
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return order if len(order) == num_nodes else []  # Empty if cycle

def insert_bst(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = insert_bst(root.left, val)
    elif val > root.val:
        root.right = insert_bst(root.right, val)
    return root

def search_bst(root, val):
    if not root or root.val == val:
        return root
    if val < root.val:
        return search_bst(root.left, val)
    return search_bst(root.right, val)

def inorder_traversal(root):
    """Returns sorted elements of BST."""
    if not root:
        return []
    return inorder_traversal(root.left) + [root.val] + inorder_traversal(root.right)

def is_valid_bst(root, min_val=float('-inf'), max_val=float('inf')):
    """Validate if tree is a valid BST."""
    if not root:
        return True
    if root.val <= min_val or root.val >= max_val:
        return False
    return (is_valid_bst(root.left, min_val, root.val) and
            is_valid_bst(root.right, root.val, max_val))

def find_kth_smallest(root, k):
    """Find kth smallest element in BST — in-order traversal."""
    stack = []
    current = root
    count = 0

    while stack or current:
        while current:
            stack.append(current)
            current = current.left
        current = stack.pop()
        count += 1
        if count == k:
            return current.val
        current = current.right
    return None

# ═══════════════ APPROACH 1: MINIMAX WITH ALPHA-BETA ═══════════════

def minimax(state, depth, is_maximizing, alpha, beta):
    """Classic game tree search with pruning."""
    if depth == 0 or state.is_terminal():
        return state.evaluate()

    if is_maximizing:
        max_eval = float('-inf')
        for move in state.get_legal_moves():
            new_state = state.apply_move(move)
            eval_score = minimax(new_state, depth-1, False, alpha, beta)
            max_eval = max(max_eval, eval_score)
            alpha = max(alpha, eval_score)
            if beta <= alpha:
                break  # Prune
        return max_eval
    else:
        min_eval = float('inf')
        for move in state.get_legal_moves():
            new_state = state.apply_move(move)
            eval_score = minimax(new_state, depth-1, True, alpha, beta)
            min_eval = min(min_eval, eval_score)
            beta = min(beta, eval_score)
            if beta <= alpha:
                break  # Prune
        return min_eval

# ═══════════════ APPROACH 2: REINFORCEMENT LEARNING ═══════════════

import numpy as np

class QLearningAgent:
    def __init__(self, actions, lr=0.1, gamma=0.95, epsilon=0.1):
        self.q_table = {}  # state → action values
        self.lr = lr
        self.gamma = gamma
        self.epsilon = epsilon
        self.actions = actions

    def get_q(self, state, action):
        return self.q_table.get((state, action), 0.0)

    def choose_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.choice(self.actions)

        q_values = [self.get_q(state, a) for a in self.actions]
        return self.actions[np.argmax(q_values)]

    def update(self, state, action, reward, next_state):
        """Q-learning update rule."""
        best_next = max(self.get_q(next_state, a) for a in self.actions)
        current = self.get_q(state, action)

        # Q(s,a) ← Q(s,a) + α[r + γ·max_a'Q(s',a') - Q(s,a)]
        self.q_table[(state, action)] = current + self.lr * (
            reward + self.gamma * best_next - current
        )

# Convergence: Q-learning converges if:
# 1. All state-action pairs visited infinitely often
# 2. Learning rate decreases appropriately (Σα = ∞, Σα² < ∞)
# 3. MDP is finite

Will the approach converge? - Minimax: Always terminates (bounded by tree depth), but may not find optimal play without sufficient depth - Q-learning: Converges to optimal policy given sufficient exploration (ε-greedy) and proper learning rate decay - Deep RL (DQN): No convergence guarantees, but empirically works with experience replay + target networks

Q17. Implement beam search for sequence generation (Google — AI Engineer)

Question: Implement beam search decoding for a language model. Compare with greedy decoding.

Solution:

import numpy as np

def greedy_decode(model_fn, start_token, max_len=20, eos_token=2):
    """Greedy: always pick highest probability token."""
    sequence = [start_token]
    for _ in range(max_len):
        logits = model_fn(sequence)
        next_token = np.argmax(logits)
        sequence.append(next_token)
        if next_token == eos_token:
            break
    return sequence

def beam_search(model_fn, start_token, beam_width=3, max_len=20, eos_token=2):
    """
    Beam search: maintain top-k sequences at each step.

    Args:
        model_fn: function(sequence) → logits over vocab
        beam_width: number of beams to keep
    """
    # Each beam: (log_probability, sequence)
    beams = [(0.0, [start_token])]
    completed = []

    for step in range(max_len):
        all_candidates = []

        for score, seq in beams:
            if seq[-1] == eos_token:
                completed.append((score, seq))
                continue

            logits = model_fn(seq)
            log_probs = logits - np.log(np.sum(np.exp(logits)))  # log softmax

            # Get top-k tokens for this beam
            top_k = np.argsort(log_probs)[-beam_width:]

            for token in top_k:
                new_score = score + log_probs[token]
                new_seq = seq + [token]
                all_candidates.append((new_score, new_seq))

        if not all_candidates:
            break

        # Keep top beam_width candidates
        all_candidates.sort(key=lambda x: x[0], reverse=True)
        beams = all_candidates[:beam_width]

    # Add remaining beams to completed
    completed.extend(beams)

    # Length-normalize scores
    completed = [(score / len(seq), seq) for score, seq in completed]
    completed.sort(key=lambda x: x[0], reverse=True)

    return completed[0][1] if completed else beams[0][1]

# Simulate with dummy model
vocab_size = 100
def dummy_model(sequence):
    np.random.seed(len(sequence))
    return np.random.randn(vocab_size)

greedy_result = greedy_decode(dummy_model, start_token=1)
beam_result = beam_search(dummy_model, start_token=1, beam_width=5)
print(f"Greedy: {greedy_result[:10]}...")
print(f"Beam:   {beam_result[:10]}...")

Key Insight: Greedy decoding is suboptimal — local best ≠ global best. Beam search explores multiple paths. Length normalization prevents bias toward shorter sequences. Nucleus sampling (top-p) is preferred for creative generation.

import numpy as np

class ImageAugmentor:
    """Custom image augmentation pipeline."""

    def __init__(self, transforms=None):
        self.transforms = transforms or []

    def add(self, fn, probability=0.5):
        self.transforms.append((fn, probability))
        return self

    def __call__(self, image):
        for fn, prob in self.transforms:
            if np.random.random() < prob:
                image = fn(image)
        return image

def random_horizontal_flip(image):
    return image[:, ::-1, :]

def random_vertical_flip(image):
    return image[::-1, :, :]

def random_rotation(image, max_angle=30):
    """Rotate image by random angle."""
    angle = np.random.uniform(-max_angle, max_angle)
    h, w = image.shape[:2]
    cy, cx = h // 2, w // 2

    # Rotation matrix
    theta = np.radians(angle)
    cos_t, sin_t = np.cos(theta), np.sin(theta)

    rotated = np.zeros_like(image)
    for y in range(h):
        for x in range(w):
            # Inverse mapping
            src_x = cos_t * (x - cx) + sin_t * (y - cy) + cx
            src_y = -sin_t * (x - cx) + cos_t * (y - cy) + cy

            if 0 <= int(src_x) < w and 0 <= int(src_y) < h:
                rotated[y, x] = image[int(src_y), int(src_x)]

    return rotated

def random_brightness(image, factor_range=(0.7, 1.3)):
    factor = np.random.uniform(*factor_range)
    return np.clip(image * factor, 0, 255).astype(np.uint8)

def random_crop(image, crop_ratio=0.8):
    h, w = image.shape[:2]
    new_h, new_w = int(h * crop_ratio), int(w * crop_ratio)
    top = np.random.randint(0, h - new_h)
    left = np.random.randint(0, w - new_w)
    cropped = image[top:top+new_h, left:left+new_w]
    # Resize back to original (nearest neighbor)
    result = np.zeros_like(image)
    for y in range(h):
        for x in range(w):
            sy = int(y * new_h / h)
            sx = int(x * new_w / w)
            result[y, x] = cropped[sy, sx]
    return result

def cutout(image, n_holes=1, hole_size=16):
    """Random erasing / cutout augmentation."""
    h, w = image.shape[:2]
    augmented = image.copy()

    for _ in range(n_holes):
        cy = np.random.randint(0, h)
        cx = np.random.randint(0, w)
        y1 = max(0, cy - hole_size // 2)
        y2 = min(h, cy + hole_size // 2)
        x1 = max(0, cx - hole_size // 2)
        x2 = min(w, cx + hole_size // 2)
        augmented[y1:y2, x1:x2] = 0  # Or random noise

    return augmented

def mixup(image1, image2, label1, label2, alpha=0.2):
    """Mixup: blend two images and labels."""
    lam = np.random.beta(alpha, alpha)
    mixed_image = (lam * image1 + (1 - lam) * image2).astype(np.uint8)
    mixed_label = lam * label1 + (1 - lam) * label2
    return mixed_image, mixed_label

Q19. Implement BFS and DFS for graph problems (IBM — AI Engineer)

Question: Given a graph, implement BFS (shortest path) and DFS (cycle detection). Apply to AI knowledge graph traversal.

Solution:

from collections import deque, defaultdict

class Graph:
    def __init__(self, directed=False):
        self.adj = defaultdict(list)
        self.directed = directed

    def add_edge(self, u, v, weight=1):
        self.adj[u].append((v, weight))
        if not self.directed:
            self.adj[v].append((u, weight))

    def bfs(self, start, target=None):
        """BFS: shortest path in unweighted graph. O(V + E)"""
        visited = {start}
        queue = deque([(start, [start])])
        parent = {start: None}

        while queue:
            node, path = queue.popleft()

            if node == target:
                return path

            for neighbor, _ in self.adj[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    parent[neighbor] = node
                    queue.append((neighbor, path + [neighbor]))

        return None if target else visited

    def dfs(self, start, visited=None):
        """DFS: traversal and cycle detection. O(V + E)"""
        if visited is None:
            visited = set()

        visited.add(start)
        result = [start]

        for neighbor, _ in self.adj[start]:
            if neighbor not in visited:
                result.extend(self.dfs(neighbor, visited))

        return result

    def has_cycle(self):
        """Detect cycle using DFS coloring."""
        WHITE, GRAY, BLACK = 0, 1, 2
        color = defaultdict(int)

        def dfs_cycle(node):
            color[node] = GRAY
            for neighbor, _ in self.adj[node]:
                if color[neighbor] == GRAY:
                    return True  # Back edge → cycle
                if color[neighbor] == WHITE and dfs_cycle(neighbor):
                    return True
            color[node] = BLACK
            return False

        for node in self.adj:
            if color[node] == WHITE:
                if dfs_cycle(node):
                    return True
        return False

    def dijkstra(self, start):
        """Shortest path in weighted graph. O((V + E) log V)"""
        import heapq

        distances = {start: 0}
        pq = [(0, start)]
        parent = {start: None}

        while pq:
            dist, node = heapq.heappop(pq)

            if dist > distances.get(node, float('inf')):
                continue

            for neighbor, weight in self.adj[node]:
                new_dist = dist + weight
                if new_dist < distances.get(neighbor, float('inf')):
                    distances[neighbor] = new_dist
                    parent[neighbor] = node
                    heapq.heappush(pq, (new_dist, neighbor))

        return distances, parent

import numpy as np

# ═══════ 1. Binary Cross-Entropy ═══════
def binary_cross_entropy(y_true, y_pred, eps=1e-7):
    """Standard classification loss."""
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# ═══════ 2. Focal Loss ═══════
def focal_loss(y_true, y_pred, gamma=2.0, alpha=0.25, eps=1e-7):
    """Focal loss for class imbalance. Down-weights easy examples."""
    y_pred = np.clip(y_pred, eps, 1 - eps)

    # pt = p if y=1, else (1-p)
    pt = np.where(y_true == 1, y_pred, 1 - y_pred)
    alpha_t = np.where(y_true == 1, alpha, 1 - alpha)

    loss = -alpha_t * (1 - pt) ** gamma * np.log(pt)
    return np.mean(loss)

# ═══════ 3. Contrastive Loss (Siamese Networks) ═══════
def contrastive_loss(embedding1, embedding2, label, margin=1.0):
    """
    label=1: similar pair (minimize distance)
    label=0: dissimilar pair (maximize distance up to margin)
    """
    distance = np.sqrt(np.sum((embedding1 - embedding2) ** 2, axis=1))

    loss = label * distance ** 2 + \
           (1 - label) * np.maximum(0, margin - distance) ** 2

    return np.mean(loss) / 2

# ═══════ 4. Triplet Loss ═══════
def triplet_loss(anchor, positive, negative, margin=0.2):
    """
    Minimize distance(anchor, positive)
    Maximize distance(anchor, negative)
    """
    pos_dist = np.sum((anchor - positive) ** 2, axis=1)
    neg_dist = np.sum((anchor - negative) ** 2, axis=1)

    loss = np.maximum(0, pos_dist - neg_dist + margin)
    return np.mean(loss)

# ═══════ 5. InfoNCE / Contrastive Loss (CLIP-style) ═══════
def info_nce_loss(features_a, features_b, temperature=0.07):
    """
    Contrastive loss for multimodal learning (CLIP).
    Diagonal entries are positive pairs.
    """
    # Normalize
    features_a = features_a / np.linalg.norm(features_a, axis=1, keepdims=True)
    features_b = features_b / np.linalg.norm(features_b, axis=1, keepdims=True)

    # Similarity matrix
    logits = features_a @ features_b.T / temperature

    # Labels: diagonal = positive pairs
    n = len(features_a)
    labels = np.arange(n)

    # Cross-entropy for both directions
    def cross_entropy(logits, labels):
        exp = np.exp(logits - np.max(logits, axis=1, keepdims=True))
        probs = exp / exp.sum(axis=1, keepdims=True)
        return -np.mean(np.log(probs[np.arange(n), labels] + 1e-8))

    loss = (cross_entropy(logits, labels) + cross_entropy(logits.T, labels)) / 2
    return loss

    STRATEGIES = {
        'feature_extraction': 'Freeze all pretrained layers, train only new head',
        'fine_tune_head': 'Freeze backbone, fine-tune last few layers + head',
        'full_fine_tune': 'Fine-tune entire network with discriminative LR',
        'progressive_unfreeze': 'Gradually unfreeze layers during training'
    }

    def __init__(self, pretrained_model, num_classes, strategy='fine_tune_head'):
        self.model = pretrained_model
        self.strategy = strategy
        self.num_classes = num_classes
        self._modify_head(num_classes)
        self._apply_strategy()

    def _modify_head(self, num_classes):
        """Replace the classification head."""
        # For ResNet-like models
        if hasattr(self.model, 'fc'):
            in_features = self.model.fc.in_features
            self.model.fc = nn.Sequential(
                nn.Dropout(0.3),
                nn.Linear(in_features, 256),
                nn.ReLU(),
                nn.Dropout(0.2),
                nn.Linear(256, num_classes)
            )

    def _apply_strategy(self):
        if self.strategy == 'feature_extraction':
            # Freeze everything except head
            for param in self.model.parameters():
                param.requires_grad = False
            for param in self.model.fc.parameters():
                param.requires_grad = True

        elif self.strategy == 'fine_tune_head':
            # Freeze early layers, fine-tune last block + head
            for param in self.model.parameters():
                param.requires_grad = False
            # Unfreeze last layer group
            if hasattr(self.model, 'layer4'):
                for param in self.model.layer4.parameters():
                    param.requires_grad = True
            for param in self.model.fc.parameters():
                param.requires_grad = True

        """Discriminative learning rates for fine-tuning."""
        if self.strategy == 'full_fine_tune':
            param_groups = []

            # Lower LR for pretrained layers
            pretrained_params = []
            head_params = []
            for name, param in self.model.named_parameters():
                if 'fc' in name:
                    head_params.append(param)
                else:
                    pretrained_params.append(param)

                {'params': pretrained_params, 'lr': base_lr / 10},
                {'params': head_params, 'lr': base_lr}

            return torch.optim.Adam(trainable, lr=base_lr)

import numpy as np
import re
from collections import Counter, defaultdict
from math import log

class TextPreprocessor:
    def __init__(self, lowercase=True, remove_punct=True,
                 remove_stopwords=True, stemming=False):
        self.lowercase = lowercase
        self.remove_punct = remove_punct
        self.remove_stopwords = remove_stopwords
        self.stopwords = {'the', 'is', 'at', 'which', 'on', 'a', 'an', 'and',
                         'or', 'but', 'in', 'with', 'to', 'for', 'of', 'this',
                         'that', 'it', 'by', 'from', 'as', 'are', 'was', 'be'}

    def preprocess(self, text):
        if self.lowercase:
            text = text.lower()
        if self.remove_punct:
            text = re.sub(r'[^\w\s]', '', text)
        tokens = text.split()
        if self.remove_stopwords:
            tokens = [t for t in tokens if t not in self.stopwords]
        return tokens

class TFIDF:
    def __init__(self):
        self.vocab = {}
        self.idf = {}
        self.preprocessor = TextPreprocessor()

    def fit(self, documents):
        """Compute IDF from corpus."""
        n_docs = len(documents)
        doc_freq = Counter()

        # Build vocabulary and document frequency
        all_tokens = set()
        for doc in documents:
            tokens = self.preprocessor.preprocess(doc)
            unique_tokens = set(tokens)
            for token in unique_tokens:
                doc_freq[token] += 1
            all_tokens.update(tokens)

        # Create vocabulary mapping
        self.vocab = {token: idx for idx, token in enumerate(sorted(all_tokens))}

        # IDF = log(N / (1 + df))  — smoothed
        self.idf = {token: log(n_docs / (1 + df))
                     for token, df in doc_freq.items()}

        return self

    def transform(self, documents):
        """Convert documents to TF-IDF matrix."""
        matrix = np.zeros((len(documents), len(self.vocab)))

        for doc_idx, doc in enumerate(documents):
            tokens = self.preprocessor.preprocess(doc)
            tf = Counter(tokens)
            n_tokens = len(tokens)

            for token, count in tf.items():
                if token in self.vocab:
                    col_idx = self.vocab[token]
                    tf_val = count / n_tokens  # Normalized TF
                    idf_val = self.idf.get(token, 0)
                    matrix[doc_idx, col_idx] = tf_val * idf_val

        return matrix

    def fit_transform(self, documents):
        self.fit(documents)
        return self.transform(documents)

    def cosine_similarity(self, vec1, vec2):
        """Compute cosine similarity between two TF-IDF vectors."""
        dot = np.dot(vec1, vec2)
        norm1 = np.linalg.norm(vec1)
        norm2 = np.linalg.norm(vec2)
        return dot / (norm1 * norm2 + 1e-8)

import numpy as np

class LayerNorm:
    def __init__(self, d_model, eps=1e-6):
        self.gamma = np.ones(d_model)
        self.beta = np.zeros(d_model)
        self.eps = eps

    def forward(self, x):
        mean = x.mean(axis=-1, keepdims=True)
        std = x.std(axis=-1, keepdims=True)
        return self.gamma * (x - mean) / (std + self.eps) + self.beta

class FeedForward:
    def __init__(self, d_model, d_ff=None):
        d_ff = d_ff or 4 * d_model
        self.W1 = np.random.randn(d_model, d_ff) * 0.02
        self.b1 = np.zeros(d_ff)
        self.W2 = np.random.randn(d_ff, d_model) * 0.02
        self.b2 = np.zeros(d_model)

    def forward(self, x):
        hidden = np.maximum(0, x @ self.W1 + self.b1)  # ReLU / GELU
        return hidden @ self.W2 + self.b2

class SelfAttention:
    def __init__(self, d_model, n_heads):
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        self.W_q = np.random.randn(d_model, d_model) * 0.02
        self.W_k = np.random.randn(d_model, d_model) * 0.02
        self.W_v = np.random.randn(d_model, d_model) * 0.02
        self.W_o = np.random.randn(d_model, d_model) * 0.02

    def forward(self, x, mask=None):
        batch, seq_len, _ = x.shape

        Q = (x @ self.W_q).reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        K = (x @ self.W_k).reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)
        V = (x @ self.W_v).reshape(batch, seq_len, self.n_heads, self.d_k).transpose(0, 2, 1, 3)

        scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(self.d_k)

        if mask is not None:
            scores = np.where(mask == 0, -1e9, scores)

        exp = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        attn = exp / exp.sum(axis=-1, keepdims=True)

        out = (attn @ V).transpose(0, 2, 1, 3).reshape(batch, seq_len, self.d_model)
        return out @ self.W_o

class TransformerEncoderBlock:
    """Pre-LN Transformer Encoder Block."""

    def __init__(self, d_model, n_heads, d_ff=None, dropout_rate=0.1):
        self.attention = SelfAttention(d_model, n_heads)
        self.ff = FeedForward(d_model, d_ff)
        self.norm1 = LayerNorm(d_model)
        self.norm2 = LayerNorm(d_model)
        self.dropout_rate = dropout_rate

    def _dropout(self, x, training=True):
        if not training:
            return x
        mask = (np.random.random(x.shape) > self.dropout_rate).astype(float)
        return x * mask / (1 - self.dropout_rate)

    def forward(self, x, mask=None, training=True):
        # Pre-LN: Norm → Attention → Residual
        normed = self.norm1.forward(x)
        attn_out = self.attention.forward(normed, mask)
        x = x + self._dropout(attn_out, training)

        # Pre-LN: Norm → FFN → Residual
        normed = self.norm2.forward(x)
        ff_out = self.ff.forward(normed)
        x = x + self._dropout(ff_out, training)

        return x

class TransformerEncoder:
    """Stack of Transformer Encoder blocks."""

    def __init__(self, n_layers, d_model, n_heads, vocab_size, max_seq_len):
        self.embedding = np.random.randn(vocab_size, d_model) * 0.02
        self.pos_encoding = self._positional_encoding(max_seq_len, d_model)
        self.layers = [TransformerEncoderBlock(d_model, n_heads) for _ in range(n_layers)]

    def _positional_encoding(self, max_len, d_model):
        pe = np.zeros((max_len, d_model))
        position = np.arange(max_len)[:, np.newaxis]
        div_term = np.exp(np.arange(0, d_model, 2) * -(np.log(10000.0) / d_model))

        pe[:, 0::2] = np.sin(position * div_term)
        pe[:, 1::2] = np.cos(position * div_term)
        return pe

    def forward(self, token_ids, mask=None):
        seq_len = token_ids.shape[1]
        x = self.embedding[token_ids] + self.pos_encoding[:seq_len]

        for layer in self.layers:
            x = layer.forward(x, mask)

        return x

import numpy as np
from collections import defaultdict

class FairnessAuditor:
    """Compute fairness metrics across demographic groups."""

    def __init__(self, y_true, y_pred, y_prob, sensitive_attr):
        self.y_true = np.array(y_true)
        self.y_pred = np.array(y_pred)
        self.y_prob = np.array(y_prob)
        self.sensitive = np.array(sensitive_attr)
        self.groups = np.unique(self.sensitive)

    def demographic_parity(self):
        """Equal positive prediction rates across groups.
        Ratio of P(Y_hat=1 | A=a) across groups."""
        rates = {}
        for group in self.groups:
            mask = self.sensitive == group
            rates[group] = np.mean(self.y_pred[mask])

        min_rate = min(rates.values())
        max_rate = max(rates.values())

        return {
            'group_rates': rates,
            'ratio': min_rate / max_rate if max_rate > 0 else 0,
            'fair': min_rate / max_rate >= 0.8 if max_rate > 0 else True
        }

    def equalized_odds(self):
        """Equal TPR and FPR across groups."""
        metrics = {}
        for group in self.groups:
            mask = self.sensitive == group
            y_t = self.y_true[mask]
            y_p = self.y_pred[mask]

            tp = np.sum((y_p == 1) & (y_t == 1))
            fn = np.sum((y_p == 0) & (y_t == 1))
            fp = np.sum((y_p == 1) & (y_t == 0))
            tn = np.sum((y_p == 0) & (y_t == 0))

            tpr = tp / (tp + fn) if (tp + fn) > 0 else 0
            fpr = fp / (fp + tn) if (fp + tn) > 0 else 0

            metrics[group] = {'tpr': tpr, 'fpr': fpr}

        tpr_values = [m['tpr'] for m in metrics.values()]
        fpr_values = [m['fpr'] for m in metrics.values()]

        return {
            'group_metrics': metrics,
            'tpr_ratio': min(tpr_values) / max(tpr_values) if max(tpr_values) > 0 else 0,
            'fpr_ratio': min(fpr_values) / max(fpr_values) if max(fpr_values) > 0 else 0
        }

    def calibration(self, n_bins=10):
        """Calibration: predicted probability matches true frequency."""
        results = {}
        for group in self.groups:
            mask = self.sensitive == group
            probs = self.y_prob[mask]
            labels = self.y_true[mask]

            bin_edges = np.linspace(0, 1, n_bins + 1)
            calibration = []

            for i in range(n_bins):
                bin_mask = (probs >= bin_edges[i]) & (probs < bin_edges[i + 1])
                if np.any(bin_mask):
                    avg_pred = np.mean(probs[bin_mask])
                    avg_true = np.mean(labels[bin_mask])
                    calibration.append({
                        'predicted': avg_pred,
                        'actual': avg_true,
                        'count': int(np.sum(bin_mask))
                    })

            results[group] = calibration

        return results

    def full_audit(self):
        """Run complete fairness audit."""
        dp = self.demographic_parity()
        eo = self.equalized_odds()

        print("=" * 50)
        print("FAIRNESS AUDIT REPORT")
        print("=" * 50)

        print("\n📊 Demographic Parity:")
        for group, rate in dp['group_rates'].items():
            print(f"  {group}: {rate:.4f}")
        print(f"  Ratio: {dp['ratio']:.4f} {'✅' if dp['fair'] else '❌'}")

        print("\n📊 Equalized Odds:")
        for group, m in eo['group_metrics'].items():
            print(f"  {group}: TPR={m['tpr']:.4f}, FPR={m['fpr']:.4f}")
        print(f"  TPR ratio: {eo['tpr_ratio']:.4f}")
        print(f"  FPR ratio: {eo['fpr_ratio']:.4f}")

        return {'demographic_parity': dp, 'equalized_odds': eo}

auditor = FairnessAuditor(y_true, y_pred, y_prob, sensitive)
auditor.full_audit()

Key Insight: Demographic parity: equal positive rates. Equalized odds: equal error rates. These can conflict — it's mathematically impossible to satisfy all fairness criteria simultaneously (Chouldechova's impossibility theorem). Choose based on context: lending → equalized odds; hiring → demographic parity.

Q27. Build a complete text classification pipeline with transformers (TCS — AI Engineer)

Question: Design an end-to-end text classification system using pre-trained transformers, including data preprocessing, fine-tuning, and evaluation.

Solution:

import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
from typing import List, Dict, Tuple
import re

class TextClassificationPipeline:
    """End-to-end text classification with transformers."""

    def __init__(self, num_classes: int, model_name: str = "bert-base"):
        self.num_classes = num_classes
        self.model_name = model_name

    def preprocess(self, texts: List[str]) -> List[str]:
        """Clean and normalize text data."""
        cleaned = []
        for text in texts:
            t = text.lower()
            t = re.sub(r'http\S+|www\S+', '[URL]', t)  # URLs
            t = re.sub(r'\S+@\S+', '[EMAIL]', t)  # Emails
            t = re.sub(r'[^\w\s\[\]]', ' ', t)  # Special chars
            t = re.sub(r'\s+', ' ', t).strip()
            cleaned.append(t)
        return cleaned

    def build_classifier(self, hidden_size: int = 768) -> nn.Module:
        """Build classification head on top of transformer."""
        class TransformerClassifier(nn.Module):
            def __init__(self, base_model, num_classes, hidden_size):
                super().__init__()
                self.base = base_model
                self.dropout = nn.Dropout(0.3)
                self.classifier = nn.Sequential(
                    nn.Linear(hidden_size, 256),
                    nn.ReLU(),
                    nn.Dropout(0.1),
                    nn.Linear(256, num_classes)
                )
                # Freeze base initially
                for param in self.base.parameters():
                    param.requires_grad = False

            def forward(self, input_ids, attention_mask):
                outputs = self.base(input_ids, attention_mask=attention_mask)
                cls_output = outputs.last_hidden_state[:, 0, :]  # [CLS] token
                return self.classifier(self.dropout(cls_output))

            def unfreeze_last_n_layers(self, n=2):
                layers = list(self.base.parameters())
                for param in layers[-n*2:]:  # Each layer has weight + bias
                    param.requires_grad = True

        return TransformerClassifier

    def train_loop(self, model, train_loader, val_loader,
                   epochs=3, lr=2e-5):
        """Training loop with gradual unfreezing."""
        optimizer = torch.optim.AdamW(
            filter(lambda p: p.requires_grad, model.parameters()), lr=lr
        )
        criterion = nn.CrossEntropyLoss()
        scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, epochs)

        best_val_acc = 0
        for epoch in range(epochs):
            model.train()
            total_loss, correct, total = 0, 0, 0

            for batch in train_loader:
                optimizer.zero_grad()
                logits = model(batch['input_ids'], batch['attention_mask'])
                loss = criterion(logits, batch['labels'])
                loss.backward()
                torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                optimizer.step()

                total_loss += loss.item()
                correct += (logits.argmax(1) == batch['labels']).sum().item()
                total += len(batch['labels'])

            # Validation
            val_acc = self.evaluate(model, val_loader)
            print(f"Epoch {epoch+1}: Loss={total_loss/len(train_loader):.4f}, "
                  f"Train Acc={correct/total:.3f}, Val Acc={val_acc:.3f}")

            if val_acc > best_val_acc:
                best_val_acc = val_acc
                torch.save(model.state_dict(), "best_model.pt")

            # Gradual unfreezing after first epoch
            if epoch == 0:
                model.unfreeze_last_n_layers(2)
                optimizer.add_param_group({
                    'params': filter(lambda p: p.requires_grad, model.base.parameters()),
                    'lr': lr / 10
                })

            scheduler.step()
        return best_val_acc

    def evaluate(self, model, dataloader):
        model.eval()
        correct, total = 0, 0
        with torch.no_grad():
            for batch in dataloader:
                logits = model(batch['input_ids'], batch['attention_mask'])
                correct += (logits.argmax(1) == batch['labels']).sum().item()
                total += len(batch['labels'])
        return correct / total

# Best practices:
# 1. Start with frozen base, unfreeze gradually (discriminative learning rates)
# 2. Use learning rate warmup + cosine decay
# 3. Gradient clipping (max_norm=1.0) for stability
# 4. Label smoothing for better generalization

Key Insight: For text classification with transformers: (1) freeze base, train head → (2) unfreeze last 2 layers with 10x lower LR → (3) optionally fine-tune all layers. This prevents catastrophic forgetting. Use gradient clipping and cosine LR schedule. For production: distill to smaller model (DistilBERT) for latency-sensitive deployments.

Q28. Implement object detection pipeline (Infosys — AI Engineer)

Question: Build an object detection system using anchor-based and anchor-free approaches. Explain NMS (Non-Max Suppression).

Solution:

import numpy as np
from typing import List, Tuple, Dict

def iou(box1: np.ndarray, box2: np.ndarray) -> float:
    """Intersection over Union for two boxes [x1, y1, x2, y2]."""
    x1 = max(box1[0], box2[0])
    y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2])
    y2 = min(box1[3], box2[3])

    intersection = max(0, x2 - x1) * max(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - intersection

    return intersection / union if union > 0 else 0

def non_max_suppression(boxes: np.ndarray, scores: np.ndarray,
                        iou_threshold: float = 0.5) -> List[int]:
    """NMS: Remove overlapping detections, keep highest confidence."""
    if len(boxes) == 0:
        return []

    # Sort by confidence (descending)
    order = scores.argsort()[::-1]
    keep = []

    while len(order) > 0:
        current = order[0]
        keep.append(current)

        if len(order) == 1:
            break

        # Compute IoU of current box with all remaining
        remaining = order[1:]
        ious = np.array([iou(boxes[current], boxes[r]) for r in remaining])

        # Keep only boxes with IoU below threshold
        order = remaining[ious < iou_threshold]

    return keep

def generate_anchors(feature_map_size: Tuple[int, int],
                     scales: List[float] = [32, 64, 128],
                     ratios: List[float] = [0.5, 1.0, 2.0],
                     stride: int = 16) -> np.ndarray:
    """Generate anchor boxes for a feature map."""
    h, w = feature_map_size
    anchors = []

    for y in range(h):
        for x in range(w):
            cx = (x + 0.5) * stride
            cy = (y + 0.5) * stride

            for scale in scales:
                for ratio in ratios:
                    anchor_w = scale * np.sqrt(ratio)
                    anchor_h = scale / np.sqrt(ratio)
                    anchors.append([
                        cx - anchor_w / 2, cy - anchor_h / 2,
                        cx + anchor_w / 2, cy + anchor_h / 2
                    ])

    return np.array(anchors)

# Evaluation metrics
def mean_average_precision(predictions: List[Dict],
                            ground_truths: List[Dict],
                            iou_threshold: float = 0.5) -> float:
    """mAP: Primary object detection metric."""
    all_precisions = []

    for pred, gt in zip(predictions, ground_truths):
        pred_boxes = pred["boxes"]
        gt_boxes = gt["boxes"]

        if len(gt_boxes) == 0:
            continue

        matched = set()
        tp, fp = 0, 0

        for pb in pred_boxes:
            best_iou, best_idx = 0, -1
            for j, gb in enumerate(gt_boxes):
                current_iou = iou(pb, gb)
                if current_iou > best_iou:
                    best_iou = current_iou
                    best_idx = j

            if best_iou >= iou_threshold and best_idx not in matched:
                tp += 1
                matched.add(best_idx)
            else:
                fp += 1

        precision = tp / (tp + fp) if (tp + fp) > 0 else 0
        recall = tp / len(gt_boxes)
        all_precisions.append(precision)

    return np.mean(all_precisions) if all_precisions else 0

# Detection model comparison:
# YOLO (v5-v8): Real-time, single-stage, anchor-free (v8)
# Faster R-CNN: Two-stage, higher accuracy, slower
# SSD: Single-stage, good speed-accuracy trade-off
# DETR: Transformer-based, no NMS needed, end-to-end

Key Insight: NMS is the critical post-processing step — without it, you get hundreds of overlapping detections. Anchor-free models (YOLOv8, FCOS) are replacing anchor-based ones. mAP@0.5 (PASCAL VOC) and mAP@[0.5:0.95] (COCO) are standard metrics. For production: YOLOv8 for speed, Faster R-CNN for accuracy, DETR for elegant end-to-end.

Q29. Build an AI-powered document processing pipeline (KPMG — AI Engineer)

Question: Design a system that extracts structured data from unstructured documents (invoices, contracts, forms).

Solution:

from typing import Dict, List, Optional
from dataclasses import dataclass
from enum import Enum

class DocumentType(Enum):
    INVOICE = "invoice"
    CONTRACT = "contract"
    FORM = "form"
    RECEIPT = "receipt"

@dataclass
class ExtractedField:
    name: str
    value: str
    confidence: float
    bounding_box: Optional[tuple] = None

class DocumentProcessor:
    """AI-powered document processing pipeline."""

    def __init__(self, ocr_engine, classifier, extractor, validator):
        self.ocr = ocr_engine
        self.classifier = classifier
        self.extractor = extractor
        self.validator = validator

    def process(self, document_path: str) -> Dict:
        """Full pipeline: OCR → Classify → Extract → Validate."""

        # Step 1: OCR — image to text
        ocr_result = self.ocr.extract_text(document_path)

        # Step 2: Document classification
        doc_type = self.classifier.classify(ocr_result["text"])

        # Step 3: Field extraction based on document type
        fields = self.extractor.extract(
            text=ocr_result["text"],
            doc_type=doc_type,
            layout=ocr_result.get("layout", None)
        )

        # Step 4: Validation & confidence scoring
        validated = self.validator.validate(fields, doc_type)

        # Step 5: Human review routing
        needs_review = any(f.confidence < 0.85 for f in validated)

        return {
            "document_type": doc_type.value,
            "fields": {f.name: {"value": f.value, "confidence": f.confidence}
                       for f in validated},
            "needs_human_review": needs_review,
            "low_confidence_fields": [f.name for f in validated if f.confidence < 0.85]
        }

    def extract_invoice_fields(self, text: str) -> List[ExtractedField]:
        """Invoice-specific extraction rules + ML."""
        import re
        fields = []

        # Rule-based extraction (high precision)
        patterns = {
            "invoice_number": r'(?:Invoice|Inv)\s*(?:#|No\.?|Number)\s*[:.]?\s*(\S+)',
            "date": r'(?:Date|Dated)\s*[:.]?\s*(\d{1,2}[-/]\d{1,2}[-/]\d{2,4})',
            "total_amount": r'(?:Total|Grand Total|Amount Due)\s*[:.]?\s*[\$₹€]?\s*([\d,]+\.?\d*)',
            "gstin": r'(?:GSTIN|GST No)\s*[:.]?\s*(\d{2}[A-Z]{5}\d{4}[A-Z]\d[A-Z\d][A-Z])',
            "pan": r'(?:PAN)\s*[:.]?\s*([A-Z]{5}\d{4}[A-Z])',
        }

        for field_name, pattern in patterns.items():
            match = re.search(pattern, text, re.IGNORECASE)
            if match:
                fields.append(ExtractedField(
                    name=field_name,
                    value=match.group(1).strip(),
                    confidence=0.9  # Rule-based = high confidence
                ))

        return fields

#                → Validator (business rules + cross-field checks)
#                → Human Review Queue (low confidence items)
#                → Structured Output (JSON/Database)

# Key models: LayoutLMv3 (Microsoft) — understands text + layout + images
# Indian specifics: GSTIN, PAN, Aadhaar extraction, Hindi/regional language OCR

Key Insight: Document AI combines OCR + NLP + layout understanding. LayoutLMv3 is state-of-art for document understanding. For consulting (KPMG/EY/Deloitte), invoice processing and contract analysis are the most common use cases. Use rule-based extraction for high-confidence fields (dates, amounts), ML for complex fields. Always include human-in-the-loop for low-confidence extractions.
