1. The Estimator API

Estimator APIConventions to rememberforbidden

Scikit-learn's power comes from a single, consistent Estimator API. Every algorithm is an object that implements the same handful of methods, so swapping one model for another never requires changing the surrounding code.

Method Role Used by
fit(X, y) Learn parameters from data All estimators
predict(X) Produce class labels / values Classifiers, regressors
predict_proba(X) Class probabilities Most classifiers
transform(X) Transform features Preprocessors, decomposers
fit_transform(X) fit then transform (often faster) Transformers
score(X, y) Default metric (accuracy / R²) Predictors
get_params() / set_params() Inspect / change hyperparameters All estimators 
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

clf = LogisticRegression(max_iter=200)
clf.fit(X_train, y_train)          # learn
clf.predict(X_test[:3])            # array([1, 0, 2])
clf.predict_proba(X_test[:1]).round(3)   # array([[0.   , 0.97 , 0.03 ]])
print(round(clf.score(X_test, y_test), 3))   # 0.974

Conventions to remember:

  • Attributes learned during fit end with a trailing underscore: coef_, feature_importances_, cluster_centers_, classes_.
  • Hyperparameters (constructor args) never have a trailing underscore.
  • fit on test data is forbidden — always fit on train, then transform/predict on test (prevents data leakage).

from sklearn import set_config
set_config(transform_output="pandas")   # transforms keep column names

3. Preprocessing

Preprocessing converts raw data into a model-ready format. The golden rule: fit the transformer on training data only, then transform both train and test with the learned statistics.

Scaling

Scaler Formula Use when
StandardScaler (x − μ) / σ Default for SVM, logistic regression, KNN, NN
MinMaxScaler (x − min) / (max − min) Need a bounded [0, 1] range
RobustScaler (x − median) / IQR Data contains outliers
MaxAbsScaler x / max(\|x\|) Sparse data (keeps zeros zero) 
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)   # learn μ, σ on train
X_test_s  = scaler.transform(X_test)        # apply SAME μ, σ to test
print(X_train_s.mean(axis=0).round(2)[:3])  # [ 0. -0.  0.]  (≈ mean 0)
print(X_train_s.std(axis=0).round(2)[:3])   # [1. 1. 1.]     (≈ std 1)

Encoding Categoricals

from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder, LabelEncoder
import numpy as np

cats = np.array([['red'], ['green'], ['blue'], ['red']])

ohe = OneHotEncoder(handle_unknown='ignore', sparse_output=False)
print(ohe.fit_transform(cats))
# [[0. 0. 1.]   (blue, green, red columns)
#  [0. 1. 0.]
#  [1. 0. 0.]
#  [0. 0. 1.]]

# Ordinal: use only when categories have a natural order
ord_enc = OrdinalEncoder(categories=[['low', 'med', 'high']])
print(ord_enc.fit_transform([['low'], ['high'], ['med']]).ravel())  # [0. 2. 1.]

# LabelEncoder: for the TARGET y only, never for features
le = LabelEncoder()
print(le.fit_transform(['cat', 'dog', 'cat', 'bird']))  # [1 2 1 0]
  • OneHotEncoder → nominal, low-cardinality features. handle_unknown='ignore' avoids crashing on unseen categories at inference.
  • OrdinalEncoder → ordered categories.
  • TargetEncoder (sklearn 1.3+) → high-cardinality categoricals (mean target per category, with cross-fitting to limit leakage).

4. Pipelines & ColumnTransformer

PipelineColumnTransformerWhy pipelines matter

A Pipeline chains preprocessing and a final estimator into a single object. ColumnTransformer applies different transformers to different column subsets. Together they prevent leakage (preprocessing is re-fit on each CV fold) and produce one serializable artifact.

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression

numeric_features = ['age', 'income']
categorical_features = ['city', 'education']

numeric_pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler()),
])
categorical_pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False)),
])

preprocessor = ColumnTransformer([
    ('num', numeric_pipe, numeric_features),
    ('cat', categorical_pipe, categorical_features),
], remainder='drop')   # 'passthrough' keeps untouched columns

model = Pipeline([
    ('prep', preprocessor),
    ('clf', LogisticRegression(max_iter=1000)),
])

model.fit(X_train, y_train)       # one fit — no leakage
y_pred = model.predict(X_test)
model.named_steps['clf']          # access a step by name
model['prep']                     # access by name via indexing

Why pipelines matter: no data leakage during CV, one object to serialize, works seamlessly inside GridSearchCV (tune preprocessing + model together), and guaranteed identical transforms at train and inference time.

5. Cross-Validation

Cross-validation estimates generalization by repeatedly splitting into train/validation folds. Pick the splitter that matches your data.

Splitter Use for
KFold Regression / generic
StratifiedKFold Classification (preserves class ratios — default)
GroupKFold Same group (patient/user) must not span folds
TimeSeriesSplit Temporal data (expanding window, no future leakage)
RepeatedStratifiedKFold Small data, lower-variance estimate
LeaveOneOut Very small datasets 
from sklearn.model_selection import StratifiedKFold, cross_val_score, cross_validate
from sklearn.ensemble import RandomForestClassifier

clf = RandomForestClassifier(n_estimators=200, random_state=42)

scores = cross_val_score(clf, X, y, cv=StratifiedKFold(5), scoring='accuracy')
print(scores.round(3))                        # e.g. [0.95 0.93 0.96 0.94 0.95]
print(f"{scores.mean():.3f} ± {scores.std():.3f}")   # 0.946 ± 0.011

# Multiple metrics + train scores in one pass
res = cross_validate(clf, X, y, cv=StratifiedKFold(5),
                     scoring=['accuracy', 'f1_weighted', 'roc_auc'],
                     return_train_score=True)
print(res['test_f1_weighted'].mean().round(3))   # 0.944
# Grouped CV — keep all rows of a group together
from sklearn.model_selection import GroupKFold

6. Linear Models

Linear models predict a weighted combination of features: ŷ = wᵀx + b. They are fast, interpretable, and strong baselines. Always scale features when regularization is used.

from sklearn.linear_model import (LinearRegression, Ridge, Lasso, ElasticNet,
                                  LogisticRegression, SGDClassifier)

LinearRegression()                       # plain OLS, minimizes MSE
Ridge(alpha=1.0)                         # L2 penalty — shrinks coefficients
Lasso(alpha=0.1)                         # L1 penalty — drives some coefs to 0 (selection)
ElasticNet(alpha=0.1, l1_ratio=0.5)      # L1 + L2 blend

LogisticRegression(
    C=1.0,                  # inverse regularization (smaller = stronger)
    penalty='l2',           # 'l1', 'l2', 'elasticnet'
    solver='lbfgs',         # 'saga' for L1/elasticnet
    max_iter=1000,
    class_weight='balanced' # handle class imbalance
)
from sklearn.datasets import make_regression
from sklearn.linear_model import LinearRegression, Lasso

X, y = make_regression(n_samples=100, n_features=5, n_informative=2,
                       noise=10, random_state=42)

print(lr.coef_.round(1))         # e.g. [ 0.   88.6  0.   41.2  0. ]

LinearRegression none Baseline, closed-form Optional

9. Clustering

K-MeansDBSCANAgglomerative

Unsupervised grouping of similar points. K-Means minimizes within-cluster variance (you choose K). DBSCAN finds arbitrary-shaped, density-based clusters and labels noise as -1. Agglomerative builds a hierarchy. Scale features first for distance-based methods.

from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.metrics import silhouette_score
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, random_state=42)

km = KMeans(n_clusters=4, n_init=10, random_state=42)
labels = km.fit_predict(X)
print(km.inertia_.round(1))                       # within-cluster SSE
print(round(silhouette_score(X, labels), 3))      # ≈ 0.79 (higher is better, max 1)

DBSCAN(eps=0.5, min_samples=5).fit_predict(X)     # -1 = noise/outlier
AgglomerativeClustering(n_clusters=4, linkage='ward').fit_predict(X)
# Elbow method: plot inertia for K=2..10 and look for the "knee"
inertias = [KMeans(k, n_init=10, random_state=42).fit(X).inertia_
            for k in range(2, 11)]

11. Hyperparameter Tuning

Tune hyperparameters inside cross-validation. GridSearchCV is exhaustive; RandomizedSearchCV samples and scales to large spaces; HalvingRandomSearchCV uses successive halving for speed.

12. Classification Metrics

Accuracy is misleading on imbalanced data — use precision, recall, F1, and ROC/PR-AUC.

from sklearn.metrics import (accuracy_score, precision_score, recall_score,
                             f1_score, classification_report, confusion_matrix,
                             roc_auc_score, average_precision_score)

y_pred = clf.predict(X_test)
y_prob = clf.predict_proba(X_test)[:, 1]   # positive-class probability

print(confusion_matrix(y_test, y_pred))
# [[85  5]    rows = actual, cols = predicted
#  [ 7 53]]
print(classification_report(y_test, y_pred, digits=3))
#               precision  recall  f1-score  support
#            0      0.924   0.944     0.934       90
#            1      0.914   0.883     0.898       60

print(round(roc_auc_score(y_test, y_prob), 3))            # threshold-independent ranking
print(round(average_precision_score(y_test, y_prob), 3))  # PR-AUC — better for imbalance
Metric Optimizes for When
Accuracy Overall correctness Balanced classes
Precision Few false positives Spam, costly FPs
Recall Few false negatives Fraud, disease screening
F1 Harmonic mean of P & R Imbalanced, single number
ROC-AUC Ranking quality Balanced-ish data
PR-AUC Positive-class ranking Severe imbalance 
# Threshold tuning — default 0.5 is rarely optimal
from sklearn.metrics import precision_recall_curve
import numpy as np
p, r, thr = precision_recall_curve(y_test, y_prob)
f1 = 2 * p * r / (p + r + 1e-9)
best_thr = thr[np.argmax(f1[:-1])]
y_tuned = (y_prob >= best_thr).astype(int)

13. Regression Metrics

MSE/RMSEMAEMAPE 
from sklearn.metrics import (mean_squared_error, mean_absolute_error,
                             r2_score, mean_absolute_percentage_error)
import numpy as np

y_true = np.array([3.0, 5.0, 2.5, 7.0])
y_pred = np.array([2.8, 5.2, 3.0, 6.5])

print(round(mean_squared_error(y_true, y_pred), 4))                       # 0.135  (MSE)
print(round(np.sqrt(mean_squared_error(y_true, y_pred)), 4))             # 0.3674 (RMSE)
print(round(mean_absolute_error(y_true, y_pred), 4))                      # 0.35   (MAE)
print(round(r2_score(y_true, y_pred), 4))                                 # 0.9617 (R²)
print(round(mean_absolute_percentage_error(y_true, y_pred), 4))          # 0.0871 (MAPE)
  • MSE/RMSEpenalize large errors; same units as target (RMSE).
  • MAErobust to outliers, equal weight to all errors.
  • R²fraction of variance explained (1 = perfect, 0 = predicting the mean).
  • MAPEscale-free percentage error (breaks when true values are near 0).

14. Feature Selection

from sklearn.feature_selection import (SelectKBest, f_classif, mutual_info_classif,
                                       RFE, SelectFromModel, VarianceThreshold)
from sklearn.linear_model import LogisticRegression

15. Model Calibration

Platt / 'sigmoid'Isotonic

Some models (Random Forest, SVM) output uncalibrated probabilities. Calibration aligns predicted probabilities with observed frequencies.

from sklearn.calibration import CalibratedClassifierCV, calibration_curve

calibrated = CalibratedClassifierCV(rf, method='isotonic', cv=5)  # 'sigmoid' = Platt
calibrated.fit(X_train, y_train)
probs = calibrated.predict_proba(X_test)[:, 1]

# Reliability check: prob_pred should track prob_true along the diagonal
prob_true, prob_pred = calibration_curve(y_test, probs, n_bins=10)
  • Platt / 'sigmoid'best when the model is already roughly calibrated.
  • Isotonicnon-parametric, more flexible, needs more data (can overfit on small sets).

17. Custom Transformers & Estimators

Inherit BaseEstimator + TransformerMixin to get get_params/set_params and fit_transform for free, ensuring full Pipeline/GridSearch compatibility.

import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin

class OutlierClipper(BaseEstimator, TransformerMixin):
    """Clip each column to IQR-based bounds learned during fit."""
    def __init__(self, factor=1.5):
        self.factor = factor

    def fit(self, X, y=None):
        X = np.asarray(X)
        q1, q3 = np.percentile(X, [25, 75], axis=0)
        iqr = q3 - q1
        self.lower_ = q1 - self.factor * iqr
        self.upper_ = q3 + self.factor * iqr
        return self

    def transform(self, X):
        return np.clip(np.asarray(X), self.lower_, self.upper_)

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
Pipeline([('clip', OutlierClipper(2.0)),
          ('scale', StandardScaler()),
          ('clf', RandomForestClassifier())])

Key contract: learn all state in fit (store with a trailing underscore), keep __init__ free of logic (just assign args), and never mutate input arrays.

23. Outlier / Anomaly Detection

Unsupervised detectors flag anomalies (label -1 = outlier, 1 = inlier). contamination is the expected outlier fraction.

from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.covariance import EllipticEnvelope
import numpy as np

iso = IsolationForest(n_estimators=200, contamination=0.05, random_state=42)
labels_iso = iso.fit_predict(X)            # isolates anomalies via random splits (fewer splits = outlier)

lof = LocalOutlierFactor(n_neighbors=20, contamination=0.05)
labels_lof = lof.fit_predict(X)            # density-based: low local density vs neighbors = outlier

ee = EllipticEnvelope(contamination=0.05, random_state=42)
labels_ee = ee.fit_predict(X)              # robust Gaussian / Mahalanobis ellipsoid

# Consensus across detectors
votes = np.vstack([labels_iso, labels_lof, labels_ee])
consensus = np.where((votes == -1).sum(0) >= 2, -1, 1)
# Simple statistical IQR rule (no model)
def detect_outliers_iqr(data, factor=1.5):
    q1, q3 = np.percentile(data, [25, 75]); iqr = q3 - q1
    lo, hi = q1 - factor*iqr, q3 + factor*iqr
    return data[(data < lo) | (data > hi)], lo, hi

IsolationForest scales to high dimensions; LocalOutlierFactor is density-based (no predict for new data by default); EllipticEnvelope assumes roughly Gaussian data.

4. Train-Test Split

Train-test splittrainingteststratification

Train-test split divides the dataset into separate training and test sets to evaluate how well a model generalizes to unseen data. The training set is used to fit the model, and the test set is held out for final evaluation. A typical split is 80% train / 20% test (or 70/30 for smaller datasets). Use stratification for classification to maintain class proportions in both sets.

from sklearn.model_selection import train_test_split
import numpy as np

# ── Basic split ──

    X, y, 
    test_size=0.2,       # 20% for testing
    random_state=42,     # Reproducibility
    shuffle=True,        # Shuffle before splitting (default)
)

# ── Stratified split (preserves class distribution) ──
# ALWAYS use for classification, especially imbalanced data
X_train, X_test, y_train, y_test = train_test_split(
    X, y, 
    test_size=0.2, 
    stratify=y,          # Maintain class proportions
    random_state=42,
)
print(f"Train: {len(X_train)}, Test: {len(X_test)}")

print(f"Test class dist:  {np.bincount(y_test) / len(y_test)}")

# ── Three-way split: Train / Validation / Test ──

5. Cross-Validation Strategies

Cross-validationK-Fold CVStratified K-FoldTimeSeriesSplitGroupKFoldRepeatedKFold

Cross-validation estimates model performance on unseen data by repeatedly splitting the dataset into train and validation folds. K-Fold CV splits data into K parts, trains on K-1, validates on 1, and rotates. Variants: Stratified K-Fold (preserves class distribution — default for classification), TimeSeriesSplit (respects temporal order — no future data leakage), GroupKFold (prevents data from the same group appearing in both train and test), and RepeatedKFold (reduces variance). Always use CV instead of a single train/test split.

from sklearn.model_selection import (
    KFold, StratifiedKFold, GroupKFold, TimeSeriesSplit,
    RepeatedStratifiedKFold, LeaveOneOut,
    cross_val_score, cross_validate
)

# ── Standard KFold ──
kf = KFold(n_splits=5, shuffle=True, random_state=42)

# ── Stratified (maintain class balance) — DEFAULT for classification ──
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# ── Grouped (no leakage across groups — e.g., same patient) ──
gkf = GroupKFold(n_splits=5)
scores = cross_val_score(model, X, y, cv=gkf, groups=patient_ids)

# ── Time Series (respects temporal order) ──
tscv = TimeSeriesSplit(n_splits=5)
# Train: [0:t], Test: [t:t+1] — expanding window

# ── Repeated (more robust estimates) ──
rskf = RepeatedStratifiedKFold(n_splits=5, n_repeats=3, random_state=42)

# ── Cross-validate with multiple metrics ──
results = cross_validate(
    full_pipeline, X, y, 
    cv=StratifiedKFold(5), 
    scoring=['accuracy', 'f1_weighted', 'roc_auc'],
    return_train_score=True
)

6. Linear Models

Linear modelsLinear RegressionLogistic RegressionRidgeLassoElasticNet

Linear models predict outputs as a weighted linear combination of input features: ŷ = wT x + b. Linear Regression minimizes MSE for continuous targets. Logistic Regression applies a sigmoid to the linear output for binary classification. Ridge (L2 penalty) shrinks coefficients toward zero, Lasso (L1 penalty) drives some coefficients to exactly zero (feature selection), and ElasticNet combines both. These are the baseline models for any ML problem — interpretable, fast, and surprisingly effective.

from sklearn.linear_model import (
    LinearRegression, Ridge, Lasso, ElasticNet,
    LogisticRegression, SGDClassifier, SGDRegressor
)

# ── Regression ──
lr = LinearRegression()
ridge = Ridge(alpha=1.0)               # L2 regularization
lasso = Lasso(alpha=0.1)               # L1 (feature selection)
enet = ElasticNet(alpha=0.1, l1_ratio=0.5)  # L1 + L2

# ── Classification ──
logreg = LogisticRegression(
    C=1.0,                # Inverse regularization (smaller = stronger)
    penalty='l2',         # 'l1', 'l2', 'elasticnet', 'none'
    solver='lbfgs',       # For L2: 'lbfgs'. For L1: 'saga'. For elasticnet: 'saga'
    max_iter=1000,
    class_weight='balanced',  # Handle imbalanced classes
    multi_class='auto',   # 'ovr' or 'multinomial'
)

# ── Large-scale (online learning, out-of-core) ──
sgd = SGDClassifier(loss='log_loss', penalty='l2', alpha=1e-4)
sgd.partial_fit(X_batch, y_batch, classes=np.unique(y))  # Incremental

7. Tree-Based Models

Decision TreesRandom ForestGradient BoostingXGBoostLightGBMCatBoost

Decision Trees recursively split data on features that maximize information gain (or minimize impurity: Gini / entropy). They're interpretable but prone to overfitting. Random Forest builds many trees on bootstrapped samples with random feature subsets, then averages their predictions (bagging) to reduce variance. Gradient Boosting (GBDT) builds trees sequentially, each correcting the previous's errors. XGBoost, LightGBM, and CatBoost are optimized GBDT libraries that dominate tabular data competitions and production ML.

from sklearn.ensemble import (
    RandomForestClassifier, RandomForestRegressor,
    GradientBoostingClassifier, GradientBoostingRegressor,

)

8. SVM, KNN, Naive Bayes

SVM (Support Vector Machine)KNN (K-Nearest Neighbors)Naive Bayes

Three classic ML algorithms: SVM (Support Vector Machine) finds the hyperplane with the maximum margin separating classes; uses kernel trick for non-linear data. KNN (K-Nearest Neighbors) classifies a point based on the majority class of its K nearest neighbors — simple, no training, but slow at prediction and sensitive to dimensionality. Naive Bayes applies Bayes' theorem with the "naive" assumption of feature independence — fast, works well for text classification and high-dimensional sparse data.

from sklearn.naive_bayes import GaussianNB, MultinomialNB, ComplementNB

# probability=True enables predict_proba (uses Platt scaling, slower)

# LinearSVC (much faster for large datasets)

# KNN
knn = KNeighborsClassifier(n_neighbors=5, weights='distance', metric='minkowski')

# Naive Bayes
gnb = GaussianNB()           # Continuous features
mnb = MultinomialNB()        # Count/frequency features (text)
cnb = ComplementNB()         # Better for imbalanced text classification

9. Clustering

ClusteringK-MeansDBSCANHierarchical clusteringsilhouette scoreelbow method

Clustering groups similar data points together without labeled targets (unsupervised learning). K-Means partitions data into K clusters by minimizing within-cluster variance (iterative centroid updates). DBSCAN finds clusters of arbitrary shape based on density (no need to specify K; identifies outliers as noise). Hierarchical clustering builds a dendrogram of nested clusters (agglomerative = bottom-up). Use silhouette score and elbow method to evaluate and choose K.

from sklearn.cluster import (
    KMeans, DBSCAN, AgglomerativeClustering, MeanShift, OPTICS
)
from sklearn.metrics import silhouette_score, calinski_harabasz_score

# K-Means
km = KMeans(n_clusters=5, n_init=10, max_iter=300, random_state=42)
labels = km.fit_predict(X_scaled)

# DBSCAN (density-based, finds arbitrary shapes)
db = DBSCAN(eps=0.5, min_samples=5, metric='euclidean')
labels = db.fit_predict(X_scaled)

# Agglomerative (hierarchical)
agg = AgglomerativeClustering(n_clusters=5, linkage='ward')

# Elbow method
inertias = []
for k in range(2, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    km.fit(X_scaled)
    inertias.append(km.inertia_)

# Silhouette score (higher = better, max=1)
score = silhouette_score(X_scaled, labels)

Dimensionality reduction reduces the number of features while preserving as much information (variance) as possible. 13. Model Calibration

Model calibration ensures that predicted probabilities reflect true likelihoods — e.g., when a model says 80% probability, it should be correct ~80% of the time. 14. Imbalanced Data

Imbalanced dataResamplingClass weightsThreshold tuningMetrics

Imbalanced data occurs when one class vastly outnumbers the other (e.g., 99% negative, 1% positive in fraud detection). Standard models become biased toward the majority class. Solutions: Resampling — oversample minority (SMOTE generates synthetic samples) or undersample majority. Class weights — class_weight='balanced' penalizes misclassifying the minority class more. Threshold tuning — lower the decision threshold to catch more positives. Metrics — use precision/recall/F1/AUC instead of accuracy. Combine multiple techniques for best results.

X_adasyn, y_adasyn = adasyn.fit_resample(X_train, y_train)
print(f"Before ADASYN: {Counter(y_train)}")

15. Custom Estimators & Transformers

Custom estimators and transformers let you extend sklearn with your own preprocessing steps or models while maintaining full compatibility with Pipelines, GridSearchCV, and cross_val_score. Inherit from BaseEstimator + TransformerMixin (for transformers) or ClassifierMixin/RegressorMixin (for models). Implement fit(), transform() (or predict()), and get_params()/set_params() (auto-provided by BaseEstimator). This is how you integrate domain-specific logic (custom feature engineering, business rules) into production pipelines.

from sklearn.base import BaseEstimator, TransformerMixin

class OutlierClipper(BaseEstimator, TransformerMixin):
    """Clip outliers to IQR bounds. Fits into sklearn pipelines."""
    
    def __init__(self, factor=1.5):
        self.factor = factor
    
    def fit(self, X, y=None):
        Q1 = np.percentile(X, 25, axis=0)
        Q3 = np.percentile(X, 75, axis=0)
        IQR = Q3 - Q1
        self.lower_ = Q1 - self.factor * IQR
        self.upper_ = Q3 + self.factor * IQR
        return self
    
    def transform(self, X):
        return np.clip(X, self.lower_, self.upper_)

class TargetMeanEncoder(BaseEstimator, TransformerMixin):
    """Safe target encoding with K-fold + smoothing."""
    
    def __init__(self, smoothing=10):
        self.smoothing = smoothing
    
    def fit(self, X, y):
        self.global_mean_ = y.mean()
        self.encodings_ = {}
        for col in range(X.shape[1]):
            mapping = {}
            for cat in np.unique(X[:, col]):
                mask = X[:, col] == cat
                n = mask.sum()
                cat_mean = y[mask].mean()
                # Smoothed: weighted average of category mean and global mean
                smooth = (n * cat_mean + self.smoothing * self.global_mean_) / (n + self.smoothing)
                mapping[cat] = smooth
            self.encodings_[col] = mapping
        return self
    
    def transform(self, X):
        X_encoded = np.zeros_like(X, dtype=float)
        for col in range(X.shape[1]):
            mapping = self.encodings_[col]
            for i, val in enumerate(X[:, col]):
                X_encoded[i, col] = mapping.get(val, self.global_mean_)
        return X_encoded

# Use in pipeline
pipeline = Pipeline([
    ('clipper', OutlierClipper(factor=1.5)),
    ('scaler', StandardScaler()),
    ('model', RandomForestClassifier()),

17. Complete Production Template

A production ML template ties together all sklearn components into a reproducible, end-to-end workflow: data loading → EDA → preprocessing (ColumnTransformer) → model training (Pipeline) → hyperparameter tuning (GridSearchCV) → evaluation (metrics + calibration) → persistence (joblib) → inference. This template serves as a reusable starting point for any tabular ML project, following sklearn best practices to prevent data leakage and ensure reproducibility.

"""Production-grade sklearn pipeline template."""
import numpy as np
import pandas as pd
from sklearn.model_selection import StratifiedKFold, cross_validate
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.feature_selection import SelectFromModel
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import classification_report, roc_auc_score
from lightgbm import LGBMClassifier
import joblib

def build_pipeline(numeric_features, categorical_features, params=None):
    """Build complete preprocessing + model pipeline."""
    params = params or {}
    
    numeric_transformer = Pipeline([
        ('imputer', SimpleImputer(strategy='median')),
        ('scaler', StandardScaler()),
    ])
    
    categorical_transformer = Pipeline([
        ('imputer', SimpleImputer(strategy='most_frequent')),
        ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False)),
    ])
    
    preprocessor = ColumnTransformer([
        ('num', numeric_transformer, numeric_features),
        ('cat', categorical_transformer, categorical_features),
    ])
    
    pipeline = Pipeline([
        ('preprocessor', preprocessor),
        ('selector', SelectFromModel(
            LGBMClassifier(n_estimators=100, verbose=-1), threshold='median'
        )),
        ('classifier', LGBMClassifier(**{
            'n_estimators': 500,
            'learning_rate': 0.05,
            'max_depth': 6,
            'subsample': 0.8,
            'colsample_bytree': 0.8,
            'min_child_samples': 20,
            'class_weight': 'balanced',
            'verbose': -1,
            **params,
        })),
    ])
    
    return pipeline

def evaluate_pipeline(pipeline, X, y, cv=5):
    """Stratified cross-validation with multiple metrics."""
    results = cross_validate(
        pipeline, X, y,
        cv=StratifiedKFold(cv, shuffle=True, random_state=42),
        scoring=['accuracy', 'f1_weighted', 'roc_auc'],
        return_train_score=True,
    )
    
    for metric in ['accuracy', 'f1_weighted', 'roc_auc']:
        train = results[f'train_{metric}']
        test = results[f'test_{metric}']
        print(f"{metric}: train={train.mean():.4f}±{train.std():.4f}, "
              f"test={test.mean():.4f}±{test.std():.4f}")
    
    return results

def train_final_model(pipeline, X_train, y_train, X_test, y_test, calibrate=True):
    """Train final model with optional calibration."""
    pipeline.fit(X_train, y_train)
    
    if calibrate:
        calibrated = CalibratedClassifierCV(pipeline, method='isotonic', cv=5)
        calibrated.fit(X_train, y_train)
        model = calibrated
    else:
        model = pipeline
    
    y_pred = model.predict(X_test)
    y_prob = model.predict_proba(X_test)
    
    print(classification_report(y_test, y_pred, digits=4))
    print(f"ROC-AUC: {roc_auc_score(y_test, y_prob[:, 1]):.4f}")
    
    joblib.dump(model, 'production_model.joblib')
    return model

18. Feature Selection

SelectKBestRFESelectFromModelSequentialFeatureSelector

Sklearn provides multiple strategies to reduce dimensionality by keeping only the most informative features, improving model speed and generalization.

SelectKBest scores each feature with a univariate statistical test and keeps the top k. RFE wraps a model and recursively drops the least important feature. SelectFromModel uses a fitted estimator's feature_importances_ or coef_ to threshold features. SequentialFeatureSelector greedily adds or removes features based on cross-validated performance.

from sklearn.feature_selection import (SelectKBest, f_classif, RFE,
                                        SelectFromModel, SequentialFeatureSelector)
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression

# SelectKBest — keep top 5 features by ANOVA F-score
skb = SelectKBest(score_func=f_classif, k=5)
X_new = skb.fit_transform(X_train, y_train)

# RFE — recursively eliminate down to 5 features
rfe = RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=5)
X_rfe = rfe.fit_transform(X_train, y_train)
print("Selected mask:", rfe.support_)

# SelectFromModel — use RF importance with median threshold
sfm = SelectFromModel(RandomForestClassifier(n_estimators=100, random_state=42),
                       threshold="median")
X_sfm = sfm.fit_transform(X_train, y_train)

# SequentialFeatureSelector — forward selection with CV
sfs = SequentialFeatureSelector(LogisticRegression(max_iter=1000),
                                 n_features_to_select=5, direction="forward", cv=5)
X_sfs = sfs.fit_transform(X_train, y_train)

19. Missing Data Imputation

SimpleImputerKNNImputerIterativeImputer

SimpleImputer fills missing values with a column-level statistic (mean, median, most_frequent) or a constant. KNNImputer estimates missing values from the k nearest complete neighbours. IterativeImputer (experimental) models each feature as a function of the others in a round-robin fashion, similar to MICE.

# SimpleImputer — constant fill

X_const = imp_const.fit_transform(X_train)

# KNNImputer — 5-neighbour weighted imputation

20. Learning Curves & Validation Curves

learning_curve() plots training and validation scores as a function of training-set size. If both converge high → good fit; both converge low → high bias (underfit); large gap → high variance (overfit). validation_curve() varies a single hyperparameter to reveal sensitivity—use it to find the sweet spot before full grid search.

from sklearn.model_selection import learning_curve, validation_curve
from sklearn.svm import SVC
import numpy as np

# Learning curve — diagnose bias vs variance
train_sizes, train_scores, val_scores = learning_curve(
    SVC(kernel="rbf", gamma=0.1), X, y,
    train_sizes=np.linspace(0.1, 1.0, 10), cv=5, scoring="accuracy")

# Interpretation:
#   mean_train = train_scores.mean(axis=1)
#   mean_val   = val_scores.mean(axis=1)
#   Gap closing at high score  → well-fit model
#   Gap closing at low score   → add complexity / features
#   Gap not closing            → more data or regularise

# Validation curve — tune C for SVC
param_range = np.logspace(-3, 3, 7)
train_sc, val_sc = validation_curve(
    SVC(kernel="rbf"), X, y,
    param_name="C", param_range=param_range, cv=5, scoring="accuracy")

# Plot mean ± std for train_sc and val_sc vs param_range
# Peak val score indicates optimal C; divergence after = overfitting

21. Outlier Detection Models

IsolationForestLocalOutlierFactorEllipticEnvelope

IsolationForest isolates anomalies by random recursive partitioning—outliers need fewer splits. LocalOutlierFactor compares local density of a point to its neighbours; low ratio = outlier. EllipticEnvelope fits a robust covariance estimate assuming Gaussian data and flags points outside the Mahalanobis-distance ellipsoid.

from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.covariance import EllipticEnvelope

# IsolationForest — contamination = expected outlier fraction
iso = IsolationForest(n_estimators=200, contamination=0.05, random_state=42)
labels_iso = iso.fit_predict(X)          # -1 = outlier, 1 = inlier

# LocalOutlierFactor — density-based
lof = LocalOutlierFactor(n_neighbors=20, contamination=0.05)
labels_lof = lof.fit_predict(X)          # -1 = outlier

# EllipticEnvelope — Gaussian assumption
ee = EllipticEnvelope(contamination=0.05, random_state=42)
labels_ee = ee.fit_predict(X)            # -1 = outlier

# Common pattern: majority vote across detectors
import numpy as np
votes = np.vstack([labels_iso, labels_lof, labels_ee])
consensus = np.where(np.sum(votes == -1, axis=0) >= 2, -1, 1)

22. Interview Deep Dive

No data leakageSingle serializable objectWorks with GridSearchCVReproducibilityRandom ForestXGBoost

Q1: Explain the sklearn Pipeline. Why is it critical for production?

A: A Pipeline chains preprocessing and modeling into a single object. Critical reasons: (1) No data leakage — preprocessing (scaling, imputation) is fit only on training data during CV, applied to validation/test. Without a pipeline, calling scaler.fit_transform(X_all) before splitting leaks test statistics. (2) Single serializable object — save one joblib file for entire workflow. (3) Works with GridSearchCV — tune preprocessing and model params together. (4) Reproducibility — guaranteed same transforms at training and inference.

Q2: When would you use Random Forest vs XGBoost vs LightGBM?

A: Random Forest: Good baseline, robust to hyperparameters, embarrassingly parallel (n_jobs=-1), handles missing values poorly. XGBoost: Best for structured/tabular data competitions, strong regularization (L1/L2 + column subsampling), GPU support. LightGBM: Fastest for large datasets (histogram-based), handles categoricals natively, lower memory, leaf-wise growth (more splits but potentially overfits). In practice: Start with LightGBM for speed, validate with XGBoost, use RF as a simple baseline. CatBoost if you have many categorical features.

Q3: How do you handle a 1:100 class imbalance?

A: Layered approach: (1) Metric: Don't use accuracy! Use PR-AUC, F1, or Matthews Correlation Coefficient. (2) Class weights: class_weight='balanced' in the model (free, no extra data). (3) Resampling: SMOTE in an imbalanced-learn pipeline (oversample minority). (4) Threshold tuning: After training, optimize classification threshold on validation set to maximize F1. (5) Anomaly detection reframing: If minority class is rare enough, Isolation Forest may work better. (6) Collect more data for the minority class if possible. (7) Evaluation: Always report PR-AUC, not ROC-AUC — ROC-AUC can be misleading with severe imbalance.

Q4: What is model calibration and when do you need it?

A: Model calibration ensures predicted probabilities match actual frequencies — when the model says P(y=1)=0.7, ~70% of those cases should actually be positive. Needed when: (1) Making decisions based on probability thresholds (fraud detection, medical diagnosis). (2) Comparing predictions from different models. (3) Using log loss as evaluation metric. Random Forests push probabilities toward 0.5 (poor calibration), logistic regression is usually well-calibrated. Fix: CalibratedClassifierCV with isotonic regression or Platt scaling (sigmoid). Check: plot calibration curve (reliability diagram).

Q5: How do you prevent data leakage in feature engineering?

A: Data leakage occurs when information from the test set influences training. Prevention: (1) Pipeline everything — scaling, imputation, encoding inside sklearn Pipeline. (2) Target encoding — use K-fold target encoding (never encode using full dataset mean). (3) Time-based features — only use data available at prediction time; no future data in lag features. (4) Feature selection — do it inside CV (SelectFromModel in pipeline), not on full data before splitting. (5) Check: If model seems too good (AUC > 0.99 on typical problem), suspect leakage. Look at feature importance — if a suspiciously informative feature exists, investigate.

Q6: Explain ColumnTransformer and when you'd use it.

A: ColumnTransformer applies different transformations to different column subsets in parallel — numeric columns get scaling, categorical get encoding. It takes a list of (name, transformer, columns) tuples. Use remainder='drop' to ignore other columns or remainder='passthrough' to keep them. It's essential because real datasets have mixed types — applying StandardScaler to categorical or OneHotEncoder to numeric columns makes no sense. Combined with Pipeline, it creates a complete preprocessing step that handles any input DataFrame consistently.

Q7: When would you write a custom sklearn transformer?

A: When you need preprocessing logic that doesn't exist in sklearn's built-in transformers. Examples: (1) Business-specific feature engineering (RFM scores, domain calculations). (2) Custom outlier clipping (IQR-based bounds). (3) Target encoding with smoothing. (4) Feature interactions specific to your domain. Key: inherit from BaseEstimator + TransformerMixin, implement fit() (learn parameters from training data) and transform() (apply to any data). This ensures compatibility with Pipeline, GridSearchCV, and proper train/test separation.

Q8: How do you choose between PCA and feature selection?

A: PCA: Creates new features as linear combinations of originals. Use when: features are correlated, you want dimensionality reduction, interpretability isn't critical. Set n_components=0.95 to keep 95% variance. Feature selection (SelectKBest, RFE, LASSO): Keeps original features. Use when: interpretability matters, you want to understand which features drive predictions, regulatory requirements exist (finance, healthcare). In practice: Use feature selection first (remove obviously useless features), then optionally PCA on the remaining. For tree-based models, PCA usually hurts performance.
