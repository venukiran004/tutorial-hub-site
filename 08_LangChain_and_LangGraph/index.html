LangChain & LangGraph

Building large language model (LLM) applications and stateful agent workflows — the two libraries end to end, the agent pattern catalogue, the failure-handling trilogy, implementation cookbooks, and roughly a thousand practice questions and scenarios.

The distinction to hold: LangChain composes straight-line pipelines — that is what the LangChain Expression Language (LCEL) is for. The moment you need a loop, a decision, memory across turns, or human approval, you need an orchestrator with state — that is LangGraph.
